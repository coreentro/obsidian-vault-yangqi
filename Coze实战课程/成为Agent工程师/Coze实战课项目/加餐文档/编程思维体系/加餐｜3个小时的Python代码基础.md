# 加餐｜3个小时的Python代码基础

这也是我经常被问到的问题：我没有编程经验，可以入门Coze（AI Agent）么？

我的回答是：入门Coze是很容易的，但是在当下的这个技术水平下，如果你想要用好，可能需要一些编程的思维和基础，这块绕不开。

作为程序员的我可以负责任的告诉你，这块的知识没那么简单，不是听别人讲个一两节课就可以搞定的。

重要的是去实操。

但是在AI时代，学习这些知识的成本又大大的降低了，虽然ChatGPT没有办法帮我们写出完整的代码，但是他可以帮我们写代码片段以及修改语法错误，只要我们掌握了基本的编程思维，利用ChatGPT写简单的代码并不是什么难题。

我们课程不教授写代码，因为这是一个非常巨大的工程，而且在AI时代，我和艾木都推崇以练带学，所以对于非程序员学习代码，并且你的目标不是成为程序员，那么我们认为有两步：

- 学习一些编程的基础知识，起码你得知道代码是什么（这部分要靠教程，但是不要沉浸在各种教程中，搞清楚代码是什么之后，接下来就可以进入第二阶段啦）
- 利用ChatPT、智谱清言等工具帮助你不断的写代码，调试代码（这部分要靠自己动手，**而且更重要！**）

所以针对第一部分，本来我们想出个教程，但是奈何能力有限，于是我在B站上找到了一个教程。
