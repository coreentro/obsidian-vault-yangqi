# 数据类型是什么

在学习一个新知识前，我喜欢将其进行分类，类似于阅读一本书之前先阅读大纲一样。

针对数据类型，我们将其分类为基本数据类型以及复杂数据类型

## 基本数据类型

在本文中，我们将基本类型分为以下4类，足够我们理解绝大部分的场景

1. **String（字符串）**：

   - 表示文本数据。
   - 例子：`"Hello, World!"`，`"1234"`
2. **Integer（整数）**：

   - 表示所有整数数据类型
   - 例子：`123`（整数）
3. **Double**（**浮点数**）

   - 表示所有小数数据类型
   - 例子：13.5 （小数）
4. **Boolean（布尔值）**：

   - 表示逻辑值，只有两个取值：`true` 和 `false`。
   - 例子：`true`（表示真），`false`（表示假）

## 复杂数据类型

复杂数据类型大家并不陌生，就是我们的老朋友：JSON

如果不了解JSON的，请务必先阅读这篇文章

<cite doc-id="VnocwzT3TirKGvkUfvncWa53njc" file-type="wiki" title="加餐｜Coze的插件与JSON" type="doc"></cite>

如果你已经阅读过这篇文章，我相信你对JSON有了一个清晰的认知

**对象（Object）**：

- 由键值对（key-value pairs）组成，键是字符串，值可以是任何类型的数据。
- 用大括号 `{}` 包围，每个键值对用冒号 `:` 分隔，不同的键值对用逗号 `,` 分隔。
- 例子：

```JSON
{
    "name": "Alice",
    "age": 30,
    "isStudent": false
}
```

**数组（Array）**：

- 有序的值的集合，值可以是任何类型的数据。
- 用方括号 `[]` 包围，值之间用逗号 `,` 分隔。

**例子1：由基本数据类型构成的数组**

1. 由String类型构成的数组

```JSON
[
    "apple",
    "banana",
    "cherry"
]
```

1. 由Number类型构成的数组

```JSON
[
    1.5,
    2.6,
    3.7
]
```

**例子2：由复杂数据类型（Object）构成的数组**

```JSON
[
    {
        "name": "大圣",
        "age": 18,
        "weight":70.5
        "isStudent": true
    },
    {
        "name": "艾木",
        "age": 16,
        "weight":70.5
        "isStudent": false
    }
]
```

## 两种数据类型的关系

通过上面的例子，我相信你已经发现了一些规律

<callout emoji="⛱️">
**规律1**：复杂数据类型（JSON中的Object）其实就是由一系列的基本数据类型构成的
**规律2**：复杂数据类型（JSON中的Array）既可以是基本数据类型的集合，也可以是复杂数据类型Object的集合
**如果你明白了我说的嵌套的概念，你会发现，当你一层一层的剥开JSON的对象或者数组的时候，最后都会是一个个的基本数据类型组成**
</callout>

为了确保大家能理解，我再举一个简单的例子：

假设我们要描述一个朋友的基本信息和他的爱好。

这些信息可以包括他的名字、年龄、体重、是否喜欢运动，以及他喜欢的运动项目。

我们可以用编程中的数据类型来表示这些信息。

1. **String（字符串）**：

   - 表示朋友的名字和他喜欢的运动项目。
   - 例子：`"小明"`, `"篮球"`
2. **Integer（整数）**：

   - 表示朋友的年龄。
   - 例子：年龄 25
3. **Double**（浮点数）

   - 表示朋友的体重
   - 例子：体重70.5 千克
4. **Boolean（布尔值）**：

   - 表示朋友是否喜欢运动。
   - 例子：`true`（喜欢运动）, `false`（不喜欢运动）
5. **JSON（复杂数据类型）**：

   - 用于表示整个朋友的信息，包括他的基本信息和爱好。
   - 其中包含对象和数组。

假设我们描述的小明的信息如下：

- 名字是小明
- 年龄是25岁
- 他喜欢运动
- 他喜欢的运动项目有篮球和足球

用 JSON 表示小明的信息：

```JSON
{
    "name": "小明",
    "age": 25,
    "weight":70.5
    "likesSports": true,
    "favoriteSports": [
        "篮球",
        "足球"
    ]
}
```

# 数据类型在Coze中的应用

Coze中你可能并没有特别注意到数据类型的存在，那是因为你大部分时间都在和**String**打交道，但是当你可以进阶一些内容的时候，你就会逐渐接触更多的数据类型

这一章节，我跟大家细数下Coze中数据类型的存在

PS：**关于整数和浮点数类型，Coze中一直没有交代的特别清楚，你会发现Number这么一个数据类型，不用太过关注。**

- 如果有既有Integer又有Number，那么Integer就是整数，Number就是浮点数
- 如果只有Number，那么可能Number既表示整数，也可以表示浮点数

为什么变量都是String类型呢？这里涉及到一个编程概念

**任何的数据类型都可以用String来表示，然后在程序中可以转换为对应的其余类型**

- 整数可以是13，用String也可以表示为"13"
- 浮点数可以是13.5，用String也可以表示为"13.5"
- 布尔值可以是true，也可以是"true"
- JSON 对象可以是

  ```JSON
  {
      "name": "Alice",
      "age": 30,
      "isStudent": false
  }
  ```

用String可以表示为

```JSON
"{\"name\":\"Alice\",\"age\":30,\"isStudent\":false}"
```

- JSON 数组可以是用String 可以表示为

  ```JSON
  [
      1.5,
      2.6,
      3.7
  ]
  ```

  ```JSON
  "[1.5,2.6,3.7]"
  ```
