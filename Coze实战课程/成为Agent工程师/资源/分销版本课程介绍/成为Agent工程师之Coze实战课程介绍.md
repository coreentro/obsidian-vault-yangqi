# 课程的由来

<callout emoji="🎁">
**这是两个互不相识的软件开发工程师（大圣和艾木）共同推出的首次付费课程**
**我们俩有很多的相同点：**
1. 都热爱 Coze，并对其背后代表的 AI Agent 领域充满兴趣。
2. 看好 AI Agent 的前景，同时对其当前的能力保持理性判断。
3. 反感贩卖焦虑和空谈梦想，推崇抬头看天，脚踏实地
4. 我们都比较关注自己的成长。AI 技术日新月异，我们也在不断学习、不断实践。但驱动我们的不是焦虑，而是兴趣，以及我们感受到的 AI 打开的各种可能。
**我们又有一些不同，这也让我们能更好的互补：**
1. 大圣擅长将 AI 知识讲解的通俗易懂
2. 艾木更偏技术流，他喜欢读论文，直指技术的本质
**针对这次课程来讲：**
1. 作为长期主义者，我们设定了成为 Agent 工程师的长远目标
2. 由于脚踏实地的原则，我们选择了 Coze 作为第一期的课程
**课程目标很简单：**
- 一起学习，提高对 AI Agent 领域的认知，拥抱即将到来的 AI 时代
- 我们不承诺学完课程后能立即变现，也不承诺找到高薪工作。
- 唯一的承诺是：尽我们所能，分享我们所学，不制造信息差。
</callout>

# 课程基本信息

## 课程信息

我们课程的定位是AI Agent教学，不承诺变现，也不承诺找到高薪工作。

我们的课程通过例子的方式来进行教学，希望可以通过案例交给大家Coze的初阶以及高阶用法。

我们的课程大纲如下

（**PS：由于一期课程已经完成，因此下面的大纲都会是录播，每周的直播课程则会替换成直播答疑**）

1. 第一周：课程开幕式，我们两位跟大家分享下课程的预期以及我们各自的教学风格
2. 第一周：客服机器人｜基于RAG构建企业生产资料问答系统（录播） + 周六直播答疑
3. 第二周：绘本故事｜儿童绘本+电影海报解锁Coze卡片玩法（录播） + 周六直播答疑
4. 第三周：翻译智能体｜Multiagent之间的交互优化回答结果（录播）+周六直播答疑

## 课程特点

我们的课程有自己独特的风格

1. **尽我们所能教授知识，不搞信息差**。但对于**变现、企业落地以及找工作**，不做任何承诺，这些全凭个人能力
2. **我们使用案例进行教学**，而不是像有些教程仅仅是讲一个个的功能点
3. **我们所有的案例都是公布在课程的Coze团队中的，大家可以百分之百复制学习**（**包括艾木的谁是卧底！**）
4. **我们希望能够讲出Coze各个组件背后的本质**，比如数据库、知识库和变量等，而不仅仅是使用手册。这样在以后其他类似Coze的AI Agent平台出现的时候，你可以无缝迁移。**既授人以鱼**，又**授人以渔，让你知其然，知其所以然**
5. **我们的课程由浅入深，针对不同阶段的人群**，前面的课程很基础，帮助小白入门，后面的案例都是进阶玩法，不会浮于表面
6. **大圣和艾木两位也在不断的学习和进步，我们不会死守着这门课程固步不前。**我们深知AI技术发展的快速性
7. **我们俩都有公开分享，可以看到我们的教学风格**

## 学习课程之后，我能做出XX Bot么？

这个我们无法承诺，因为对于一个产品需求，他是一个非常复杂的事情。

这里面需要考虑的事情有很多，比如：

- 这个Bot用户的输入是什么？期望的输出是什么？
- 老板对于Bot的回答速度有什么要求？
- Bot怎样的回答才是符合要求的（因为大模型是具有不稳定性的）
- 是否需要考虑数据安全的问题？
- Bot需要发布在哪里，该如何给用户使用
- ....

如果你是一个职场打工人或者老板，你肯定能明白对于一个产品需求来讲，有时候技术并不是主要的，而是提需求的人是否将需求考虑的全面，然后在产品实现之后还要使用不同的测试用例对产品测试，如果不符合预期还需要进行调试迭代或者降低产品的一些其他能力等等。

所以请不要指望一个几百块的课程可以帮助你解决复杂的产品需求。

但是Coze确实是一个可以打造产品原型的平台，我们希望这个课程可以拓宽你的思维，给你提供更多的灵感。

至于是否能够解决你的实际痛点，这需要你去进行不断的尝试了
