# 06.28 第二次直播课程开课通知

大家好，这里是《成为Agent工程师》课程的通知消息。

我们预告下一次直播课程的时间：

上课时间：**6月29号 20:00（本周六）**

上课方式：视频会议（会有回放）

上课主题：**儿童绘本 + 电影海报解锁Coze的卡片玩法**

预计耗时：1.5 -2 小时

我们的第一周已经打完了基础，还没有学习的小伙伴可以查阅资料<cite doc-id="PbQXwLzvqi4oo0kLL9pcae5dnRg" file-type="wiki" title="01｜基于RAG构建企业生产资料问答系统" type="doc"></cite>

本周我们的主题是学习Coze的两个进阶玩法：卡片和批处理（图像流没有什么可讲的）

为什么是这两个知识点呢？因为随着最近Coze比赛的增多，大家会发现获奖的优秀Bot不仅内容新奇有趣，而且都会有比较漂亮的UI，这正是使用了Bot中的卡片能力。而批处理则可以加快工作流的处理速度
