# 本周及下周课程计划变更：以赛带学

大家应该有了解到，WayToAGI 社区最近推出了一个"谁是人类"的 AI Agent 比赛。以下是活动介绍 ：

<callout emoji="💥">
### **比赛目标：**
通过 **AI Bot 拟人化比赛**，带大家一起`提升 Prompt 书写能力`，通过多轮比赛和分享来加深对 `AI Agent 的学习和理解`。
### **活动形式：**
在一个活动群里，主持人出题，AI机器人+人类卧底潜伏在微信群中回答问题。一场比赛6-8轮，每轮群众选出谁是人类。
### **参与方式：**
围观群众：在比赛时间查看视频号「通往AGI之路」或「阿里云」
参与选手：加入微信群，7月24日首次共学结束后，群中统一招募
</callout>

详情见这里：<cite doc-id="Gm72wS4BqixefikquThcERlgnD0" file-type="wiki" title="「Agent 共学」之&#34;谁是人类&#34; 「WayToAGI x 阿里云」" type="doc"></cite>。

正好我们的《成为 Agent 工程师》课程本周的主题也是“搭建微信机器人”，无论是时间节奏还是主题上跟这个活动都很契合。所以我们（艾木和大圣）经过商议，决定对本周以及下周的课程计划做出一个比较大的调整，我们决定将本周原定的直播课变更成**带领大家参加 WayToAGI 的这次 Agent 比赛，以赛带学**。过程中，我们会为大家提供好指导和技术支持，**确保想参赛的朋友都至少能搭建起一个能够参赛的微信机器人（\*在硬性条件都具备的情况下）。**虽然梦飞已经很详尽的分享了（<cite doc-id="NB3nwtUC0iDLYxkIkSYc0WRznGg" file-type="wiki" title="【共学最全版本】微信机器人共学教程" type="doc"></cite>），但是我们清楚“搭建起一个能够参赛的微信机器人”并不是一个容易达到的门槛。【\* 这里的硬性条件指有自己的服务器，有微信小号等】

WayToAGI 的活动安排如下：

## 任务单

大家在 7.25 号 WaytoAGI 的 “Bot 拟人化”分享之前，需要自助完成以下任务。

1. 查阅活动文档 <cite doc-id="Gm72wS4BqixefikquThcERlgnD0" file-type="wiki" title="「Agent 共学」之&#34;谁是人类&#34; 「WayToAGI x 阿里云」" type="doc"></cite>，了解活动的详细信息。
2. 跟随大圣的文档 <cite doc-id="Ptd6wCspuiJtb7kAekpcV7Lbnoh" file-type="wiki" title="加餐｜服务器是什么" type="doc"></cite> 购买并准备好自己的服务器。
3. 跟随我们提供的微信机器人搭建教程（这个教程我们今天准备出来）完成基础 Bot 的搭建。当然，之前已经跟随梦飞的教程搭建好 Bot 的朋友，就不用再搭啦。

 

PS. 在 7.24 号大家可以选择性参加 WaytoAGI 关于 “通义 API 接入 Bot” 的分享。
