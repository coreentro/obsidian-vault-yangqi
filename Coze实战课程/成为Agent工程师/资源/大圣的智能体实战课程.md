# 一、为什么有这门课和社群

这不仅是一门体系化的AI课程，更是一个高质量的AI学习社群（微信社群）。

从2024年6月开始，已有1200+志同道合的学员加入其中。

过去一年的教学与陪伴，让我看清了一个普通人学习AI的关键误区：

**大多数人不是不会用AI，而是从一开始就走错了方向。**

**沉迷工具、囤积模板，却始终无法真正驾驭AI：不会判断工具边界，不理解底层逻辑，学得越多，焦虑越深。**

- **它不仅仅是教你怎么用某个工具，核心是帮你构建一套可长期进化的AI能力体系。**

- 从AI通识打基础，到主流工具实操，再到智能体构建与AI编程能力，我希望带你走完这条路径：**从“会用”，到“会整合”，再到“能创造”。**
