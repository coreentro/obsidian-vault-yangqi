# 数据类型是什么

在学习一个新知识前，我喜欢将其进行分类，类似于阅读一本书之前先阅读大纲一样。

针对数据类型，我们将其分类为基本数据类型以及复杂数据类型

## 基本数据类型：基础积木

在本文中，我们将基本类型分为以下4类，足够我们理解绝大部分的场景

1. **String（字符串）**：

   - 表示文本数据。
   - 例子：`"Hello, World!"`，`"1234"`
2. **Integer（整数）**：

   - 表示所有整数数据类型
   - 例子：`123`（整数）
3. **Double**（**浮点数**）

   - 表示所有小数数据类型
   - 例子：13.5 （小数）
4. **Boolean（布尔值）**：

   - 表示逻辑值，只有两个取值：`true` 和 `false`。
   - 例子：`true`（表示真），`false`（表示假）

## 复杂数据类型：积木的集合

想象你在玩乐高，基本数据类型就是各种基础积木，而复杂数据类型就是用这些积木搭建的作品

复杂数据类型大家并不陌生，就是我们的老朋友：JSON

如果不了解JSON的，请务必先阅读这篇文章

<cite doc-id="BohSwor9NibXtMk7nqjcyvJRnlg" file-type="wiki" title="06｜数据的桥梁，理解与应用JSON" type="doc"></cite>

如果你已经阅读过这篇文章，我相信你对JSON有了一个清晰的认知

1. **对象（Object）：一个信息卡片**

- 由键值对（key-value pairs）组成，键是字符串，值可以是任何类型的数据。
- 用大括号 `{}` 包围，每个键值对用冒号 `:` 分隔，不同的键值对用逗号 `,` 分隔。
- 例子：就像一张个人信息卡，上面有不同的信息项：

```JSON
{
    "姓名": "小明",
    "年龄": 25,
    "身高": 175.5,
    "是否学生": true
}
```

**2. 数组（Array）：一个有序列表**

- 有序的值的集合，值可以是任何类型的数据。
- 用方括号 `[]` 包围，值之间用逗号 `,` 分隔。

**例子1：由基本数据类型构成的数组**

1. 由String类型构成的数组

```JSON
// 购物清单
["苹果", "香蕉", "牛奶"]
```

1. 由Number类型构成的数组

```JSON
// 成绩单
[98, 87, 92]
```

1. 数组和对象的组合使用

```JSON
{
    "班级": "三年二班",
    "学生列表": [
        {
            "姓名": "小明",
            "年龄": 9,
            "爱好": ["足球", "画画"]
        },
        {
            "姓名": "小红",
            "年龄": 8,
            "爱好": ["跳舞", "唱歌"]
        }
    ]
}

```

我来帮你把这部分内容改写得更生动形象：

## 基础类型与复杂类型的关系

<callout emoji="💡">
1. **积木搭建规律**：

   - 复杂的对象（Object）就像一个由基础积木搭建的房子
   - 数组（Array）就像一个积木收纳盒，可以存放基础积木，也可以存放已经搭好的小房子
2. **层层拆解**：

   - 如果你把一个复杂的JSON结构一层层拆开
   - 最终都能拆解成最基本的积木块（**基础数据类型**）
</callout>

## 一个例子：小明的个人档案

让我们用制作一份个人档案的方式来理解数据类型：

### 收集基础信息

想象你在填写一份表格，需要收集以下信息：

📝 **文字信息**（String类型）

- 姓名："小明"
- 运动项目："篮球"、"足球"

🔢 **数字信息**（Integer类型）

- 年龄：25岁

⚖️ **精确数字**（Double类型）

- 体重：70.5千克

✅ **是否类信息**（Boolean类型）

- 是否爱好运动：是（true）

### 制作档案卡（组合数据）

就像我们把散落的信息整理到一个档案卡中，我们用JSON把这些信息组织起来：

```JSON
{
    "name": "小明",        // 文字类型
    "age": 25,            // 整数类型
    "weight": 70.5,       // 小数类型
    "likesSports": true,  // 是否类型
    "favoriteSports": [   // 数组类型
        "篮球",
        "足球"
    ]
}
```

### 可视化理解

```Bash
小明的档案
├── 基本信息
│   ├── 姓名: "小明" (字符串)
│   ├── 年龄: 25 (整数)
│   ├── 体重: 70.5 (小数)
│   └── 喜欢运动: true (是否值)
     └── 喜欢的运动: ["篮球", "足球"] (字符串数组)
```

### 生活中的类比

这就像是：

- 📁 一个文件夹（对象）里面
- 📄 装着各种文件（基础数据）
- 📦 还有一个收纳盒（数组）用来存放相关的物品

通过这种方式，我们就把零散的基础数据类型组织成了一个有结构的信息档案。

**这正是JSON的强大之处：它能够像搭积木一样，用简单的基础类型构建出复杂的数据结构。**
