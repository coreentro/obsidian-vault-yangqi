# 写在前面

大家好，我是大圣，这节课给大家讲解写好提示词的6个技巧

写好提示词的策略是道层面的内容，而这篇文章是术的层面，真正告诉你技巧

今天我们就用**6个技巧**，教你写出高效、易懂的提示词

# 技巧1：明确任务（Task）

<callout emoji="💡">
**清晰的告诉AI“你要做什么”**
</callout>

**核心**：用一句话说清楚你想让AI完成的具体任务。

  
**为什么重要**？如果任务模糊，AI可能会“自由发挥”，结果偏离预期。

  
**正确示范：**

  
❌ 模糊指令：“帮我写点东西。”

  
✅ 明确任务：“请写一篇关于环保的科普文章，重点介绍塑料污染的危害。”

# 技巧2：补充背景（Context）

<callout emoji="💡">
**核心**：**提供任务相关的背景信息，帮助AI理解上下文。让AI知道“为什么做这件事”**
</callout>

  
**适用场景**：复杂任务、专业领域或需要特定视角的内容。  

**例子**：

> 任务：撰写一份产品推广文案
> 
>   
> **背景：这是一款针对儿童的可降解水杯，主打安全环保，目标用户是注重健康的年轻家长。**

# 技巧3：给例子（Examples）

<callout emoji="💡">
**这招就像"用案例打样"，通过给AI看几个例子，让它明白你想要什么样的回答。**
</callout>

  
**效果**：显著提高AI的准确率，尤其适合创意类任务（如写诗、设计口号）。

**举个例子：**

<grid>

❌ 直接提问：
"帮我写几条朋友圈文案。"

✅ 少样本提示：
请参考以下风格，再写5条类似的朋友圈文案：
```SQL
例1：
周末早起去了趟菜市场
买了些新鲜时蔬
阳光暖暖的，心情也暖暖的
生活总是在柴米油盐里偷偷变甜

例2：
下了一天的雨
写字楼里的灯一盏盏亮起
对面星巴克飘来咖啡香
这座城市又开始忙碌
```

</grid>

# 技巧4：设定角色（Persona）

<callout emoji="💡">
**指定AI以特定身份回答问题，提升专业性或亲和力。**
</callout>

  
**常用角色**：

- 专业型：医生、律师、市场营销专家
- 风格型：幽默的朋友、严肃的老师、贴心的客服

**示例1**：

> 任务：解释量子力学  
> 角色：“**假设你是一位初中科学老师**，用简单易懂的语言和比喻向学生解释。”

**示例2:**

> 请用**鲁迅的文风**帮我写一篇关于体育圈饭圈文化现象的文章

# 技巧5：规定格式（Format）

<callout emoji="💡">
让答案“整齐划一”，明确输出结构（如Markdown、表格、对话体），方便后续使用。
</callout>

  
**常见格式**：

1. 列表：`第一点 2. 第二点`

- 邮件：`标题+正文+落款`
- 对话体：`用户：... / AI：...`

**示例1**：

> 任务：总结会议纪要  
> 格式：请用Markdown，包含“时间、参会人、主要结论、下一步行动”四个部分。

**示例2:**

<grid>

❌ 直接提问：
"给我一些关于苹果、香蕉和橙子的营养信息。"

✅ 输出格式控制：
```JSON
请提供苹果、香蕉和橙子的营养信息

使用以下JSON格式：

{
  "水果": [
    {
      "名称": "水果名",
      "热量": "每100克卡路里数",
      "维生素C": "每100克含量（毫克）",
      "膳食纤维": "每100克含量（克）",
      "主要益处": "简短描述"
    }
  ]
}
```

</grid>

# 技巧6：调整语气（Tone）

<callout emoji="💡">
控制语言风格，根据场景选择适合的语气，比如正式、随意、热情或严肃。
</callout>

  
**场景对比**：

- 正式：商务报告、学术论文 → “经分析，本方案可行性较高。”
- 随意：社交媒体文案 → “超好用的水杯！宝妈们快冲！”

# 综合应用

我们根据上面的几个策略写了一个完整的提示词模板

```Markdown
任务：撰写一封邀请客户参加新品发布会的邮件  
背景：客户是长期合作的高端品牌，发布会主题是“科技与可持续未来”  
角色：以公司市场总监的身份撰写  
格式：邮件格式，包含标题、问候语、活动亮点、报名方式  
语气：正式且富有吸引力  
例子参考：  
标题：诚邀您共赴XX品牌2024科技新品发布会  
正文：尊敬的[客户名]，我们诚挚邀请您……  
```

注意：提示词的本意是为了描述清楚，让AI可以输出符合预期的回答，所以并不一定需要所有的策略都用上

请始终记住一句话：一切策略都是为了最终的效果服务

# 总结

<callout emoji="💡">
好提示词 = 清晰目标 + 充分信息
</callout>

刚开始可以按顺序逐个添加，熟练后灵活组合。
