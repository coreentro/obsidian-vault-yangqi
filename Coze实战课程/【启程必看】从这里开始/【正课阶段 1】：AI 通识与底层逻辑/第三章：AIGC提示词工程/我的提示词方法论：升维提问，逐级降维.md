# 写在前面

大家好，我是大圣，这节课给大家讲一个我一直在用的提示词方法论：升维提问，逐级降维

大部分AI初学者会遇到这种情况：

学了很多AI提示词技巧，背了一堆案例，但真要自己写提示词时，还是大脑一片空白，不知道从何下手？

这个问题的本质还是你没有很好的利用AI，为了让你有更好的理解，我将我日常使用的方法总结了一个方法论

**升维提问，逐级降维**

#  什么是“升维提问，逐级降维”

<callout emoji="💡">
当你面对一个复杂问题，不知道如何具体操作时，可以先向AI提一个更“高维度”的问题，让AI帮你找到解决问题的思路和框架。然后，再根据AI的回答，一步步细化问题，最终找到具体的解决方案。
</callout>

**核心思想：** 一切皆可AI，当你不知道怎么做的时候，把问题交给AI，让它帮你思考。

下面，我们直接通过两个案例让你对这个抽象的方法论有更具象的理解

# 案例一：如何总结会议纪要

假设你刚参加完一个重要会议，老板让你整理一份会议纪要。你可能绞尽脑汁也想不出一个清晰的总结方法。

这时，你可能会去网上搜索“会议纪要提示词模板”，然后找到一个类似这样的模板：

```Markdown
请将如下会议纪要按照如下三个框架进行整理：

决策事项
待办事项
风险预警

会议纪要内容:[会议纪要]
```

我想这个时候你可能会产生一些疑惑和自我怀疑：

- 为什么是这三个框架？
- 这三个框架是怎么来的？为什么别人能写出来我不能
- 如果换一个会议，我还应该用这三个框架吗？

这时候我们的升维提问方法论就派上用场了

**第一步：升维提问（向AI寻求思路）**

你可以直接问AI：

> 我刚参加完一个会议，需要整理一份会议纪要。我不确定该从哪些方面入手，你能给我一些建议吗？

AI可能会给出这样的回答（**这里是学习案例，具体可以自行用DeepSeek进行测试**）

> 整理会议纪要，通常可以从以下几个方面入手

> 1.  **会议基本信息：** 会议主题、时间、地点、参会人员等。
> 
> 2.  **会议核心议题：** 本次会议讨论的主要问题是什么？
> 
> 3.  **决策事项：** 会议上达成了哪些共识或决定？
> 
> 4.  **待办事项：** 会议后需要跟进的任务有哪些？谁负责？截止时间？
> 
> 5.  **风险预警：** 会议中是否提到了潜在的风险或问题？
> 
> 6.  **其他重要信息：** 会议中是否有其他值得记录的内容？

你可以根据会议的具体情况，选择合适的方面进行整理。”

**第二步：降维细化（根据AI的建议，结合实际情况，构建自己的提示词）**

经过升维提问，我们已经有了一个更全面的框架。

接下来可以根据会议的实际内容，选择合适的维度，构建你的提示词。

比如，这次会议主要讨论了项目的进展和风险，那么你可以这样写：

```Markdown
请根据以下会议记录，整理出一份会议纪要，重点关注：

1.  决策事项：本次会议达成了哪些关于项目推进的决定？
2.  待办事项：为了落实这些决定，需要做哪些事情？谁负责？截止时间？
3.  风险预警：会议中提到了哪些项目风险？

会议记录：[你的会议记录]
```

**第三步：持续优化（根据AI的反馈，不断调整提示词）**

将提示词输入AI后，如果AI给出的结果不够理想，你可以根据实际情况，继续调整提示词，或者向AI提问，直到得到满意的结果。

**第四步：总结出一套关于会议纪要的通用提示词框架**

如果你觉得第二步中AI给你的框架很好用，你想做成一个通用的会议纪要提示词框架

这时候你可以直接人肉总结出一套适合自己的提示词框架，例如

```Markdown
请根据以下会议记录，整理出一份会议纪要，请按照如下框架总结：

1. 会议基本信息： 会议主题、时间、地点、参会人员等。
2. 会议核心议题： 本次会议讨论的主要问题是什么？
3. 决策事项：本次会议达成了哪些关于项目推进的决定？
4. 待办事项：为了落实这些决定，需要做哪些事情？谁负责？截止时间？
5. 风险预警：会议中提到了哪些项目风险？
6. 会议中是否有其他值得记录的内容？

我的会议文字记录如下：[你的会议记录]
```

当然你也可以让AI帮你总结，但是我不建议，AI已经给了框架，我们可以自己抽象，这样对这件事情的理解更深刻

另外请注意如果使用的是DeepSeek的R1模型，因为R1模型本身就具备推理能力，我们可能并不需要提供框架，单纯的提出让其帮我们整理会议纪要，就能得到不错的结果

这里我想说明：针对不同的模型，提示词的复杂程度可能不同，最主要的还是日常要去用，从中总结出属于自己的对不同模型的认知

# 案例二：如何制定一份健身计划

你想要开始健身，但你是个健身小白，完全不知道该如何制定一份适合自己的健身计划。

直接搜索“健身计划模板”可能得到的结果五花八门，让你更困惑。

这时候，我们继续使用“升维提问，逐级降维”的方法论

**第一步：升维提问（向AI寻求思路）**

不要直接问“给我一份健身计划”，而是这样问AI：

```Markdown
我是一个健身新手，想制定一份适合自己的健身计划。我不确定该考虑哪些因素，你能给我一些建议吗？
```

AI可能会给出这样的回答（**这里是学习案例，具体可以自行用DeepSeek进行测试**）：

> “制定健身计划，你需要考虑以下几个方面：
> 
> 1.  **健身目标：** 你是想增肌、减脂、塑形，还是提高心肺功能？
> 
> 2.  **身体状况：** 你目前的体能水平如何？有没有旧伤或疾病？
> 
> 3.  **时间安排：** 你每周能抽出多少时间来健身？
> 
> 4.  **运动偏好：** 你喜欢什么样的运动方式？有氧、力量、还是其他？
> 
> 5.  **饮食习惯：** 你的饮食习惯如何？是否需要配合健身计划进行调整?
> 
> 了解这些信息后，才能帮你制定更个性化的健身计划。”

**第二步：降维细化（根据AI的建议，结合实际情况，构建自己的提示词）**

现在，你对制定健身计划需要考虑的因素有了更清晰的认识。

接下来，结合你自己的情况，逐步细化问题：

1. **明确你的目标：** 比如，你想减脂，同时稍微增加一点肌肉。
2. **评估你的身体状况：** 比如，你没有运动基础，没有旧伤。
3. **确定你的时间：** 比如，你每周可以抽出3-4天，每次1小时左右。
4. **选择你喜欢的运动：** 比如，你喜欢跑步，也想尝试一些力量训练。

根据这些信息，你可以构建你的提示词：

<callout emoji="💡">
我是一个健身新手，没有运动基础，也没有旧伤。
我的目标是减脂，同时稍微增加一点肌肉。
我每周可以抽出3-4天，每次1小时左右来健身。
我喜欢跑步，也想尝试一些力量训练。
请你帮我制定一份初步的健身计划，包括热身、训练内容、训练强度、以及饮食建议。
</callout>

**第三步：持续优化（根据AI的反馈，不断调整提示词）**

AI可能会给你一个初步的计划，但你可能觉得强度太大，或者有些动作不适合你。没关系，你可以继续和AI沟通：

<callout emoji="💡">
这个计划很好，但是对我来说强度有点大，能不能帮我降低一些强度？
另外，我不喜欢深蹲，有没有其他动作可以替代？
</callout>

AI会根据你的反馈，调整计划，直到你满意为止。

# 总结一个升维提问的模版

从上面两个案例中，我们可以总结出一个非常简单但是实用的升维提问的模版：

<callout emoji="💡">
我要做一件XX事情，但是我没有头绪，你能帮我整理下做这个事情的框架么？
</callout>

# 写在最后

通过这两个例子，我们可以更清楚地看到，“升维提问，逐级降维”是一个非常实用的方法：

1. **遇到问题，不要慌：** 不管是总结会议纪要，还是制定健身计划，当你不知道如何下手时，先冷静下来。
2. **升维提问，寻求思路：** 向AI提一个更“高维度”的问题，让AI帮你打开思路，找到解决问题的框架。
3. **降维细化，构建提示词：** 根据AI的回答，结合你的实际情况，逐步细化问题，构建你的专属提示词。
4. **持续优化，获得满意结果：** 根据AI的反馈，不断调整提示词，直到得到满意的结果。
5. **总结通用提示词框架**：根据上述四步，总结出一个在这个场景下适合自己的提示词框架，以后直接调用

这节课是我最想给你讲清楚的内容，因为这是我一直在使用的提示词方法论，我希望你慢慢可以忘掉那些提示词模版，通过和AI沟通来针对问题进行一步步的拆解，最后达到满意的效果
