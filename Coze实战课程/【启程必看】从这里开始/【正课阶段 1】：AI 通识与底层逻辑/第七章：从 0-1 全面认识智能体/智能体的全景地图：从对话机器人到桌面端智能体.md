# 智能体的全景地图：从对话机器人到桌面端智能体

> 【启程必看】从这里开始 › 【正课阶段 1】：AI 通识与底层逻辑 › 第七章：从 0-1 全面认识智能体

# 写在前面

你好，我是大圣

前面几节课，你已经知道了智能体是什么、见过了最简单的两种形态：提示词智能体和AI搜索

但智能体有很多种形态，比如你可能听过Coze、Manus、Claude Code、小龙虾等等

感觉每个都不一样，却又说不清楚区别在哪，这节课，我带你把所有形态一次看清楚

**我希望你可以永远记住一句话：形态在变，本质没变**

所有的智能体，底层都是我们前面讲的那个公式，不同的只是：它在哪里运行、你用什么方式跟它交互

智能体的整个发展路径可以从两个维度来衡量

<callout emoji="✨">
第一个维度：人和AI的分工；**从你控制的越多，到AI自主的越多**
第二个维度：AI能做的事情；**从简单的生成内容，到可以处理你本地的文件，甚至操控你的浏览器**
</callout>

接下来给大家分享智能体发展的5个形态

# 一、形态一：对话式的ChatBot

代表产品：豆包、Kimi、ChatGPT、秘塔搜索

这是你最熟悉的形态，也是AI出现的最基本的形态

你问它一个问题，它回你一个答案

# 二、形态二：工作流式智能体

<callout emoji="✨">
**在2024年2月份左右**，字节跳动的扣子智能体爆火
以至于在很长的一段时间里面，大家谈到智能体就是以扣子工作流为代表的形态
</callout>

代表产品：扣子工作流、Dify

这种形态，你提前设计好流程，它按步骤走

打个比方：你在车间里画好了一条流水线：第一道工序做什么、第二道做什么、第三道做什么

工人按照流水线走就行了，工作流智能体就是这样

**它适合什么：** 固定的、重复的自动化流程。比如：每天早上采集新闻 → 用AI总结 → 推送到飞书

**它的局限：** 需要懂业务的人去搭建，而且搭建复杂的工作流仍然需要代码逻辑

# 三、形态三：云端自主规划式智能体

代表产品：**Manus、现在的扣子**

在以扣子工作流为代表的智能体形态火了一年之后，2025年4月份左右，一款叫做Manus的产品上线

这是一款划时代意义的产品，因为它设计了一种新的形态，叫做**自主规划的智能体**

它不需要自己搭建工作流，你只需要说出你的目标，它自己决定怎么完成

更具划时代意义的是，为了让这个智能体更好地完成任务，它为其配备了一个云端的电脑

这个智能体可以操控这个云端的电脑去生成文件、写代码脚本、访问浏览器，比如登录你的小红书，你的抖音去帮你抓取数据

Manus地址：https://manus.im/app

扣子的地址：https://www.coze.cn

# 四、形态四：本地自主规划智能体（命令行）

代表产品：Claude Code、Kimi Code、WorkBuddy

**云端自主式有一个硬伤：它在云端，够不到你电脑里的文件**

而我们大多数人的工作都是在本地电脑这个载体上去完成的，你的PPT，你的word，你的项目文档都存在你的电脑上的文件夹里

所以这种形态的智能体可以装在我们的电脑上，来处理我们本地的文件，极大地提高我们的生产效率

---

从历史演进的角度，其代表产品是国外Anthropic公司的Claude Code，拥有全球最顶级模型Claude的公司

但Claude Code它的交互形式是命令行，对普通人没有那么友好的一种交互

后来国内也开始跟进，比如kimi的Kimi Code（也是命令行的交互方式）

Kimi Code地址（需要付费才能使用）：https://www.kimi.com/code
