# 写在前面

大家好，我是大圣，前面我已经全面的认识了大模型，这节课我给大家讲解下大模型的优势和缺陷

在开始这篇文章之前，我想给大家提到一个词：人机协作

为什么是人机协作，而不是大模型全自动，或者是AI一键生成，因为AI有其独特的优势和缺陷

我们要学会用AI的长处弥补我们的短板

# AI的主要优势

## **闪电处理速度**

- **表现**：0.5秒内读完一本书，3分钟写出一篇论文草稿
- **原理**：3000亿个神经元的并行计算，相当于百万个人同时翻书查找
- **案例**：律师用它10分钟分析完500页合同中的风险条款

## **知识广度碾压**

- **容量**：存储超过人类个体1000倍的知识量
- **跨界**：从量子物理到菜谱改良，从莎士比亚到网络流行语无缝切换
- **局限突破**：偏远地区医生用它获取最新医学论文摘要

## **创意组合创新**

- 跨界混搭：用「莫奈画风+赛博朋克」描述落日
- 语言魔术：把《论语》翻译成街头说唱歌词
- 模式预测：通过历史数据生成未来城市交通优化方案

## **永续工作模式**

- 无疲劳：连续生成10万字不降低质量
- 无情绪：面对谩骂仍保持专业输出
- 无遗忘：随时精准调取冷门知识（如19世纪伦敦面包价格）

# AI的局限性

## **幻觉制造机**

<callout emoji="💡">
**AI因为是概率预测的工作方式，因此他的答案是概率预测，而不是既定事实**
**假设网络上的谣言重复了百万次，那么大模型就会认为这是正确答案**
</callout>

- **典型错误**：伪造名人名言、编造不存在的历史事件
- **致命场景**：医疗咨询时误将「青霉素过敏」写成「推荐用药」
- **根源**：**概率预测的工作方式，把「高频文字组合」误认为事实**

## 时效性限制

<callout emoji="💡">
**AI的知识是在特定时间点训练的，不会自动更新。**
</callout>

**案例**：

```SAS
如果AI的训练数据截止到2022年.

那么它无法知道2023年的新电影、新产品或新闻事件。
```

## **固化偏见放大器**

- 性别歧视：默认「护士=女性」「工程师=男性」
- 文化偏见：用西方中心视角解读东方历史
- 数据污染：传播已过时的科学理论

## 推理能力有限

<callout emoji="💡">
**面对需要深度推理的问题，AI可能会出现逻辑错误。**
**你记住一句话：大模型不擅长做数学题**
</callout>

**案例**：

```SAS
问："如果张三比李四大，李四比王五大，那么张三和王五的年龄关系是？"

AI可能会犹豫或给出错误答案，因为这需要多步推理。
```

## 深层次含义理解局限

<callout emoji="💡">
**AI可能抓不住对话中的深层含义和情感变化。**
</callout>

**案例**：

```SAS
用户："今天真是个好天气啊"（实际下着大雨，带有讽刺意味）

AI可能会理解为字面意思，回复："是啊，好天气适合出门散步"
```

## 上下文长度限制

<callout emoji="💡">
**AI模型能处理的文本长度是有限的，超过限制的内容会被截断或遗忘。**
</callout>

就好比两个人聊天，随着时间的推移，如果不做任何笔记，双方可能都会忘记前面聊的内容了

**案例**：

```SAS
场景一：长文档处理

用户：[粘贴了一个100页的文档]

"帮我总结一下这个文档的内容"

AI：由于token限制，只能处理文档的前面部分，后面的内容会被忽略。
```

```SAS
场景二：长对话历史

在一个持续了很久的对话中：

用户："还记得我们一开始讨论的那个问题吗？"

AI：可能已经"遗忘"了对话开始时的内容，因为它超出了上下文窗口范围。
```

# 如何更好地使用AI

了解了这些特点和局限，我们在使用AI时就要注意：

1. 给出明确、具体的指令
2. 提供必要的背景信息
3. 对重要信息做交叉验证
4. 复杂问题要分步骤提问
5. 保持适度的怀疑态度
