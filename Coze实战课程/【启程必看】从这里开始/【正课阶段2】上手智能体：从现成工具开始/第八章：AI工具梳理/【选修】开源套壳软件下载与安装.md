# 一、开源套壳的原理

无论是正规的第三方套壳软件，还是开源的套壳，它的工作原理基本都是一致的

你可以认为他们唯一的区别在于：这个API是自己接，还是别人帮你接好

- 你自己接：那就需要了解一些技术细节，但是你可以按量付费
- 别人帮你接好：你可以无脑使用，但是你要遵循人家的付费规则

## 2）创建 API密钥

什么是 API密钥？

我们前面讲到厂商通过 API对外提供服务，从而按量进行收费

API密钥就是一个钥匙，你只有通过这个钥匙才能访问厂商的 API服务，同时他也是一个身份标识，厂商要通过这个身份标识来对你的访问进行统计和计费

**所以：API密钥千万不能泄露，否则会被被人盗用**

---

接下来，点击「API 密钥」---「新建 API 密钥」---「新建密钥」之后，就创建了一个 API 密钥
