## 代码模版

```Python
async def main(args):
    params = args.params
    ret = {
        "records": [{
            "fields": {
                "标题": {"text": params["title"],"link": params["url"]},
                "作者": params["author"],
                "来源": params["platform"],
                "状态": "未读",
                "摘要": params["summary"],
                "标签": params["tags"]
            }
        }]
    }
    return ret
```
