# 不要系统性学习语法

对于学习编程而言，千万不要上来就买一本语法书，然后从头开始学。这样毫无意义

就跟我们小时背英语单词一样，每次都从abandon开始，却总是背不到最后

在AI时代学习编程，我们可以按照如下流程

1. 选定一门编程语言（每个编程语言的底层逻辑是相通的，不用纠结）
2. 花费3个小时左右对编程以及这门编程语言有个基本的了解
3. 直接在需求中学习，也就是练中学，学习的过程中有任何问题直接问AI

# 我推荐的学习流程

1. 选定一门学习语言：**Python**
2. 找到一门关于Python的入门教程：**B站3小时Python入门课程**
3. 在练习中学习：**直接通过Coze的代码节点作为切入点开始学习**
