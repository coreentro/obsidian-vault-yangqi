## 示例

### 输入

```
输入参数：
- url: 网页地址 (string)
- keywords: 要搜索的关键词列表 (list[string])

输出参数：
- matched_texts: 包含关键词的文本片段列表 (list[string])
- total_count: 匹配到的总数量 (integer)

功能描述：
创建一个网页内容关键词搜索插件，获取指定网页内容，搜索给定关键词，并返回包含这些关键词的文本片段。
```

### 输出

```python
from runtime import Args
from typing import TypedDict, List
import requests
from bs4 import BeautifulSoup
import re

class Input(TypedDict):
    url: str
    keywords: List[str]

class Output(TypedDict):
    matched_texts: List[str]
    total_count: int

def handler(args: Args[Input]) -> Output:
    """
    网页内容关键词搜索插件
    
    Args:
        args: 包含输入参数的Args对象
        args.input.url: 要搜索的网页URL
        args.input.keywords: 要搜索的关键词列表
        
    Returns:
        Output: 包含匹配文本片段和总数量的结果
        
    Raises:
        requests.RequestException: 网页请求失败时抛出
        Exception: 其他处理异常
    """
    try:
        # 正确的参数访问方式
        url = args.input.url
        keywords = args.input.keywords
        
        # 获取网页内容
        response = requests.get(url)
        response.raise_for_status()
        
        # 解析HTML
        soup = BeautifulSoup(response.text, 'html.parser')
        text_content = soup.get_text()
        
        # 搜索关键词
        matched_texts = []
        for keyword in keywords:
            pattern = f'.{{0,30}}{re.escape(keyword)}.{{0,30}}'
            matches = re.finditer(pattern, text_content)
            matched_texts.extend([match.group() for match in matches])
        
        return {
            "matched_texts": matched_texts,
            "total_count": len(matched_texts)
        }
        
    except requests.RequestException as e:
        args.logger.error(f"网页请求失败: {str(e)}")
        raise
    except Exception as e:
        args.logger.error(f"处理失败: {str(e)}")
        raise
```
