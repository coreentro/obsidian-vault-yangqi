# 什么是问答节点？

问答节点是Coze工作流中的一个重要功能，它能让你的智能体主动收集用户信息，实现更自然的人机对话。

就像一个细心的服务员，通过提问来了解顾客需求。

我们直接通过案例来进行学习

# 两种问答方式

## 直接回答模式

**特点**：让用户自由发挥，用自然语言回答问题

- 优势：**用户表达更自由**
- 应用场景：收集详细信息，如用户反馈、个人信息等
- 工作原理：智能体会自动从用户回答中提取关键信息

🌟 **示例**：

```Diff
智能体：请问您的公司名称、联系人和联系方式是？
用户：我是小明，在ABC科技工作，电话13800138000
智能体：[自动提取] 
- 公司：ABC科技
- 联系人：小明
- 电话：13800138000
```

## 选项回答模式

**特点**：提供预设选项供用户选择

- 优势：**引导性强，用户操作简单**
- 应用场景：功能选择、意图分类等
- 展示方式：不同平台展示形式可能不同
