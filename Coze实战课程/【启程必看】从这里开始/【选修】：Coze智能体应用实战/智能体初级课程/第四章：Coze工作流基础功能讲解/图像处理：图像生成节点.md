# 什么是图像生成节点

图像生成节点是Coze平台提供的一个专门用于AI绘画的功能模块。

它可以：

- 将文字描述转换为图片（文生图）
- 基于参考图生成新的图片（图生图）

## 参考图设置（可选）

如果需要基于已有图片生成，可以配置：

- 📌 参考模式：支持画面布局、人物姿势等多种参考方式
- 🖼️ 参考图片：可上传图片或引用其他节点的输出
- 📊 参考程度：控制新生成图片与参考图的相似度

## 提示词设置

提示词分为两类：

**正向提示词**（必填）：

- **描述你想要在图中看到的内容**
- 例如：`1girl, necklace, jewelry, best quality`
- 可以引用变量：`{{变量名}}`

**负向提示词**（选填）：

- **描述你不想在图中出现的内容**
- 例如：`watermark, long neck, missing fingers`
- **系统已预设常见负向词，一般来说，我们不用动这块**
