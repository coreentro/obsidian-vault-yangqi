# 写在前面

大家好，我是大圣

这节课我们制作一个可以根据单词生成英语学习的卡片

PS：这个案例是我购买的一个模版，用来给大家进行教学，这个案例是那个完整模版的一部分

这个案例可以让我们学习

1. 如何使用大模型将一个单词进行全面的拆解
2. 使用插件将文本内容转换成语音
3. 使用插件将语音的地址转换成二维码
4. 使用图像生成节点针对单词生成图片并且进行抠图
5. 工作流如何嵌套进行调用
6. 使用画版功能生成最终的卡片

案例名称：**大圣教学｜初阶｜制作单词闪卡**

# 需求分析

这个智能体的输入是一个中文单词：例如树叶

输出是一张卡片：

![图片\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\]\[\] addCriterion图片展示的是一个单词闪卡。上方是一片绿色的枫叶，下方用蓝色字体显示单词“leaf”，其下方是其中文翻译“树叶”。再下方是英文示例“The leaves turn yellow in autumn.”及中文示例“秋天树叶变黄了”。图片右下角有一个二维码。该图片是文档中“需求分析”部分提到的输出卡片示例，展示了根据输入单词生成的卡片样式，包含图片、单词、翻译、示例及二维码等关键信息。](https://feishu.cn/file/W3N5bV8VzodTuUxifQRcKqcfnxc)

其中可以扫描二维码进行阅读

这个需求可以分成两个流程

1. 第一个流程：

   1. 根据输入的单词扩展出如下内容（**这一块要使用到大模型的能力**）
   
      ```Plain Text
       "word": "英文单词",
       "phonetic": "国际音标",
       "translation": "中文释义",
       "pos": "词性",
       "etymology": "词源简介",
       "example_en": "实用英文例句",
       "example_zh": "对应中文翻译",
       "description": "词义解释与用法说明",
       "pronunciation_tips": "发音要点与技巧",
       "cultural_notes": "相关文化知识"
      ```
   2. 根据发音要点和技巧的文字，生成语音并且生成二维码
   3. 将内容输入给**第二个流程**，生成最终的卡片
   4. 将卡片展示给用户

1. 第二个流程

   1. 针对单词生成一张白底图
   2. 将图片 + 单词 + 中文翻译 + 英文示例 + 中文示例 + 二维码 组合成一张图片
