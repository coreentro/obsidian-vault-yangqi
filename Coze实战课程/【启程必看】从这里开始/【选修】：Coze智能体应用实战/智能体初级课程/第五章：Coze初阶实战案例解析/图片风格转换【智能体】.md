# 写在前面

大家好，我是大圣

这节课我们制作一个可以对图片进行转绘并且支持用户自由选择风格的智能体

这个案例可以让我们学习

1. 如何使用选择器根据用户的选择走不同的路径
2. 如何使用图像风格化对照片进行风格转换

案例名称：**大圣教学｜初阶｜图片风格转换**

# 需求分析

这个智能体的输入有两个：

1. 一张待转绘的图片
2. 转绘的风格

我们提供如下几种的转绘风格

```Plain Text
毛毡风
粘土风
积木风
美漫风
玉石风
搞笑涂鸦
工笔画
水彩画
```
