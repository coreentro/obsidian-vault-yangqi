# 写在前面

大家好，我是大圣，这节课我们来讲一下 Coze 平台的注册和登录。

# 一、访问 Coze 官网

首先，Coze 平台的网址是 **www.coze.cn**

我们直接复制这个网址，打开浏览器，在地址栏里输入 **www.coze.cn**，然后按回车键

# 三、登录 / 注册流程

我们点击右上角的「登录」按钮。

选择**手机号登录**，输入你的手机号，点击「获取验证码」

输入验证码后点击登录。

Coze 的登录和注册是一体的：如果你是新用户，系统会自动帮你注册；如果是老用户，就直接登录
