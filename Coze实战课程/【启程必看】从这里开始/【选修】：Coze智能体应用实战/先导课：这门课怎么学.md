# 先导课：这门课怎么学

> [!info] 位置
> 【启程必看】从这里开始 › 【选修】：Coze智能体应用实战

# 写在前面

大家好，我是大圣。欢迎来到Coze智能体实战课

在正式开始学习之前，有几件重要的事，我想先跟你聊清楚。

这些事关系到你怎么学这门课，以及你能从这门课里得到什么

花几分钟看完，会让你后面的学习事半功倍

# 一、为什么要学习Coze

你可能听过很多智能体平台的名字：

扣子、Dify、n8n、元器、千帆……

为什么我选择用扣子来教？原因很简单：

**如果你想系统学习搭建智能体，你需要选一个平台吃透它**

而扣子，是目前最适合的选择

- 功能全，几乎涵盖了智能体搭建的所有核心模块
- 迭代快，你能通过它看到整个行业的演进方向
- 国内用户多，生态成熟，遇到问题容易找到答案

更重要的是：

**通过扣子，你能看到智能体的完整发展路径**

什么是工作流、什么是节点、怎么调用工具、怎么设计流程；这些智能体的底层逻辑，在扣子里都能学到

但我要先说清楚一件事：

**学扣子，不是目的。通过扣子理解智能体、学会搭建智能体，才是目的**

你学会了扣子，换到任何一个平台，都能快速上手

因为底层逻辑是相通的

# 二、这门课怎么学

这门课分为初级、中级、高级三个阶段，几乎涵盖了扣子的所有功能。

听起来内容很多，但我想告诉你一件非常重要的事：

**不要以学完为目的，要以用起来为目的**

很多人学东西有个习惯，一定要从头到尾全部学完，才觉得自己会了。

这个习惯，在学习 Coze智能体这件事情上，行不通

因为你学完了不用，过几天就忘了。而且说实话，你根本不需要全部学完

**学完初级，你就已经比市面上99%的人，对智能体的理解更深了**

学完初级，你就可以：

- 出去讲课
- 在工作中应用
- 甚至可以来接商单赚钱

一定要用输出倒逼输入，我的建议是：**按需学习**

你现在需要什么，就先学什么

**把这门课当成一本百科全书，**你不需要从第一页背到最后一页

你需要的是，遇到问题的时候，知道来这里查。哪里不会查哪里，查完就去用。

这才是最高效的学习方式

# 三、关于 Coze平台更新

还有一件事，我必须提前跟你说清楚：**扣子这个平台，是会变化的**

它会更新功能，会调整界面，会下线一些旧的东西，会上线一些新的东西

这是所有互联网产品的常态，而我们这门课，内容非常庞大。

我没有办法做到扣子每更新一个小功能，我就立刻去重新录一遍；我也没有办法讲到每一个细枝末节

但是：**这门课的骨架，我已经帮你搭好了**

什么是骨架？就是智能体的底层逻辑：

- 工作流是怎么运转的
- 节点之间是怎么连接的
- 工具是怎么被调用的
- 一个完整的智能体是怎么被设计出来的

这些东西，不会因为平台更新就失效。**你理解了底层逻辑，就不会被表面的变化困住**

所以当你遇到一些变化的时候，不要慌。比如：

- 某个模型突然不能用了？没关系，换一个模型就行。
- 某个功能的位置变了？没关系，自己找一找就能找到。
- 某个新功能课程里没讲？没关系，用你学到的底层逻辑去理解它。

**我希望你能在这个骨架的基础上，学会举一反三**

这才是真正的"学会"。

不是我讲什么你会什么，而是我没讲的，你也能自己搞定。
