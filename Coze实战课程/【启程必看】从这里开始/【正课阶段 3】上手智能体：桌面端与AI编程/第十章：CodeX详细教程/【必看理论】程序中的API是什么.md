# 写在前面

你好，我是大圣

这是一节理论知识，我们会讲一个概念，叫做 API

**这个概念对于编程小白而言，是在 AI 时代最重要的概念之一**

因为我们开发的各种应用，很多时候都是在接入各种 API

比如：你要给你的 WorkBuddy 和 Codex 换模型，本质就是接入第三方模型的 API

比如：你想获取公众号、抖音、小红书的数据，最简单的方案就是找到第三方的数据 API

当你掌握了 API 的概念，在叠加上CodeX这类工具，你会发现你的能力边界会被极大地扩展

下面这篇文章，我不仅讲了程序中 API 的理论，并且让你亲手调通 DeepSeek API 的案例来进行实操说明
