# 二、Skill安装的本质

在跟大家分享如何安装 Skill 之前，我们必须先了解一下 Skill 的安装本质

在前面的课程里面，我们详细给大家讲了 Skill 的规范：<cite doc-id="V9pbweJb0iZVFjk5jskcVJPMnQd" file-type="wiki" title="【必看理论篇】面向小白的Skills保姆级教程" type="doc"></cite>

**它的本质其实就是一套文件夹，然后放在约定好的位置**，就可以被 Codex 等桌面端智能体发现

所以 Skill 安装的本质，**就是把那个 Skill 的文件夹下载下来，然后放到你电脑上的某个路径下面**

只是不同的桌面端智能体需要的路径不同而已

**而 Codex 等桌面端智能体天然就可以帮你安装 Skill，因为它的强项就是对你电脑上的文件进行增删改查**

# 三、如何安装Skill

安装 skill 的技巧可以总结为如下这句话：

<callout emoji="✨">
只要你能找到这个 skill 的源文件，无论是网页地址还是压缩包
丢给你的桌面端智能体，它就能帮你安装好
</callout>
