# 一、当前产品格局

命令行智能体这个品类，起源于 Anthropic 的 Claude Code

后来OpenAI的CodeX、Google 的 Gemini CLI 相继上线。国内目前有 Kimi Code 和阿里的 Qwen Code

但有一个重要插曲：2026 年 3 月 31 日，Claude Code 源码意外泄露

这意味着国内很快会涌现一批命令行智能体产品，格局正在变

# 二、怎么选？看两个东西

还记得前面那张图吗？一个命令行智能体 = 执行架构（身体）+ AI 大脑

> [!abstract]- 🖼 图片展示了命令行智能体的构成。左侧为执行架构（身体），包含终端交互、文件
> 图片展示了命令行智能体的构成。左侧为执行架构（身体），包含终端交互、文件读写、代码执行、工具调用等模块。右侧为AI大脑（可替换），列举了Claude、GPT、Kimi、Gemini/DeepSeek等。中间有API调用箭头，连接执行架构与AI大脑。底部文字说明“工具决定能做什么，大脑决定做得多好”。此图与上下文紧密相关，直观呈现了命令行智能体由执行架构和AI大脑构成，选产品时需关注这两方面。
> 
> 原图未迁移 · [飞书原图](https://feishu.cn/file/NhuXbTpDwoGVg0x8a6OcfSlrnBd) · `NhuXbTpDwoGVg0x8a6OcfSlrnBd`

选产品就看这两样东西够不够强。只有强大脑没有好身体，能想到但做不到。只有好身体没有好大脑，能做但做不好

目前公认最强的身体是 Claude Code，最强的大脑是 Claude 旗舰系列

最优解当然是两者结合：但旗舰模型贵，所以实际使用中你需要按任务灵活切换大脑
