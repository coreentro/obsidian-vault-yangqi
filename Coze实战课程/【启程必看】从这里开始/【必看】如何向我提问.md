# 【必看】如何向我提问

> [!info] 位置
> 【启程必看】从这里开始

大家好，我是大圣

在我们的社群里，我能给你的价值主要是两件事：

**第一，我给你的课程和分享。** 这是我可以控制的，我会持续输出我的思考、我的实践、我踩过的坑。

**第二，回答你的问题。** 这是我们共同完成的。你提问，我回答

**好问题会引出好答案，不好的问题会让我们的沟通效率极低**

一个模糊的问题，我需要反复追问才能搞清楚你到底卡在哪。这不仅浪费你的时间，也浪费我的时间，还会影响群里其他学员的注意力

而一个清晰的问题，我可以直接给你有价值的回答，甚至这个回答可以帮助到群里所有遇到同样问题的人

所以关于提问，我们必须有一个约定

# 一、在哪里提问

**优先在微信群里提问，不要私聊我**

原因很简单：我每天收到的私信非常多，很容易漏掉。但微信群的消息我会定期翻看和集中回复

而且你的问题发在群里，很可能其他同学也遇到了类似的情况，我回答一次就能帮到一群人。这比私聊的效率高太多了

所以除非是涉及个人隐私的问题，**请一律在微信群提问**

# 二、提问之前，请先做一件事

**在向我提问之前，请你先跟AI聊过**

我们是一个AI课程的社群，你手里是有AI工具的

很多问题，你跟AI对话几轮就能解决。如果跟AI聊了之后还是搞不定，那再来问我，这时候你的问题一定比一开始更清晰，因为你已经经历过一轮思考了

但是请不要直接把跟AI对话的截图给我，内容太多了，我看不过来。你应该加上自己的总结，针对性地向我提问

# 三、站在我的角度写你的问题

这是最重要的一条

很多时候问题回答不好，不是因为问题本身难，而是因为**你站在自己的角度在描述，默认我知道你的情况**

但事实是：我不知道你是谁、你在做什么、你到了哪一步、你遇到了什么

**所以提问的时候，请你假设我什么都不知道。** 把背景、你遇到的问题、你已经尝试过的方法，一次性说清楚

你描述得越清楚，花费我的时间越少，我越愿意回答，回答的质量也越高

反过来说，如果你扔过来一句话，我还得反复追问"你具体是什么情况""你试过什么了""你说的是哪个环节"，说实话，这种来回很消耗人的精力

# 四、提供充足的上下文

描述问题不要只靠文字，根据情况选择最合适的方式：

**文字：** 最基础的方式。把你的背景、遇到的问题、已经尝试过的方法写清楚

**截图：** 如果是界面操作、报错信息、某个具体的场景，截图比文字清楚一万倍。一张图胜过你打一百个字

**飞书录屏：** 如果问题比较复杂，文字和截图都说不清楚，录一段视频

边操作边说，把你卡住的地方演示出来。这对我来说非常友好，我能快速定位你的问题在哪

**微信群一定要保护大家的注意力**，你如果一股脑扔来10张图片或者一堆文字，我有权利让你去撤回

# 五、举个例子

❌ **不好的问题：**

```Plain Text
大圣，扣子工作流跑不通，怎么办？
```

我看到这种问题，真的不知道从何答起。

你做的是什么工作流？跑到哪一步出了问题？报错信息是什么？你试过什么方法？我完全不知道

✅ **好的问题：**

```Plain Text
大圣，我在搭一个扣子工作流，功能是自动总结微信群聊记录然后发到飞书

我按照课程第12节的步骤做了，前面的节点都正常，但跑到"大模型"这个节点的时候报错了

报错信息是"输入参数格式不正确"（见截图）

我已经问过AI了，AI让我检查变量引用格式，我检查了看着没问题

具体的配置我放在这个飞书文档里了：[链接]

能帮我看看是哪里出了问题吗？
```

你看，第二种问题我扫一眼就知道你卡在哪，可能30秒就能给你答案

# 六、写在最后

我知道问出好问题本身就是一项需要锻炼的能力，不是每个人一开始都能做到的

**所以大家不要有压力，请大胆提问。** 我不会因为你的问题不够好就不回答你

只是我希望你知道：你花在组织问题上的那几分钟时间，会帮我省下大量的沟通成本。

你的问题越聚焦、描述越清楚，我就越能快速地、高质量地帮到你

**我们珍惜彼此的时间，这个社群才能越来越好**
