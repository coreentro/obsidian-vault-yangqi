<callout emoji="📄"><h2><b>总结</b></h2><p>会议讨论了机器人搭建与使用等问题。主要内容包括：</p><ul><li><b>机器人搭建与使用问题讨论</b>：讨论了机器人搭建过程中遇到的问题以及解决方法，包括宝塔登录、管理员认证、机器人回复等问题。</li><li><b>如何替换机器人配置文件</b>：讨论了如何替换机器人配置文件，包括替换的步骤和注意事项。</li><li><b>如何使用 AI 机器人</b>：讨论了如何使用 AI 机器人，包括创建机器人、获取 d 和 ID、添加插件等步骤。</li><li><b>如何使用 AI 绘画机器人</b>：讨论了如何使用 AI 绘画机器人，包括创建 bot、发布 API、添加插件和图像流等操作。</li><li><b>如何使用配置文件和插件来优化机器人的输出效果</b><ul><li><b>使用配置文件和插件优化机器人输出效果</b>：可以使用 JSON 结尾的配置文件和 py 结尾的配置文件来优化机器人的输出效果，同时可以添加文生图、退运万象等插件。</li><li><b>控制机器人私聊和群聊</b>：可以通过配置文件控制机器人的私聊和群聊，也可以在私聊中输入 stop 让机器人停止回复。</li><li><b>下堂课讲解如何让机器人换行输出</b>：由于没有准备换行输出的文件，所以下堂课再进行讲解。</li></ul></li><li><b>如何使用 AI 工具生成图像</b><ul><li><b>提示词优化</b>：可以使用优化按钮自动优化提示词，也可以手动输入。在知识库的 prompt 板块中有相关技巧。</li><li><b>工作流搭建</b>：工作流的搭建需要使用到 control net 和图像生成功能。可以参考 5 月 23 日的直播回放进行学习。</li><li><b>图像流功能使用</b>：图像流功能可以用于生成海报，需要先上传底图，然后进行提示词优化和画质提升，最后添加微推的 logo。可以参考 cost 的教程和近期比赛中的直播回放。</li><li><b>微信机器人自动拉群</b>：微信机器人可以自动拉群，需要先扫码添加机器人，然后机器人会自动把人拉进群。可以参考机器人插件拓展教学中的内容。</li></ul></li><li><b>关于如何使用大语言模型创建聊天机器人的讨论</b><ul><li><b>创建聊天机器人的方法</b>：可以使用大语言模型创建聊天机器人，需要设置人设和知识库，可以通过 prompt 来实现。知识库可以通过 agent 板块来查看和编辑。还可以使用别人的 bot ID 来扮演不同角色进行聊天。需要注意避免违规操作，以免被封号。</li><li><b>机器人聊天的有趣玩法</b>：可以编写剧本让机器人扮演不同角色进行聊天，如让机器人扮演虚拟男友、虚拟女友等。还可以让机器人进行对话，如曾小贤按下按钮后穿越到了唐朝街道等。可以在微信公众号上发布机器人聊天内容，需要先进行配置。可以使用 GPS 链来查看更多的人数和提示词。可以使用 cost 或 PPT 来让机器人解释 prompt。可以使用 configure POI 文件来设置群聊欢迎语。</li><li><b>避免违规操作</b>：不要说太多奇怪的话，以免被举报封号。不要进行违规操作，如使用机器人进行销售等。可以在法律法规范围内合理使用机器人。</li><li><b>知识库的使用</b>：知识库可以通过 agent 板块来查看和编辑。可以在 prompt 中加入知识库内容，也可以在长期记忆或知识库中加入内容。可以使用别人的 bot ID 来获取知识库内容。需要注意不同大语言模型的知识库可能不同，需要进行测试。</li><li><b>机器人聊天的注意事项</b>：需要注意上下文轮数和长度，以免机器人回答错误。可以设置 at bot 来指定机器人获取微信名字。需要先进行认证，然后才能使用插件功能。认证可以防止其他人随意与机器人聊天。可以使用 auth 密码进行认证。</li></ul></li><li><b>微信机器人的使用问题</b><ul><li><b>图片链接无法使用问题</b>：复制链接时要去掉括号，否则会识别为无效链接。</li><li><b>key 未通问题</b>：key 没通可能是因为机器人提示“暂时遇到了一些问题，请您稍后重试”，需要检查左边是否有红色叉叉。</li><li><b>报错找不到 APP 点 py 文件问题</b>：报错原因可能是执行错误或配置项出错，需要按要求重新配置。可以检查一下是否漏配，也可以重新执行一遍。</li><li><b>建立过程中掉线问题</b>：在登录时掉线可能是因为异地保护，24 小时后会恢复正常，7 天后将不再有异地保护。也有可能是因为星号或异地。如果是星号，重新登录即可；如果是异地，过 24 小时或 7 天再登录。</li><li><b>二维码无反应问题</b>：二维码无反应可能是因为配置文件出错，需要检查之前的步骤或重新确认配置。也有可能是插件有问题，需要重新复制第十八步的内容。</li></ul></li><li><b>直播结束</b>：本次直播接近尾声，主播感谢大家的参与，并宣布下期直播时间为下周日（3 月 23 日）。</li><li><b>加群方式</b>：可扫描二维码加入新群，群满后可添加梦飞微信，由梦飞拉进群。</li><li><b>定时提醒功能</b>：后续会推出定时插件，插件可以实现定时发送提醒的功能。</li><li><b>会议链接</b>：直播链接固定，可将链接添加至日历，日历会进行通知提醒。</li><li><b>其他问题</b>：有问题可在群内沟通。</li></ul><h2><b>待办</b></h2><checkbox
