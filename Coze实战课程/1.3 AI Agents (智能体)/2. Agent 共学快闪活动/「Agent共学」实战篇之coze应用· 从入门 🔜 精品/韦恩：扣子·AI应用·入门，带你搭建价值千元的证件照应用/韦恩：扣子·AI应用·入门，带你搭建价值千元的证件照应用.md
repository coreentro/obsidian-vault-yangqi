# 三、什么是扣子AI应用？为什么有这个？

### **Before：**

我们最先接触的智能体是ChatBot，这种智能体只有一个对话框，很多复杂的操作展示都难以实现。

在扣子AI应用出来前有没有AI应用，答案是肯定的，那是通过对接各个厂商的智能体平台API、大模型API等，结合软件开发，实现AI应用的搭建和交付使用。

### **Now：**

**扣子AI应用解决了什么问题？**

解决的核心问题是***低代码&零代码怎么搭建复杂的AI应用***，***怎么让人与AI的交互体验更佳***

我作为一个十多年的软件开发人员，从产品需求到产品上线迭代都跑通过很多次的人的体验来讲，现在的AI Coding对简单的、常见的小场景、要求不那么严格的应用或游戏，效果是很好的，而对于企业级的应用和开发，可以做部分辅助，尤其是企业有固定框架时，AI Coding的应用就更不显得那么得心应手了。

前几天，有几个朋友说，使用AI Coding开发的应用，第一版做得还行，当他想进一步迭代第二个第三个版本的时候，经常改出一个效果，改出多个bug，甚至整个项目都面目全非。如果是相对简单的逻辑，使用扣子平台的Project IDE应用来搭建，整体体验还是比较可控的。

大家对AI应用的呼声很高，原因是大家想变现，离用户和&客户**近一点、再近一点**

并不是每个人都有一个软件研发团队base在那里，现在的AI应用也不是一个完全体，官方仍在快速迭代中。

**背景**：最近发生的事，我决定开始做这个AI应用

**原流程**：一张图用ps需要操作3轮，且需要ps技术，且一次就是3次5分钟，（10人需要150min）

**现流程**：一人3图仅需30秒，这个应用即使只服务10人 ，仅需5分钟，
