**自学**：这个活动希望通过文字资料+直播分享的方式带领大家了解Coze这款工具，但是主要还是要靠自学

**交流：**找一些Coze的玩家跟大家视频会议交流自己的入门和进阶心得

## 答疑

**关于答疑：**

答疑会分为线下答疑和线上答疑两个环节

### 线下答疑

线下答疑的方式很简单，大家有任何问题可以抛到飞书群，大家可以互助。共性的一些问题会被记录到问题收集板，集中进行线上答疑

### 线上答疑

在**5月9号**和**5月11号**会有两场线上答疑，但是由于参与人可能会比较多，所以答疑的方式如下：

- 线下收集的问题，会放到问题反馈板中，针对比较共性的问题进行直播答疑
- 为了提高答疑效率，**线上答疑环节不现场收集问题**
