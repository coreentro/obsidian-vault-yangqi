## 接口介绍

| **类型** | 说明 |
| --- | --- |
| **请求地址** | wss://open.bigmodel.cn/api/paas/ws/chat |
| **传输协议** | 采用WebSocket协议：WebSocket协议是单个TCP连接上进行全双工通讯的协议。客户端和服务端可以建立持久性的连接，并进行双向数据传输。WebSocket协议广泛应用于需要实时互动的应用。 |
| **消息格式** | 传输的数据可以是文本格式，也可以是二进制格式。 |
| **请求鉴权** | 客户端：使用JWT进行客户端鉴权，客户端生成JWT并在WebSocket建联时通过Header传输。服务端：使用平台的API Key作鉴权信息 |
| **接口功能** | **多模态输入**：模型支持视频、图片和音频输入，支持文本和音频输出。**VAD（声音活动检测）**：模型默认支持VAD，也支持由客户端识别VAD并控制。**对话打断**：模型对话支持被打断，打断时会返回 interrupt 控制消息。**历史会话**：所有会话历史保存在一次WebSocket会话中。 |

## 使用说明

### 请求鉴权方式：

1) **客户端发起访问**: 使用JWT进行客户端鉴权，客户端生成JWT并在WebSocket建联时通过Header传输。

参考代码示例：

Java：

```Java
package com.wd.paas.test;

import com.auth0.jwt.JWT;
import com.auth0.jwt.algorithms.Algorithm;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.SignatureAlgorithm;

import java.util.Calendar;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

public class TestToken {
    // 根据传入的apikey和expireMillis过期时间来生成JWT
    private static String generateToken(String apiKey, Long expireMillis) {
        // 通过 . 分隔，提取出 api_key 和 api_secret。
        // 其中 api_secret 是用来进行 HMAC-SHA256 签名的密钥。
        String[] apiKeyInfo = apiKey.split("\\.");
        String api_key = apiKeyInfo[0];
        String api_secret = apiKeyInfo[1];
        
        // exp：计算令牌的过期时间。当前时间的秒数加上 expireMillis，决定 JWT 的有效期。
        long exp = (new Date().getTime() / 1000) + expireMillis;
        long timestamp = new Date().getTime();
        
        // payload（有效载荷）：api_key、exp、timestamp 是 JWT 的载荷，存储了令牌的元信息。
        Map<String, Object> payload = new HashMap<>();
        payload.put("api_key", api_key);
        payload.put("exp", exp);
        payload.put("timestamp", timestamp);
        
        // headerClaims（头部）：指定使用的算法（HS256）以及签名类型。
        Map<String, Object> headerClaims = new HashMap<>();
        headerClaims.put("alg", "HS256");
        headerClaims.put("sign_type", "SIGN");
        
        String token = null;
        // 使用 JWT.create() 生成一个 JWT，并且用 api_secret 和 HMAC256 算法对 JWT 进行签名。
        try {
            token =
                    JWT.create()
                            .withPayload(payload)
                            .withHeader(headerClaims)
                            .sign(Algorithm.HMAC256(api_secret.getBytes("utf-8")));
        } catch (Exception e) {
            e.printStackTrace();
        }
        return token;
    }

    public static void main(String[] args) {
        try {
            // 此处填入bigmodel.cn网站上的apikey
            String apiKey = "替换成你的apikey";
            String token = generateToken(apiKey, 600L);
            System.out.println(token);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

2)**服务端发起访问：**如果您的应用先访问您的服务端，再从服务端发起调用模型 API，服务端可以直接使用 API Key进行鉴权。具体使用方式如下：

1. 平台颁发的 API Key 同时包含 “用户标识 id” 和 “签名密钥 secret”，即为 `{id}.{secret}`格式。

参考代码示例：

python：

```Python
import websockets

async def client():
    # 将令牌作为查询参数添加到WebSocket的URI中
    uri = f"wss://open.bigmodel.cn/api/paas/ws/chat"
    # 通过 extra_headers 添加认证。
    extra_headers = {
        "Authorization": "Bearer {0}".format("替换成你的apikey")
    }
    # 通过 WebSocket 连接到服务器，并使用携带 Bearer 鉴权apikey 的 extra_headers 进行认证。
    async with websockets.connect(uri,extra_headers=extra_headers) as websocket:

        response = await websocket.recv()
        print(f"服务器响应: {response}")
```

**3）注意:🤖🤖🤖**

使用客户端鉴权时，在HTTP头部填充的是【Authorization: 鉴权token】；使用服务端鉴权时，在HTTP头部填充的是【Authorization: Bearer 鉴权apikey】，需要注意是否含有Bearer字符串。

### VAD检测：

**1）服务端VAD检测：**

- 参数设置：server_vad 为 True 时，模型会提供服务端的VAD检测
- 适用场景：主要是实时的语音或者视频通话。
- 客户端操作：您的客户端只需要发送音视频数据。
- 交互流程：

  - 请求中chunk_type设置为append
  - 当静音时间超过结束时间 finish_time，模型服务端则判断为音频结束输入，并启动模型响应。

**2）客户端VAD检测：**

- 参数设置：server_vad 为 False 时，客户端来实现结束逻辑。
- 适用场景：客户端提供长按拍摄或录音，用户上传视频文件等功能。
- 处理逻辑：在客户端操作结束，音视频文件传输完成，就可以开始模型推理。
- 交互流程：

  1. 完整音视频一次性发送：（音视频编码后发送一次请求）
  
     - chunk_type设置为finish
  2. 分批次追加发送：（比如，边录音边发送请求）
  
     - 最后一次请求chunk_type设置为finish

```Python
    ]
```

```JavaScript
    async with websockets.connect(uri, extra_headers=extra_headers) as websocket:
        response = await websocket.recv()
        print(f"{datetime.datetime.now()}: 服务器初始化响应: {response}")

        # 设置视频捕获
        video_cap = cv2.VideoCapture(video_path)
        frame_count = 25  # 每次发送 25 帧

        # 读取 .pcm 音频文件数据
        with open(audio_path, 'rb') as pcm_file:

        n = 1
        offset = 0

            print(f"循环的第{n}次")

            frames = []
            remaining_frames = frame_count
            while remaining_frames > 0:
                ret, frame = video_cap.read()
                if not ret:
                    break
                frame = cv2.resize(frame, (1550, 720))
                frames.append(frame)
                remaining_frames -= 1

            audio_chunk = pcm_data[offset:offset + 48000 * 2]  # 48kHz, 16-bit mono PCM, 1 second

            if not audio_chunk:  # 检查是否已读取完所有音频
                break

                    "audio_config": {"encoding": "pcm", "voice_type": "NORMAL_FEMALE", "speed_ratio": 1.00}
                }
            }
            print(f"{datetime.datetime.now()}: 第{n}次追加请求------------------\n")
            await websocket.send(json.dumps(append_message))

            # # 删除临时视频文件
            # os.remove(temp_video_path)

        finish_message["chunk_type"] = "finish"

        await websocket.send(json.dumps(finish_message))

        video_cap.release()
```

### WebRTC

#### 什么是WebRTC？

WebRTC（网页实时通信）是一个可以用在视频聊天、音频聊天或 P2P 文件分享等 Web 应用中的 API。 

#### web端基础常用相关API

#####  getUserMedia

- getUserMedia是什么？

getUserMedia 是 WebRTC API 中用于访问用户音视频设备的接口，包括摄像头和麦克风。无论是通过 USB 连接的设备还是虚拟设备，都可以通过这个 API 进行访问。

- 如何使用 getUserMedia？

在简单场景下，直接调用 getUserMedia 的默认参数即可获取 PC 的默认摄像头和麦克风。然而，在处理复杂场景时，例如选择特定的设备，可以按以下步骤操作：

1. 列出所有可用的媒体设备：获取设备列表以便选择。
2. 选择所需的设备：从设备列表中选择适合的摄像头和麦克风。
3. 配置并传递设备信息：将所选设备的信息传递给浏览器 API 以进行设置。

```Plain Text
// 1. 列出所有可用的媒体设备
navigator.mediaDevices.enumerateDevices()
  .then(devices => {
    devices.forEach(device => {
      console.log(device.kind, device.label, device.deviceId);
    });

    // 2. 根据用户选择的 deviceId 请求媒体流
    const constraints = {

    };

    // 将媒体流绑定到视频或音频元素上

  })
  .catch(error => {
    console.error('媒体设备访问失败:', error);
  });

```

##### getDisplayMedia

- getDisplayMedia 是什么？

getDisplayMedia API 用于在浏览器中实现屏幕分享功能。它允许用户选择并分享整个屏幕或特定应用窗口，适用于远程会议和在线演示等场景。

- 如何使用 getDisplayMedia？

调用 getDisplayMedia 获取屏幕分享的媒体流。此 API 返回一个 Promise，解析值为包含屏幕视频流的 MediaStream 对象。

```Python
async function getShareMedia() {
  // 定义要获取的媒体流的参数，如果分享系统声音，则audio设置为true

  }
  try {
    return await navigator.mediaDevices.getDisplayMedia(constraints);
```

```JavaScript
    // 初始化websocket连接
    initWS() {

      }

        this.wsLog.push(`收到服务器消息：${JSON.stringify(data)}`);
        if (data?.error) {
          this.$message({
            message: data.error.message,
            type: "error",

        if (data.message?.content) {
          this.message.time = getCurrentTimestampFormatted(
            "YYYY-MM-DD HH:mm:ss"

          const connectStr = data.message.content;
          const inited = String("inited");
          const finish = String("finish");
          const interrupt = String("interrupt");

            !inited.includes(connectStr) &&
            !finish.includes(connectStr) &&
            !interrupt.includes(connectStr)
          ) {
            if (this.control.response_type === "audio") {
              this.message.audioContent.push(connectStr);
              this.message.voicePlay = true;
            } else {
              this.message.textContent += connectStr;
            }
          }
          // 返回了结束 且不为空
          if (
            finish.includes(connectStr) &&
            (this.message.textContent || this.message.audioContent.length > 0)
          ) {
            this.serverMessages.push(JSON.parse(JSON.stringify(this.message)));

            this.$nextTick(() => {
              if(this.$refs.refChatBox){
                // 刷新滚动条
                this.$refs.refChatBox.scrollToBottom();
                // 播放音频数据

              }
            })

            this.message.textContent = "";
            this.message.audioContent = [];
          }
        }

      this.ws.onerror = (error) => {

        this.control.vad_config.server_vad = false;
      };
      this.ws.onclose = () => {
        console.log("WebSocket 连接已关闭");
        this.wsLog.push("WebSocket 连接已关闭");
        this.$message({
          message: "WebSocket 连接已关闭",
          type: "error",
        });
        this.isConnected = false;
        this.control.vad_config.server_vad = false;
      };
      console.log('initWS：', this.ws)
    },
    
    /************************************************* 获取媒体流 *********************************************/
    // 获得音、视频数据流
    getMediaStream() {
      if (!navigator.mediaDevices && navigator.mediaDevices.getUserMedia && navigator.mediaDevices.getDisplayMedia) {
        this.closeWS();
        alert('您的浏览器不支持 getUserMedia 和 getDisplayMedia ！');
        return;
      }
      if(this.videoType === "video"){  //如果是音视频通话模式
        navigator.mediaDevices.getUserMedia({
          audio: true, // 设置为 true 以请求音频流
          video: true, // 设置为 true 以请求视频流
        }).then((stream) => {
          // 获取用户媒体流
          this.activeStream = stream;
          if(stream.getVideoTracks().length > 0 && stream.getAudioTracks().length > 0){
            // 创建一个新的MediaStream，将屏幕视频轨道和麦克风音频轨道合并
            this.videoStream = new MediaStream();
            stream.getVideoTracks().forEach((track) => this.videoStream.addTrack(track));
            stream.getAudioTracks().forEach((track) => this.videoStream.addTrack(track));
            // 获得视频数据流  并发送请求
            this.getVideoBlob();
          }
          if(stream.getAudioTracks().length > 0){
            // 创建只包含音频轨道的 MediaStream
            this.audioStream = new MediaStream();
            stream.getAudioTracks().forEach((track) => this.audioStream.addTrack(track));
            // 获得音频数据流
            this.getAudioBlob();
          }
          // 通过vad状态开关视频流录制
          this.changeVad();
        }).catch((error) => {
          this.closeWS();
          alert(error);
          console.error(error);
        })
      }else{  // 如果是屏幕分享
        // 使用getDisplayMedia请求屏幕捕获
        const screenStream = navigator.mediaDevices.getDisplayMedia({
          video: true
        });
        // 使用getUserMedia请求麦克风音频
        const audioStream = navigator.mediaDevices.getUserMedia({
          audio: true
        });
        // 等待屏幕和麦克风两个流都成功获取
        Promise.all([screenStream, audioStream]).then((streams) => {
          // 获取音频流、屏幕流
          const [screenStream, audioStream] = streams;
          // 将捕获的屏幕流设置到video元素上，这样用户能看到屏幕分享的视频
          this.activeStream = screenStream;
          // 创建一个新的MediaStream，将屏幕视频轨道和麦克风音频轨道合并
          if(screenStream.getVideoTracks().length > 0 && audioStream.getAudioTracks().length > 0){
            this.videoStream = new MediaStream();
            screenStream.getVideoTracks().forEach((track) => this.videoStream.addTrack(track));
            audioStream.getAudioTracks().forEach((track) => this.videoStream.addTrack(track));
            // 获得视频数据流
            this.getVideoBlob();
          }
          // 创建只包含音频轨道的 MediaStream
          if(audioStream.getAudioTracks().length > 0){
            this.audioStream = new MediaStream();
            audioStream.getAudioTracks().forEach((track) => this.audioStream.addTrack(track));
            // 获得音频数据流
            this.getAudioBlob();
          }
          // 通过vad状态开关视频流录制
          this.changeVad();
        }).catch((error) => {
          this.closeWS();
          alert(error);
          console.error(error);
        });
      }
    },
    // 获得视频音频数据流
    getAudioVideoBlob(videoData) {
      const videoBlob = new Blob([videoData], { type: "video/webm" });  // 创建视频blob对象
      // 处理音频数据
      const float32Array = decompress(this.inputAudioData, this.audioSize);
      // 调用decompress函数来解压缩音频数据，并将解压后的数据存储在float32Array中
      const audioArrayBuffer = encodePCM(float32Array);
      // 调用encodePCM函数将float32Array编码成PCM格式的音频数据，并存储在audioArrayBuffer中

      // 重置获得的音频流数据
      this.inputAudioData.length = 0;
      this.audioSize = 0;
      const audioBlob = new Blob([audioArrayBuffer], { type: "audio/pcm" });  // 创建一个音频Blob对象，类型为audio/pcm。
      return {
        videoBlob,
        audioBlob,
      };
    },
    // 获得视频数据流
    getVideoBlob() {
      // 设置 MediaRecorder 选项
      const videoOptions = { mimeType: "video/webm" };  // 视频录制的一些配置项
      // 创建视频 MediaRecorder
      this.videoMediaRecorder = new MediaRecorder(
        this.videoStream, // 音、视频混合流 
        videoOptions
      );
      // 当stop时触发  
      this.videoMediaRecorder.ondataavailable = (event) => {  // 当有媒体数据可用时，会触发该事件
        if (event.data && event.data.size > 0) {
          const data = event.data;
          // 获得音、视频的Blob对象
          const blobDate = this.getAudioVideoBlob(data);
          if (this.control.vad_config.server_vad) {  // 设置服务端VAD检测
            // 获得base64数据，并发送
            this.sendCombinedMessage(blobDate.videoBlob, blobDate.audioBlob);
          } else {
            // 存储blob对象 等待手动发送
            this.audioBlobs.push(blobDate.audioBlob);
            this.videoBlobs.push(blobDate.videoBlob);
          }
        }
      };

      // 当录制停止时触发
      this.videoMediaRecorder.onstop = () => {
        // 开启vad检测时 触发开启事件
        if (this.control.vad_config.server_vad) {
          this.videoMediaRecorder.start();
        }
      };
    },
    // 推送消息
    async sendCombinedMessage(
      videoBlob,
      audioData,
      chunk_type = "append"
    ) {
      try{
        // download(videoBlob, 'webm')
        // 将音频转换为Base64编码
        const videoBase64data = await blobToBase64(videoBlob);
        const audioBase64data = await blobToBase64(audioData);

        const message = {
          client_timestamp: Date.now(),
          video_chunk: videoBase64data,
          audio_chunk: audioBase64data,
          system_prompt: this.promptValue,
          control: this.control,
        };
        if (!this.control.vad_config.server_vad) {
          message.chunk_type = chunk_type;
        }
        console.log('推送消息：', message);
        this.wsLog.push(`推送消息：${JSON.stringify(message)}`);
        this.ws.send(JSON.stringify(message)); 
      }catch (error) {
        console.log(error);
      }
    },
    // 获得音频数据流
    getAudioBlob() {
      // 获得pcm格式的音频数据
      // 创建 AudioContext
      const audioContext = new (window.AudioContext ||
        window.webkitAudioContext)();
      // 创建 MediaStreamSource
      const source = audioContext.createMediaStreamSource(this.audioStream);
      // 创建录音节点，指定缓冲区大小和处理音频的输入输出通道数
      const scriptProcessor = audioContext.createScriptProcessor(4096, 1, 1);
      // 将音频输入源连接到录音节点，并将录音节点连接到音频上下文的输出
      source.connect(scriptProcessor);
      scriptProcessor.connect(audioContext.destination);

      // 存储 scriptProcessor 和 audioContext 以便之后可以断开连接
      this.scriptProcessor = scriptProcessor;
      this.audioContext = audioContext;

      // 当音频数据可用时执行的回调函数
      scriptProcessor.onaudioprocess = (audioProcessingEvent) => {
        const inputBuffer = audioProcessingEvent.inputBuffer;
        // 获取第一个（也是唯一一个）输入通道的 Float32Array 数据 leftChannelData 就是 PCM 数据
        const leftChannelData = inputBuffer.getChannelData(0);
        this.inputAudioData.push(new Float32Array(leftChannelData));
        this.audioSize += leftChannelData.length;
        // this.drawRecord();
      };
    }
  },
    /************************************************* 页面按钮功能与交互 *********************************************/
    // 切换视频采集方式
    radioChange(value) {
      this.closeWS()
      location.href = `?type=${value}`
    },
    changeVad() {
      // 如果是开启vad检测
      if (this.control.vad_config.server_vad) {
        console.log("开启了vad检测，开始定时发送数据！");
        this.$message({
          message: "开启了vad检测，开始定时发送数据！",
          type: "success",
        });
        // 重置获得的音频流数据
        this.inputAudioData.length = 0;
        this.audioSize = 0;
        // 清空录制数据数组
        this.audioBlobs.length = 0;
        this.videoBlobs.splice(0, this.videoBlobs.length);

        // 如果处于关闭状态 则开启
        if (
          this.videoMediaRecorder &&
          this.videoMediaRecorder.state !== "recording"
        ) {
          this.videoMediaRecorder.start();
        }
        // 定时发送数据
        this.videoInterval = setInterval(() => {
          // 停止 MediaRecorder
          if (
            this.videoMediaRecorder &&
            this.videoMediaRecorder.state === "recording"
          ) {
            this.videoMediaRecorder.stop();
          }
        }, this.intervalTime);
      } else {
        // 如果是关闭vad检测
        // 清除定时器
        clearInterval(this.videoInterval);
        if (
          this.videoMediaRecorder &&
          this.videoMediaRecorder.state === "recording"
        ) {
          // 停止 MediaRecorder录制
          this.videoMediaRecorder.stop();
          console.log("关闭了vad检测，已停止发送数据！");
          this.$message({
            message: "关闭了vad检测，已停止发送数据！",
            type: "success",
          });
        }
        setTimeout(() => {
          // 清空录制数据数组
          this.audioBlobs.length = 0;
          this.videoBlobs.splice(0, this.videoBlobs.length);
        }, 100);
      }
    },
    // 开启视频录制
    userVideoPlay() {
      this.isUserPlaying = true;
      if (
        this.videoMediaRecorder &&
        this.videoMediaRecorder.state !== "recording"
      ) {
        // 恢复录制
        this.videoMediaRecorder.start();
      }
      // 清空暂停时获得的音频数据
      this.inputAudioData.length = 0;
      this.audioSize = 0;
      this.$message({
        message: "开始录制",
        type: "success",
      });
    },
    // 暂停视频录制
    userVideoPause() {
      this.isUserPlaying = false;
      if (
        this.videoMediaRecorder &&
        this.videoMediaRecorder.state === "recording"
      ) {
        this.videoMediaRecorder.stop();
      }
      this.$message({
        message: "暂停录制",
        type: "success",
      });
    },
    // 清空录制数据数组
    userVideoReset() {
      this.audioBlobs.length = 0;
      this.videoBlobs.splice(0, this.videoBlobs.length);
      this.$message({
        message: "重置成功",
        type: "success",
      });
    },
    // 下载音、视频数据文件
    userDownloadFile() {
      if(!this.verification()) return
      for (let i = 0; i < this.audioBlobs.length; i++) {
        download(this.audioBlobs[i], "pcm", `${i}-`);
        download(this.videoBlobs[i], "webm", `${i}-`);
      }
      this.$message({
        message: "下载完成",
        type: "success",
      });
    },
    // 向服务端推送数据
    async userSendData() {
      if(!this.verification()) return
      // 设置chunk_type为发送
      let i = 0;
      for (i; i < this.audioBlobs.length - 1; i++) {
        await this.sendCombinedMessage(this.videoBlobs[i], this.audioBlobs[i]);
      }
      // 设置chunk_type为结束 通知服务端开始推理
      this.sendCombinedMessage(this.videoBlobs[i], this.audioBlobs[i], "finish");
      this.$message({
        message: "发送成功",
        type: "success",
      });
    },
    // 校验是否可以发送数据
    verification(){
      if (this.audioBlobs.length === 0 || this.videoBlobs.length === 0) {
        this.$message({
          message: '请点击录制并暂停，录制完一段音视频',
          type: "error",
        })
        return false
      }
      return true
    },
};
</script>
```
