> 此外， Kai 还分享了自己使用语言模型的经历和感受，认为语言模型为他带来了巨大的个人改变和视野拓展。在实际工程中，需要根据业务需求选择合适的 Prompt 或多 agent 架构。在内容创作中，可以使用多智能体系统实现优化迭代。
