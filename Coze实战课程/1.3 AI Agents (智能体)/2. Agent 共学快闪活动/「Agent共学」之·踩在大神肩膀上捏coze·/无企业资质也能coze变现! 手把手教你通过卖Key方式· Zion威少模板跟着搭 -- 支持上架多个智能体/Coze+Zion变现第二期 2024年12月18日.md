  - **支付方式选择**：支付方式可选择余额模式。
  - **领券操作流程**：通过特定链接领券，未注册用户输入手机号码和邀请码可登录获得券，新申请券需等待。
  - **智能体创建顾虑**：担心客户因知晓使用扣子创建而压价，领券能覆盖专业版价格。
  - **收费模式探讨**：考虑会员开通、账号管理、短信发送等收费相关事项，可选择月付。
  - **商城套餐与激活**：商城有月度、季度、年度套餐，购买后通过激活码激活会员，可手动刷新查看会员时长变化。
  - **智能体添加与对话**：部分智能体需特定指令才能添加，可与智能体进行对话，如儿童陪伴类。
  - **专属与公开智能体**：专属智能体只发布给特定人群，开发者可为特定人员定制 bot。
- **创建项目及添加 bot 的流程讲解**

  - **项目创建流程**：通过手机注册获取邀请码和账号，在个人空间新建项目，选择微扫扣子变现模板，将默认年付改为月付，输入项目名称，结账时使用优惠券可免费体验。
  - **项目体验方法**：进入个人空间，点击新建项目，构建完成后获取二维码和链接，点击预览可体验，还可查看服务器配置。
  - **修改项目设置**：在设置的全局变量中修改 logo name 和 site name，点更新预览完成修改。
  - **添加 bot 步骤**：点击数据中的数据库，在 code bot 数据表中插入数据，填写 bot ID、上传图标、填写介绍、勾选 API 和 chat SDK 后发布，审核通过后可在商城中添加。
- **关于智能体定制与发布的讨论**

  - **设置抽取后门**：在智能体中留了一定概率能抽到金色传说的后门。
  - **发布 SDK 与绑定接口**：发布 chat SDK，未绑定成功可能是未发布或未审核通过，发布后需关注审核状态。
  - **添加 License**：添加 License 可将智能体设为专属，只有知道密码的人能添加，密码可定期变更。
  - **定制智能体方式**：包括单人单次定制，当前不具备此功能，可向许愿池许愿增加；还可在商城发布定制能力。
  - **订阅套餐设置**：插入数据创建订阅套餐，填写定制内容、价格和链接等信息。

  - **测试数据处理**：历史测试数据可删除或不管，默认带的官方模板数据可删除或不管。
