  - **触发词猜测**：对生成配文的触发词进行了猜测和尝试。
- **关于扣子循环功能的解读与实操**

  - **循环定义**：循环是重复执行一系列任务直到某个条件满足，类似编程中的 if else 和 while 函数，在循环节点中不断重复直到满足条件进入下一个节点。
  - **循环类型**：包括宿主循环、指定循环次数和无限循环。宿主循环是依次处理数组格式的元素；指定循环次数可设定任务处理次数；无限循环可基于条件判断，增强工作流的交互性。
  - **应用场景**：如长文总结、问卷调查等，循环处理相对并行处理更稳定，能实现上下文关联。
  - **中间变量**：是在循环中被依次替换的变量，顺序为初始变量到节点任务输出再到替换初始变量，达到条件后输出最终变量，变量类型需前后一致。
  - **调试实操**：通过试运行工作流可查看循环生成的成果，如对数组格式的小标题生成相应的文章段落。
- **天猫文案框架工作流配置与实践**

  - **开始节点配置**：将每个节点的配置放在文档中，首先完成开始节点的配置。
  - **大模型应用**：添加大模型用于快速生成文案框架段落，可引入插件获取实时热点新闻，选用豆包 Lite 模型因其价格便宜。
  - **循环节点设置**：设置循环节点，包括输入、空间变量、添加大模型、配置输出等，确保按照文案框架生成并处理内容。
  - **变量配置与输出**：配置设置变量储存大模型生成的段落扩写，设置标题，完成整个工作流的配置并进行实践。
  - **效果评估**：对生成的文案框架和内容进行查看和分析，认为对于发布长文存在一定局限性。
- **大模型中的循环体应用**

  - **大模型输出方式**：包括依靠节点通过提示词和示例让大模型直接输出，以及使用文本处理功能进行分隔等方式。
  - **提示词配置**：可在提示词中通过特定格式设置输出形式，如用中括号加双引号、加逗号的形式，也可通过 JSON 导入变量。
  - **循环体类型**：有定循环次数、不定循环次数、按数组长度循环等类型，还介绍了循环中的中间变量、终止条件等配置。
  - **循环体应用案例**：如根据给定标题生成多篇不同的文章，通过设置循环次数和相关条件，观察循环体的生成过程和结果。
- **工作流中循环体的应用与实践**

  - **循环体框架介绍**：包括用户输入指令、智能体生成文案初稿作为中间变量、通过消息节点展示并询问甲方意见、根据甲方反馈修改等环节。
  - **中间变量的作用**：中间变量在循环过程中不断迭代，存储每次生成和修改的内容，实现循环中的内容更新。
  - **问答节点的技巧**：问答节点中选项的回答无法引用变量参数，而直接回答或提取相关字段可在后续节点引用。
  - **循环体的应用拓展**：不仅可用于生成小红书文案，在画图、logo 设计等方面也能发挥作用，通过循环和问答实现不断优化。
- **关于循环体及相关技术的交流分享**

  - **循环体中中间变量处理**：在循环体中，通过打空格或其他方式处理中间变量，如用空数组存储图片变量。
  - **图像流处理与文本合并**：接图像流时加文本处理进行合并，以适应不同格式，保证后续处理更方便。
  - **循环节点的应用与缺陷**：在工作流中应用循环节点，存在一些缺陷，如人物角色一致性问题，可通过加入入参等方式解决。
  - **模板发布与模型选择**：模板发布需官方审批，目前专业版与普通版合并导致模板发布暂停。模型选择上，豆包 Lite 可通过提示词调教提高输出质量。
