随着AI的发展，大家对AI的诉求变得越来越具体，简单的ChatBot的弊端日渐凸显，基于LLWeng对于Agent的结构设计，Coze，Dify等平台在应用探索上有了很大的进展。

然而这些平台都有着固有局限，正如低代码平台，无代码平台历经数十年的发展，依然无法很好平衡复杂业务场景无法满足，简单业务场景ROI不高等限制。

对于专业IT人士，coze等平台不够自由，局限性过大，对于普通用户，想要完成复杂的业务场景又有着诸多的限制。软件技术的发展，一直在对抗需求的日益复杂化，最终不得不借助编程这个朴实的手段。

社区的共学从最初的agent，到coze，到微信机器人，到谁是人类，随着技术难度逐步深入，这个过程中越来越多的小伙伴，提升了技能，对AI的诉求也更加具体，更加具象，加上AI编程的发展，谈“代码”色变，逐渐过度到，这我想做，那我也想做。

和许多小伙伴交流中发现，每个人都有自己一些习惯，流程希望固定下来，也有很多繁琐又重复的工作希望能有AI来帮助，比如获取行业信息，比如做一些表格，比如一个稍微复杂一些的报表，不希望从不同网站粘贴来粘贴去。很多人希望学习编程，但是被服务器，编译，调试，开发工具报错等等限制了前进的步伐。虽然知道原理可能是什么，知道代码从哪里复制，但是不知道去哪里粘贴呀！

这次共学希望通过1-2周的时间，让大家从0到1搭建一个网站。希望通过这样一次共学，抛砖引玉，在AI时代，如此繁多优秀的资源下，整合出属于自己的最佳实践。

# 反馈洞察         

## 问卷反馈分析：用户对智能体(Agent)的期待与需求

根据您提供的问卷反馈，我总结出以下几个主要方向的期待和需求：

## 1. 商业化与变现需求

- 能用来赚钱的智能体
- 变现途径
- 如何接智能体商单
- 企业出海的智能体
- 结合落地的商业案例分享
- 如何评价agent的好坏，agent如何商业化

## 2. 实用工具与应用场景

- 电商提取工具，给亚马逊评分的插件
- 个人网站开发（前后端，小白友好）
- 编剧Agent
- 产业洞察agent（趋势洞察、技术洞察、用户洞察）
- 自动生成高质量竖屏短剧剧本
- 一键式短视频从文本到分镜到剪辑成片
- 自动抓取分析特定短剧或电影的拉片Agent
- 电商经营数据跟踪与分析
- 新闻传播学考研真题agent

## 3. 技术学习与实操需求

- 了解和快速上手最佳实践
- Dify中循环和迭代的用法
- 插件开发
- 如何用扣子或Dify从0-1开发智能体
- 搭建工作流，调取外部API做成自动化产品
- 如何最大程度减少幻觉

## 4. 行业应用与垂直领域

- 多智能体在教育领域的应用
- 企业端结合agent应用的实际案例
- 工作场景中的实际应用（超出PPT、会议总结等常规用法）
- 视频相关内容
- 亲子共学内容
- 结合AI硬件一同开发
- UI设计方向

## 5. 活动形式期待

- 真实的Agent效果展示
- 开放麦式分享
- 实操课（直接带着做实验，限制名额）
- 更多互动，少一些单向输出
- 线下实操交流
- 分类型分享（工具使用、商业化和场景、作品展示等）
- 直播回放
- 课前预习总结

这些反馈显示用户对智能体的期待主要集中在实用性、商业化、技术学习和特定领域应用上，同时也希望有更多互动性强、实操性强的分享形式。
