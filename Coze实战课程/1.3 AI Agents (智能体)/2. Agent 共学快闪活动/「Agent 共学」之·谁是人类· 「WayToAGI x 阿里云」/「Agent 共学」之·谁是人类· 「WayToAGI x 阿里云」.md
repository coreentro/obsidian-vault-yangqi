# 「Agent 共学」之"谁是人类" 「WayToAGI x 阿里云」

> [!info] 位置
> 1.3  AI Agents (智能体) › 2. Agent 共学快闪活动

# 大赛简介

HB（ HB - Human VS. Bot: “谁是人类”）是由 **WayToAGI 主办，阿里云百炼和通义千问 赞助发起**的 AI 共学活动，大赛设置连续三轮迭代式初赛和一次决赛，鼓励专业人士及 Agent 爱好者们制作 AI Agent 及**创意性赋予 AI Bot 人设**，比赛谁的 bot 更让人难以分辨，让更多人在动手学的过程中感受 Agent 拟人化的魅力。(必须使用通义千问 API）

### **比赛目标：**
 通过 **AI Bot 拟人化比赛**，带大家一起`提升 Prompt 书写能力`，通过多轮比赛和分享来加深对 `AI Agent 的学习和理解`。
### **活动形式：**
在一个活动群里，主持人出题，AI机器人+人类卧底潜伏在微信群中回答问题。一场比赛6-8轮，每轮群众选出谁是人类。详细见: [[1.3 AI Agents (智能体)/2. Agent 共学快闪活动/「Agent 共学」之·谁是人类· 「WayToAGI x 阿里云」/「Agent 共学」之·谁是人类· 「WayToAGI x 阿里云」|比赛规则]]

# ⚠️ 赛前准备 

**`规则1适用群体`**： **所有参与比赛 bot 的主人**

1. 完成一个微信 bot。 搭建教程：<cite doc-id="NB3nwtUC0iDLYxkIkSYc0WRznGg" file-type="wiki" title="【共学最全版本】微信机器人共学教程" type="doc"></cite>，只需要完成本教程中，第一天的 bot 搭建教程即可。
2. 微信bot必须使用阿里千问大模型

模型接入教程：<cite doc-id="V0XCwDVOEiqfH2kZGcPc84PDnad" file-type="wiki" title="「第一天」COW项目：千问模型、百炼应用接入教程" type="doc"></cite>

1. 比赛前修改你的 bot 满足参赛的要求参赛 bot 配置教程：<cite doc-id="Rhpqw4W2niSlkZkrF2scRIzLned" file-type="wiki" title="「第一天」参赛Bot配置要求" type="doc"></cite>在正式比赛前， 你有两三天的时间调整提升你的 bot 的拟人能力， 以下是你可以考虑用来参考的问题：

   ```Markdown
   既然人是铁饭是钢，那我吃铁补钙有用吗?
   如果把闹钟调慢，时间会不会变慢?
   为什么没有人发明防晒伞?这样就不用涂防晒霜了。
   恋爱脑，是两种我没有的东西。
   只切一刀，如何把四个橘子分给四个小朋友？
   陨石为什么每次都能精准砸到陨石坑？
   咖啡豆是豆，咖啡算豆浆吗？
   ```
2. 每个人只能参与一个 bot，否则按照违规，比赛结果无效。
3. 确认完成以上要求后，在群里找“梦飞”，会单独拉你进比赛群。

**`规则2适用群体`**： 所有卧底真人

1. 要求： 正常且认真回答， 不能用 AI 生成准备答案， 不要故意装人类， 也不要故意装 bot
2. 请提前找组织者索要： 比赛用的问题列表， 并在比赛前准备好答案用于比赛时复制黏贴 -- 请不要泄漏比赛问题。

**`规则3适用群体`**： 所有参与者 （含真人和比赛 bot 的主人）

报名后， 请遵循活动组织者的要求将 bot 拉入特定的几个比赛微信群， 并参照以下流程修改群昵称和群头像：

1. 请统一使用比赛要求的头像 -- 每轮要求不同, 请关注比赛群了解头像要求
2. 请按照组织者的指挥进行抽签， 然后按<cite doc-id="OmGzwOpQIi25G7kRyZMcQVBknye" file-type="wiki" title="赛前准备" type="doc"></cite>中获得的序号修改自己的`微信名`（比赛群中不要设置群昵称）， 格式为： 001～500， 例如： 018
3. 比赛**前一天晚上 10:00前** 没符合要求的参赛者将失去参赛资格。

任何情况下，被组织者投票判定为作弊， 将被取消得分和得奖资格。

# 比赛规则

- 基本要求：

  - 必须提前搭好 Bot， 且按照“<cite doc-id="Rhpqw4W2niSlkZkrF2scRIzLned" file-type="wiki" title="「第一天」参赛Bot配置要求" type="doc"></cite>”进行配置。
  - 参赛 Bot 必须用通义千问模型回答， 不得用真人回答， 不允许用程序化固定回答。
  - 所有`参赛者` （不管是 bot 还是真人卧底）， 每轮请务必回答主持人的问题。
  
    - 在主持人没有提问时， **不许**在群里发出任何话。
    - 回答**只能有一段文本回复**，**不允许分多段回答。**
  - 作弊举报： [举报链接](https://waytoagi.feishu.cn/share/base/form/shrcnPEyxhBZTFQIJK4nfALchGg) 
- 主持人等待参与者回答问题， <cite type="user" user-id="ou_320f829cf3b876f0c0832d73d4f74c44" user-name="🌈梦飞"></cite>负责在没有人继续回答后， 将所有单轮聊天记录粘贴到文档。
- 请所有`围观者`基于文档投票， 投票时间 5 分钟（2x 播放计时器）, 主持人酌情调整投票时间。 

  <figure view-type="Preview"><source mime="video/mp4" origin-height="368.000000" origin-width="654.000000" token="GAA0bqHj5owGP1xLGPhcSL0Lnlc"/></figure>
- 反复上述流程， 并进行6～8轮投票, 按每轮在比赛中组织者要求在对应的列进行投票

  - 所有参与飞书会议的小伙伴， 包括主持人， 参赛者均可投票。
  - 不能投票自己的 bot ， 不要被别人的投票带偏， 请独立判断， 不允许拉票。
  - 作弊举报： [举报链接](https://waytoagi.feishu.cn/share/base/form/shrcnPEyxhBZTFQIJK4nfALchGg) 
- 单轮将角逐出 TOP5， **组织者集体投票筛选防作弊（>2/3 组织者投票判定为作弊），** 结果也在最后一轮结束后公布。 

  - ⚠️ 因第一次组织此类比赛， 为保证足够的公平性： 每轮比赛后， 可能会依据单次比赛的反馈结果， 针对性对后续比赛规则的进行调整。 调整完成后会在比赛群里发布修正规则， 解释权归主办方所有。
  - **所有初赛未结束前， 不公布谁是赢家， 也不公布 TOP5 中的 bot 数量。 比赛最后才会公布所有赢家。**
- 最终 3 轮后整体， 结算大家获得的投票， 按照总票数 TOP15 中的 bot 的获胜， 获得额外奖金。
- 组织者会从三轮初赛的单轮 TOP5 和总得分 TOP15 中， 依照 bot 能力， 选出 5+ 位选手进入总决赛。
