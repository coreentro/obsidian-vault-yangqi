Claude produced a list of similar pairings (e.g., 备胎使用须知, 电池循环寿命记录, 白老鼠实验记录) and explained the generative principle: first identify a culturally loaded self-deprecating object, then find documentation types that genuinely accompany that object in real life, so both the literal and metaphorical readings hold simultaneously. Claude noted that combinations where only the metaphorical layer works feel forced and lack the "aha" quality the person was looking for.
