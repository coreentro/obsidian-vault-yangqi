根据搜索结果，我来解释一下情况：

**Claude 桌面端的定位已经发生了变化。** 桌面应用目前主要提供两个专业模式：**Claude Cowork**（一个可以在你电脑上自主操作文件、执行多步骤任务的 agent）和 **Claude Code**（专为代码开发设计的工具），这两个功能只在桌面端的付费订阅中提供。

今年 4 月，Anthropic 对 Claude Code 桌面应用进行了全面重新设计，加入了多会话侧边栏、可拖拽布局、集成终端和内置文件编辑器等功能。这次更新让桌面端更像一个"开发工作台"，而不是普通聊天界面。

**如果你想用普通对话功能，有这些选项：**

- **网页端**：访问 [claude.ai](https://claude.ai)，对话功能完整保留
- **手机 App**：Claude 移动应用依然有完整的对话界面
- **桌面端**：普通的聊天方式不在桌面 app 里，也不在移动端，而是在 claude.ai 网页上

简单说，Anthropic 把桌面 app 定位成了**面向专业用户的 agent 工具**（Cowork + Code），日常对话请使用网页或手机端。你需要哪方面的帮助？
