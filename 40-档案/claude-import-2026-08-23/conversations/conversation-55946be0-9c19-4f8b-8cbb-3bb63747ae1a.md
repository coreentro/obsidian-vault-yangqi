## Claude

 The user wants to know how to block all phone numbers starting with 400 (common telemarketing numbers in China).根据你使用的设备，有以下几种方法：

**iPhone**

1. 打开「设置」→「电话」→「来电过滤」，开启「静音未知来源」
2. 或下载第三方应用如**熊猫吃短信**、**来电通**，支持自定义规则屏蔽400号段

**Android（以小米/华为为例）**

1. 打开「电话」App → 右上角菜单 → 「骚扰拦截」
2. 添加自定义规则，填写前缀 `400`，选择「拦截」
3. 华为可在「骚扰拦截」→「拦截规则」→「号码规则」中添加

**通用方法（第三方App）**

- **腾讯手机管家** / **360手机卫士**：支持按号段批量屏蔽
- 在「骚扰拦截」→「自定义规则」中添加 `400*` 或 `400` 前缀规则

**注意事项**

- 400号码也包括一些银行、快递等正规客服，屏蔽后可能错过重要来电
- 建议优先用「静音」而非「挂断」，避免遗漏重要电话
- 也可以仅屏蔽未存储联系人中的400来电
