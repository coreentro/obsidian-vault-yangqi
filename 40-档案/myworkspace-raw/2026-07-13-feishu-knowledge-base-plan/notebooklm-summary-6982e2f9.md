## Core takeaway

NotebookLM is most useful as a source-grounded production system rather than a generic chatbot. Build a topic-specific source library, use Deep Research to discover candidate sources, verify and import the useful ones, and then reuse the same evidence base across chat and Studio outputs.

## Main workflow

1. Create one notebook for one coherent topic.
2. Import PDFs, webpages, YouTube links, local files, and pasted text.
3. Use Deep Research when the source set is incomplete, then manually screen the returned sources.
4. Ask questions against the imported evidence rather than relying on unsupported free-form generation.
5. Turn the same source set into audio overviews, explanatory videos, mind maps, reports, flashcards, quizzes, infographics, slides, or data tables.
6. Configure audience, focus, language, length, and visual style for each output instead of accepting defaults.
7. Verify citations, claims, and generated media before treating an output as knowledge.

## Practical uses

- Commuting: generate a Chinese in-depth audio overview.
- Teaching: generate an explanatory video with a defined audience, emphasis, and visual style.
- Understanding: use the mind map to inspect structure and ask follow-up questions about individual nodes.
- Consolidation: generate a report or white paper from the selected sources.
