## 🚧 红线（不要做）

1. **不要主动提议或执行删除**（备份、旧文件、缓存都算）——只在我明确说删时才删。
2. **不要越界排障**：只动我明确授权的范围；历史聊天标题、代理配置等无关组件不要当测试对象。
3. **「能跑就别动」优先于「理论上更优」**（`2026-08-17` 明确）：发现潜在隐患但**当前功能正常**时 → 只记录 + 备好预案，**不要主动改配置**。改动价值必须大于回归风险；拿不准就问，别默认动手。
4. **不保存密码 / API Key / Token / Cookie** 到知识库——只记「叫什么、放在哪个 env 变量」。
5. **不要做任何屏幕捕获** —— 包括 `screencapture` **和 `computer_use` 的 capture**（`2026-08-17` 因调 `computer_use` 截图再次弹框，教训重复）。
   - 真因：Hermes.app 本地签名 → TCC（macOS 隐私授权系统）记录永不匹配 → **授权了下次照样弹**。
   - 更关键：在此机上 `computer_use` 捕获**恒返回 `0x0`（拿不到画面）**，即"弹框骚扰用户"却"什么都看不到"，纯负收益。
   - 替代：诊断 UI 一律走**读配置 + 读源码 + 问用户**；确实必须看屏幕时才用 cua-driver，并**先征得用户同意**。
6. 导入长对话（Gemini 等）必须**无损全文**，禁止只交摘要或截断版。
7. 不改写既有笔记正文；结构调整只做移动与新增。
8. **不要关闭 VPN**（`2026-08-20` 当场纠正）：包括 `killall MacPacketTunnel`、把 Shadowrocket 切成 Direct、关掉增强模式。改分流规则也不许靠杀隧道来重载。
