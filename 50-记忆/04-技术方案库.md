## 🧰 Hermes 自定义中转（custom_providers）

```yaml
# config.yaml
custom_providers:
  - name: <站点名>
    base_url: <https://…>
    api_mode: <openai|anthropic>
    key_env: <ENV_VAR_NAME>     # 真实密钥只写在 .env
    extra_headers: {}
    models: [ … ]
```

- 密钥放 `.env`，用 `key_env` 引用。
- 切换：`/model custom:<name>:<model>`
- **未经要求不要改 `model.default`。**
- 桌面端输入框旁的选择器按 `name` 分组；**列表有缓存，改完要重启**。
- `muyuan.do`（`custom:muyuan/gpt-5.6-sol`）必须加 `extra_headers` 的 `UA=codex_cli_rs*`，否则 `403 client_restricted`。
- `DigitalGleam`（`custom:digitalgleam`，`https://ai.digitalgleam.pp.ua/v1`，`key_env: DIGITALGLEAM_API_KEY`）：同样必须 `UA=codex_cli_rs*`。缺省 OpenAI SDK UA（`OpenAI/Python …`）会被 Cloudflare **1010 / Your request was blocked**，不是密钥失效。`2026-08-20` 已证 `glm-5.2`/`glm-5.3` 可聊；`kimi-k3` 额度满。
- `Hcnsec`（`custom:hcnsec`，`https://api.hcnsec.cn/v1`，`key_env: HCNSEC_API_KEY`）：公益网关「新疆幻城网安」。**不需要**自定义 UA。目录目前只有 `glm-5.2`（上游 `z-ai/glm-5.2`）。`2026-08-20` 直连 chat 3/3 200 + Hermes CLI 冒烟回 `OK`。Anthropic `/v1/messages` 也能通，但 Hermes 条目走 `chat_completions`。
