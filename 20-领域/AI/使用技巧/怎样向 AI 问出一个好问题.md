# 怎样向 AI 问出一个好问题

> 核心：跟人提问，问题是**入场券**；跟 AI 提问，问题是**产物**。
> 别优化「第一句话」，去优化「前三轮」。

种子笔记：[[问出一个好问题]]

---

## 一、最反直觉的一点

多数人对 AI 提问的失败，不是问得不够清楚，而是**问得太早就定型了**。

你带着模糊的问题来，AI 会立刻给一个像模像样的答案。这个答案反过来框住你的思路——你开始在它给的框架里追问细节，而真正该问的那个问题，从头到尾没被提出来。

所以第一步不是「把问题问好」，是**明确宣告你还不知道问题是什么**。

## 二、让 AI 帮你找问题（可直接复制）

### 1. 反向访谈（最有效）

```
我想解决 X，但我自己也没完全想清楚。
不要现在给我方案。
请先向我提问，一次问一个，问到你认为已经足够
理解我的真实处境和约束为止。
每轮告诉我：你还缺哪块信息，为什么这块重要。
```

关键是 **「一次问一个」** 和 **「不要现在给方案」**。少了这两句，AI 大概率会礼貌地列五个问题然后自己脑补答案继续往下讲。

> 同类做法见 [[X 上的 彭根辉：“这个AGENTS.md比那个AI大神的48行md还要厉害请你在回答前，先问我问题。要求：一次只问一个问题。根据我的回答，继续追问。直到你有95%的信心理解我的真实需求和目标，然]]——把它写进 AGENTS.md / CLAUDE.md 就成了常驻规则。

### 2. 让 AI 替你重写问题

```
这是我的原始问题：「……」
先不要回答。
请给出 3 个改写版本：
- 一个更具体的
- 一个更根本的（往上抽一层，问我真正在意的东西）
- 一个我可能真正想问但没敢/没想到问的
然后告诉我你觉得哪个最值得答，为什么。
```

第三条经常是最有价值的。

### 3. 让 AI 指出你的盲区

```
基于我目前描述的内容，
我有哪些没说但你必须假设的东西？
其中哪个假设如果是错的，会让你的回答完全失效？
```

把隐含前提逼出来，往往比答案本身更有用。

### 4. 先要地图，再要路线

```
在回答之前，先给我这个问题的全景：
它通常被拆成哪几个子问题？
业内主要有哪几种立场/流派？分歧点在哪？
我这个情况大概落在哪个区域？
```

拿到地图之后，下一个问题会精确一个量级。

## 三、怎么拿到「我想要的答案」

要拆成两种情况，混着用就拿不到。

### A. 想要**正确**的答案 → 对抗迎合倾向

```
不要顾及我的感受。
先说这个方案最可能在哪里失败。
如果我的前提本身有问题，直接指出来，
不要在错误的前提上给我好建议。
```

```
给我最强的反方论证。假设你要说服一个专家我这想法是错的。
```

```
哪些部分你有把握，哪些是推测？分开标出来。
不确定就说不确定，不要补齐。
```

### B. 想要**特定形态**的答案 → 直接描述形态

| 维度 | 说法 |
|---|---|
| 长度密度 | 「三句话给结论」/「展开讲，我要能拿去说服人的细节」 |
| 深浅 | 「当我完全不懂」/「跳过基础，我是这行的」 |
| 体裁 | 「给我一个决策表」/「给我可以直接跑的代码」/「给我一段能直接发出去的话」 |
| 立场 | 「只给推荐，不要列 5 个选项让我自己选」 |

> **大部分让人不满意的 AI 回答，是因为它在做「穷举」而不是「判断」。**
> 明确说「你来选，说清理由」，质量会立刻不一样。

## 四、迭代比重写更省力

拿到不太对的回答，别推倒重问，用最短的反馈拽回来：

- 「太泛了，落到我这个具体场景上重讲」
- 「这一段是我要的，其他删掉，就这一段展开」
- 「你误解了，我说的 X 是指……重来」
- 「**往前退一步**，我们是不是在解一个错的问题？」

最后这句是随时可按的**急停键**。聊偏三轮之后按它，比重开一个对话有效。

## 五、附：通用提问原则（对人也适用）

- **先自己回答一遍**，剩下的空白才是真问题
- 区分「我不知道」（要信息）和「我不确定」（要判断）
- 四要素：**具体 / 上下文 / 目标明确 / 可证伪**
- 撬动力强的问句：
  - 反向问：不问「怎么成功」，问「什么情况下这会失败」
  - 问前提：「这个结论成立需要哪些假设？哪个最脆弱？」
  - 问取舍：「选 A 我放弃了什么？」
  - 问边界：「这个方法在什么情况下不适用？」

**对 AI 特有的**：给素材 > 给描述（贴报错原文、贴代码、贴路径）；说清你的水平和用途；允许它说「不确定」；一次别问五件事；要挑战就明说。

---

## 一句话

> 跟 AI 对话，核心工作不是「提出好问题」，而是
> **给足上下文 + 说清要什么形态 + 不让它顺着你说**。
> 问题本身，让它帮你问出来。
