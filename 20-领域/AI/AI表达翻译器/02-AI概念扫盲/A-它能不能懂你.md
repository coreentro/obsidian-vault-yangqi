# A 组 · 决定它能不能懂你

> 这一组管一件事：**这一轮 AI 眼前到底摆着什么材料**。答偏一半以上的原因都在这里。

---

## 1. 上下文（Context）

| | |
|---|---|
| 💬 **一句人话** | AI 回答这一句时，眼前摆着的**全部材料**：你的话、之前的对话、贴进去的文件、系统给它的规则 |
| ⏰ **什么时候有用** | 它答偏、答浅、忘记前面说过的话时，先想"它现在眼前有什么" |
| ⚠️ **最容易误解** | 以为它"知道"我的项目、我的习惯、我上次说的话。**它不知道**——只知道这一轮塞进去的东西 |

**追问句：**
```text
在回答之前，先复述一遍你现在掌握的关键信息和约束。
如果有你必须假设但我没说的，列出来。
```

> 💡 **实操**：给素材永远优于给描述。贴报错原文、贴代码、贴路径、贴原文段落，比你转述一遍准得多。

## 2. Token（词元）

| | |
|---|---|
| 💬 **一句人话** | AI 眼里的"字"的单位。它不是按汉字或单词算，而是按一小块一小块的片段算。**一个汉字大约 1–2 个 token** |
| ⏰ **什么时候有用** | 算成本、判断"这份材料塞不塞得下"、理解为什么长文会被截断 |
| ⚠️ **最容易误解** | 以为"字数"就是 token 数。中文比英文更"吃" token；代码、表格、JSON 尤其吃 |

**追问句：**
```text
这段材料大约多少 token？会不会超出你的上下文窗口？
如果会，告诉我该怎么拆，以及拆开后你会丢失什么。
```

---

## 3. 上下文窗口（Context Window）

| | |
|---|---|
| 💬 **一句人话** | AI 的**工作台面积**。台面就那么大，新材料放上去，旧的就被挤下去 |
| ⏰ **什么时候有用** | 长对话开始"失忆"、长文档只看了开头、改代码把前面改好的又改坏时 |
| ⚠️ **最容易误解** | ①以为窗口大就等于记得住——**塞得越满，中间部分越容易被忽略**（"中间遗忘"）。②以为它会主动告诉你满了，它通常不会 |

**追问句：**
```text
我们这轮对话里，哪些早期信息你已经不太确定了？
请把当前有效的关键结论和约束重新总结成一段，我们以这段为准继续。
```

> 💡 **实操**：长任务每隔一段就让它"重新总结当前共识"，用总结替代原始长对话。这比祈祷它记得住有效。

## 4. 系统提示 / 规则文件（System Prompt · AGENTS.md · CLAUDE.md）

| | |
|---|---|
| 💬 **一句人话** | 每轮对话开始前就悄悄放在它面前的**常驻规矩**，优先级高于你临时说的话 |
| ⏰ **什么时候有用** | 你反复重申同一个要求（"用中文""别删我文件""术语加注解"）——那就该写成规则，不该每轮说 |
| ⚠️ **最容易误解** | 以为写了就一定被遵守。规矩太多、互相冲突时会被打折；**具体、可检查的规矩**比"要专业"这类形容词有效得多 |

**追问句：**
```text
把我这几条反复强调的要求，改写成一份简洁的常驻规则，
要求每条都可被检查（不要写"要专业"这种无法验证的话）。
并指出哪几条可能互相冲突、你会怎么取舍。
```

## 5. 温度（Temperature）

| | |
|---|---|
| 💬 **一句人话** | **敢不敢乱来的旋钮**。低 = 老实、稳定、重复；高 = 发散、有创意、也更容易跑偏 |
| ⏰ **什么时候有用** | 要稳定格式、要抽取数据、要可复现 → 调低。要起名、要头脑风暴、要多个不同方案 → 调高 |
| ⚠️ **最容易误解** | ①以为温度 0 就绝对不出错——它只是更稳定地重复它的倾向，包括错的倾向。②以为温度能提高"聪明程度"——它只影响**随机性**，不影响能力 |

**追问句：**
```text
这个任务需要稳定一致还是需要多样性？
如果需要多样性，直接给我 5 个差异明显的版本，不要给 5 个换词的同一个版本。
```

> 💡 **实操**：普通聊天界面通常调不了温度。**换个说法就能达到同样效果**——"给我 5 个思路完全不同的方案"≈ 提高温度；"严格按这个格式，逐条对照原文"≈ 降低温度。

## 6. 多模态（Multimodal）

| | |
|---|---|
| 💬 **一句人话** | 除了文字，还能看图、听音、读表格和 PDF |
| ⏰ **什么时候有用** | 截图报错、拍论文图表、让它看设计稿说问题——**贴图往往比打字描述省十倍力气** |
| ⚠️ **最容易误解** | ①以为它能看清图里所有细节——小字、密集表格常读错，关键数字要自己核。②以为读 PDF 就等于读懂了——扫描版 PDF 没有文字层，可能什么都没读到 |

**追问句：**
```text
这张图里你能确定读到的文字/数字有哪些？哪些是你猜的？
分开列出来，猜的部分标明"需要我核对"。
```

## 📎 A 组速查

| 症状 | 先查 |
|---|---|
| 答偏、答浅 | 上下文里到底有什么？素材贴了吗？ |
| 长对话失忆 | 窗口挤满 → 让它重新总结共识 |
| 长文只看开头 | 超窗口 → 拆分，或先要目录再逐段 |
| 每次答得不一样 | 随机性 → 明确要"稳定一致" |
| 同一要求反复说 | 该写进常驻规则了 |
| 图里数字读错 | 让它区分"确定读到"和"猜的" |
