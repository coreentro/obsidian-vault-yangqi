# D 组 · 决定你花多少钱、等多久

> 这一组管一件事：**别用大炮打蚊子，也别用弹弓打坦克**。

---

## 1. 模型档位（旗舰 / 中档 / 轻量）

| | |
|---|---|
| 💬 **一句人话** | 同一家会出好几档：**旗舰**（最强最贵最慢）、**中档**（够用、快、便宜）、**轻量**（极快极便宜，只干简单活） |
| ⏰ **什么时候有用** | 每次开始任务前花两秒选一下，长期能省掉大量时间和钱 |
| ⚠️ **最容易误解** | ①以为越贵越好——**格式转换、摘要、翻译、分类用轻量档几乎无差别**。②以为轻量档只是"笨一点"——它在多步推理和长材料上会明显崩 |

**怎么选：**

| 任务 | 档位 |
|---|---|
| 格式整理、翻译、改错字、分类 | 🟢 轻量 |
| 日常问答、写文案、改稿、总结 | 🟡 中档 |
| 多步推理、复杂代码、方案权衡、长材料分析 | 🔴 旗舰 |

---

## 2. 参数量（7B / 70B / 数千亿）

| | |
|---|---|
| 💬 **一句人话** | 大致的"脑容量"。B = 十亿。**7B ≈ 手机能跑，70B ≈ 高配电脑，几千亿 ≈ 只能云端** |
| ⏰ **什么时候有用** | 判断"我这台电脑能不能本地跑" |
| ⚠️ **最容易误解** | 以为参数量直接等于聪明程度。**训练质量、数据、后训练调优的影响同样巨大**——一个精调过的小模型在特定任务上可以打败通用大模型 |

---

## 3. 蒸馏（Distillation）

| | |
|---|---|
| 💬 **一句人话** | 用大模型当老师去教小模型，让小模型学到接近的表现，但体积小、跑得快 |
| ⏰ **什么时候有用** | 看到"XX-distill"这类名字时，知道它是"小号仿制版" |
| ⚠️ **最容易误解** | 以为蒸馏版等于原版。它在常见任务上接近，在**边缘和困难场景上差距会显现** |

---

## 4. 量化（Quantization）

| | |
|---|---|
| 💬 **一句人话** | 把模型的数字**压缩得更粗糙**，换取体积小、速度快。类似把无损音乐转成 MP3 |
| ⏰ **什么时候有用** | 本地跑模型时，显存/内存不够就靠它 |
| ⚠️ **最容易误解** | 以为压缩无损。压得越狠（4bit 以下）**质量下降越明显**，尤其是长文和精确任务 |

---

## 5. API 与 Key

| | |
|---|---|
| 💬 **一句人话** | **API** 是程序之间的对接口子；**Key** 是你的钥匙，用来计费和认身份 |
| ⏰ **什么时候有用** | 你想让其他软件（笔记、脚本、自动化）用上 AI 时 |
| ⚠️ **最容易误解** | ①以为 Key 可以随便贴——**贴出去等于把信用卡给别人**。②以为网页版和 API 是同一套额度——通常是分开计费的 |

> 🔐 **底线**：Key 只放在配置文件或环境变量里，不贴进聊天、不提交进 Git、不写在截图里。

## 6. 本地模型 vs 云端模型

| | 本地 | 云端 |
|---|---|---|
| 隐私 | 🟢 数据不出机器 | 🔴 数据要传出去 |
| 能力 | 🔴 明显弱一档 | 🟢 最强 |
| 成本 | 🟡 一次性硬件 | 🟡 按用量 |
| 断网 | 🟢 能用 | 🔴 不能 |
| 适合 | 敏感材料、批量简单活 | 复杂推理、日常主力 |

⚠️ **最容易误解**：以为本地模型只是"慢一点"。在复杂推理和长材料上，差距是**质的**，不是速度问题。

---

## 7. 中转 / 网关（Proxy · Gateway）

| | |
|---|---|
| 💬 **一句人话** | 在你和官方之间加一层**转接台**，用来聚合多家、切换供应商、统一计费 |
| ⏰ **什么时候有用** | 想在一个界面里切换多家模型，或官方渠道不便直连时 |
| ⚠️ **最容易误解** | ①以为显示的模型名就是真实上游——**中转可以改名映射**，显示"某旗舰模型"实际可能接的是别的。②以为多加一层没代价——**你的对话内容会经过这一层** |

**追问句：**
```text
请报出你当前实际使用的模型标识和供应商。
如果你无法确认真实上游，直接说无法确认，不要猜。
```

## 8. 流式输出（Streaming）

| | |
|---|---|
| 💬 **一句人话** | 一个字一个字往外冒，而不是等全部想完再一次给你 |
| ⏰ **什么时候有用** | 长回答时体验好得多，能早点发现方向不对就打断 |
| ⚠️ **最容易误解** | 以为流式更快。**总时间一样**，只是让你更早看到开头 |

> 💡 **实操**：看到前三行就发现方向错了？立刻打断重说，比等它写完 800 字省时间。

## 📎 D 组速查

| 你的目标 | 做法 |
|---|---|
| 省钱 | 简单活用轻量档；长材料先自己筛再喂 |
| 提速 | 换小档、缩短上下文、别塞无关材料 |
| 保隐私 | 敏感材料用本地模型；或先脱敏再问 |
| 稳定不出意外 | 固定模型和版本，别随手换 |
| 搞清真实上游 | 直接问它报模型标识 |
