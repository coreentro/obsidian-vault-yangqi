# 写作与总结 Prompt

> ⏰ **适用时机**：写、改、缩、扩、变体裁、总结长文。
> 🎯 **通用原则**：写作类 Prompt 的成败在于**给不给样本**。给一段你认可的文字当基准，比形容一百句"要自然"都有效。

---

## 模板 1 · 把碎碎念变成成文

**适用**：脑子里有一堆想法，说了一堆，但没成文。

```text
以下是我关于 ［主题］ 的零散想法，顺序混乱、有重复：
「［把你说过的、想到的全贴进来，不要整理］」

请：
1. 先告诉我：这些想法里真正的核心主张是什么（一句话）；
2. 哪些是同一件事的重复表达，可以合并；
3. 哪些是我提到但没展开、值得展开的；
4. 哪些其实跑题了，建议删掉；
5. 然后给我一个结构提纲（不要直接写全文）。

我确认提纲后你再动笔。
```

| ✅ 有效标志 | 🔧 失败时的补救 |
|---|---|
| 它指出了你自己没注意到的重复 | 它直接写了全文 → **"我要的是提纲，先停在提纲。"** |
| 提炼的核心主张让你"对，就是这个" | 核心主张说偏了 → **"核心不是这个。是 ［…］。基于这个重新提炼。"** |

## 模板 2 · 改稿（保留我的声音）

```text
这是我写的：
「［原文］」

请改，但守住这几条：
1. 保留我的用词习惯和语气，不要改成标准范文腔；
2. 只改：啰嗦、逻辑断裂、指代不清、重复；
3. 不要加我没说过的观点，不要加漂亮但空的过渡句；
4. 不要用这些词：赋能、一站式、打造、深耕、闭环、抓手；
5. 改完用表格列出你改的每一处：原句 / 改后 / 为什么。

如果某句我写得其实更好，说明理由并保留原句。
```

> 💡 **最后那句很重要**。不加它，AI 会为了"有产出"而改掉你写得好的部分。

## 模板 3 · 总结长文（不丢关键）

```text
材料：［贴原文］
我的用途：［汇报／自己复习／判断值不值得细读］

请按这个结构总结：
1. 一句话结论
2. 核心主张 3 条（每条一句）
3. 它的证据类型（实验／数据／案例／推理／纯观点）
4. 它明确说了但容易被忽略的限制条件
5. 它没说但你认为读者会误解的地方
6. 如果我只读原文的一部分，读哪几段最值

不要平均分配篇幅——重要的多写，次要的一句带过。
```

## 模板 4 · 缩写与扩写

**缩：**
```text
把这段压到 ［字数］ 字以内：
「［原文］」
要求：保住 ［必须保留的信息］，可以牺牲 ［可以牺牲的］。
不要靠删细节压缩，先删重复和虚词。
压完告诉我你牺牲了什么。
```

**扩：**
```text
把这条展开成 ［字数］ 字：
「［原文］」
要求：靠增加 ［具体例子／数据／对比／步骤］ 来扩，
不要靠增加形容词、排比和过渡句凑长度。
```

## 模板 5 · 变体裁

```text
把这段内容改成 ［目标形态］：
「［原文］」

目标读者：［谁］
使用场合：［在哪里出现］
长度：［多长］
必须保留：［哪些信息不能丢］
明确避开：［不要出现的东西］

常见目标形态：
- 可以直接念出来的口播稿（不要破折号、括号、表格、条目符号）
- 三句话的结论
- 一页 PPT 的要点
- 一条能直接发出去的消息
- 一个决策表
```

> 💡 要**逐字稿/口述稿**时记得加"不要破折号、括号、条目符号"——否则会得到一份没法照着念的书面稿。

## 模板 6 · 仿写风格

```text
这是我认可的写作样本：
「［贴 200–500 字样本］」

请先分析这个样本的特征：
1. 句子长度分布（长短句怎么搭配）
2. 段落长度和节奏
3. 用词偏好（书面／口语，具体／抽象）
4. 它怎么开头、怎么收尾、怎么过渡
5. 它明显不用什么

分析完，用同样的特征写 ［主题］，长度 ［字数］。
写完自查：哪几处最偏离样本特征。
```

> ⚠️ **给样本 > 给形容词**。"要自然一点"这类要求几乎无效，贴一段你认可的文字最有效。

## 📎 速查

| 你的状态 | 用哪个 |
|---|---|
| 想法一堆没成文 | 模板 1 碎碎念 |
| 有稿要改 | 模板 2 改稿 |
| 长文要摸清 | 模板 3 总结 |
| 太长/太短 | 模板 4 缩扩 |
| 换个形式用 | 模板 5 变体裁 |
| 要某种风格 | 模板 6 仿写 |
