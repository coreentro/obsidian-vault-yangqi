# 网页与编程 Prompt

> ⏰ **适用时机**：做小网页、改界面、写小工具、让 AI 帮你动代码。
> ⚠️ **前置认知**：AI 说"我已经改好了"≠ 文件真的改了。**没有工具权限的 AI 只能生成文字。**
> 详见 [[20-领域/AI/AI表达翻译器/02-AI概念扫盲/C-它能不能干活|C 组 · 工具调用]]

---

## 模板 0 · 开工前先确认权限（每次都值得）

```text
开始之前先回答我三个问题：
1. 你现在有哪些工具权限？（能否读写文件、跑命令、联网）
2. 这个任务在你当前权限下能真正完成到哪一步？
3. 哪些步骤必须我自己手动做？

确认完再开始。做完请贴出真实证据（改了哪个文件的哪几行、命令的实际输出），
不要只说"已完成"。
```

## 模板 1 · 从零做一个小东西

```text
我想做：［一句话说清它干什么］
给谁用：［自己／同学／学生］
在哪用：［浏览器打开／手机／本地跑］
我的水平：［不会写代码／看得懂改不动］

硬性要求：
1. 如果 GitHub / npm 上有成熟的开源方案，直接复用，不要自己实现；
2. 技术选型要最简单能跑的方案，能单文件就单文件，不要引入构建工具；
3. 每完成一小步就停下来，告诉我怎么自己验证这一步是好的，我确认后再继续；
4. 告诉我每一步我要在哪里点什么、把文件放哪；
5. 遇到需要我做决定的地方，先问我，不要替我选。

先只告诉我：你打算分几步、每步产出什么。不要现在开始写代码。
```

| ✅ 有效标志 | 🔧 失败时的补救 |
|---|---|
| 它先给了步骤清单 | 它直接甩了 300 行代码 → **"回到第一步。先给我步骤清单。"** |
| 每步都有"怎么验证" | 一口气做完所有步骤 → **"太快了。回到第 2 步，停下来让我验证。"** |

## 模板 2 · 改界面（配合黑话词典）

```text
现状：［贴代码 / 贴截图 / 描述］
我的感觉：「［原话］」

请按这个顺序做：
1. 先告诉我：我这句感觉，在专业上对应的是哪几个具体问题（列 2–4 条）；
2. 每条问题给出对应的改法，以及改完我怎么用眼睛验证；
3. 等我选定要改哪几条，再动手；
4. 动手时一次只改一类问题，改完告诉我改了哪几处。

不要一次性重写整个文件。
```

## 模板 3 · 报错排查

```text
我做了：［操作］
我期望：［期望结果］
实际发生：［实际结果］

报错原文（完整，未删减）：
```
［贴报错］
```

环境：［系统／浏览器／版本］
我已经试过：［试过什么，结果如何］

请：
1. 先说最可能的原因，按可能性排序，不要一次给我十种；
2. 第一条给出最小验证步骤（我怎么用一步确认是不是它）；
3. 确认后再给修复方案；
4. 不要让我改多处再一起测——一次改一处。
```

> ⚠️ **贴原文，不要转述**。"我的代码报了个错"和贴出完整报错，得到的答案质量差一个量级。

## 模板 4 · 让它读懂我的现有代码

```text
这是我现有的代码：
［贴代码，或说明文件路径］

我想改的是：［目标］

在动手之前，请先：
1. 用几句话说清这段代码现在在干什么；
2. 指出我要改的地方涉及哪几处，改动会影响到什么；
3. 告诉我有没有"改了这里就会坏那里"的风险点；
4. 给出改动方案，但先不要改。

我确认后你再动手，动手时贴出 diff（改前改后对照）。
```

## 模板 5 · 防"越改越乱"

**适用**：改了几轮之后开始"改一处坏三处"。

```text
我们已经改了几轮，现在开始出现"改一处坏一处"。
停下来做一次整理，不要加新功能：

1. 列出现在文件里有哪些重复定义的东西（同一个值/样式/逻辑抄了多份）；
2. 把它们收敛成集中定义、各处引用；
3. 重复出现 3 次以上的结构抽成可复用部件；
4. 告诉我哪些地方原先重复、你合并成了什么；
5. 这是纯整理，不要改变现有效果——改完外观和行为应该基本一致。

整理完再继续加功能。
```

## 模板 6 · 安全线（动真实文件时）

```text
开始之前，先列出你打算执行的所有操作，标注哪些不可逆
（删除、覆盖、提交、发送、付款）。

规则：
1. 不可逆操作先问我确认，不要直接做；
2. 修改前先备份，告诉我备份在哪；
3. 不要碰我没提到的文件；
4. 每步做完贴出实际输出，失败就原样贴错误信息，不要掩盖。
```

> 🔴 **不可逆的三件事**：删除、覆盖、对外发送。这三类永远保留人工确认。

## 📎 速查

| 你的状态 | 用哪个 |
|---|---|
| 每次开工 | 模板 0 确认权限 |
| 从零做东西 | 模板 1 分步做 |
| 界面感觉不对 | 模板 2 + 黑话词典 |
| 报错了 | 模板 3 贴原文 |
| 有现成代码要改 | 模板 4 先读懂 |
| 越改越乱 | 模板 5 收敛整理 |
| 要动真实文件 | 模板 6 安全线 |
