# 学习与理解 Prompt

> ⏰ **适用时机**：撞见一个不懂的词、要吃透一个概念、要判断自己是不是真懂了。
> 🧠 **本库立场**：**只要你见过这个概念，你就能吃透它**——见一次问一次。所以知道的概念越多越好。

---

## 模板 1 · 四问吃透一个词（最常用）

```text
① 用一句不含术语的话解释 ［概念］，并给一个日常生活的例子。
② 它解决了什么问题？没有它之前人们怎么做，为什么不够？
③ 关于它，外行最常见的三个误解是什么？
④ 在我的场景（［你的场景］）里，它会怎么影响我的实际操作？
   如果不影响，直接说"对你没影响"，不要硬凑。

我的背景：［化学硕士，非 IT 背景／其他］
出现英文缩写请在括号里加一句中文注解。
```

| ✅ 有效标志 | 🔧 失败时的补救 |
|---|---|
| ③ 的误解正好命中你之前的想法 | 解释里还是全是术语 → **"你的解释里还有 ［某词］ 我不懂。用完全不含术语的话再说一遍。"** |
| ④ 明确说了对你有没有影响 | ④ 在硬凑 → **"如果对我的场景其实没影响，直说没影响。"** |

## 模板 2 · 检验我是不是真懂了

```text
我认为我理解了 ［概念］，我的理解是：
「［用你自己的话写，不要照抄定义］」

请：
1. 指出我的理解里哪里对、哪里偏、哪里明显错；
2. 给我一个我目前的理解**解释不了**的例子；
3. 出 3 道判断题，答案不要立刻给我，我先答；
4. 我答完后再告诉我对错和原因。
```

> 💡 **第 2 条最有价值**：能被反例打破的理解，说明它有边界；找不到反例的理解，往往只是背下来了。

## 模板 3 · 概念之间的关系

**适用**：一堆词都听过，但不知道它们什么关系。

```text
这几个词我都见过，但分不清关系：［词1］［词2］［词3］…

请：
1. 用一张表说明它们各自解决什么问题；
2. 说清它们是"同层竞争"、"上下层包含"，还是"完全不同维度"；
3. 举一个具体例子，说明这几个词在同一件事里分别在哪个位置；
4. 最容易被混淆的是哪两个？为什么容易混？
```

## 模板 4 · 从零开始的学习路径

```text
我想学会 ［目标能力］。
我的现状：［已有基础／完全零基础］
我能投入：［每天 X 小时，持续 Y 周］
我要用它来做：［具体用途］

请给我一条路径，要求：
1. 按顺序分阶段，每阶段说明"学完这段我能做什么"；
2. 每阶段给一个**可交付的小产出**（不是"看完某教程"，而是"做出某东西"）；
3. 明确告诉我哪些内容以我的用途可以先跳过；
4. 标出每阶段最容易卡住的地方和卡住时怎么办。

不要给我一份大而全的书单。
```

> 💡 **关键约束是最后那句**。不加它，你会得到一份永远不会看完的清单。

## 模板 5 · 把长材料变成能学的东西

**适用**：一篇论文、一本书的章节、一份长文档。

```text
材料：［贴原文或说明来源］
我的背景：［…］
我想用它来：［…］

请按这个顺序处理：
1. 一句话说清它的核心主张；
2. 它想解决什么问题，为什么这个问题重要；
3. 它的论证链条（前提 → 推理 → 结论）；
4. 哪些是它的证据、哪些是它的推测；
5. 它成立需要什么条件？什么情况下不成立？
6. 这里面哪 3 点跟我的用途最相关；
7. 我读完后应该能回答哪 3 个问题（用来自测）。
```

## 模板 6 · 费曼式讲给我听

```text
请把 ［概念］ 讲给我听，分三个层次，一层一层来：
第一层：讲给完全没接触过的人，只用生活里的东西打比方
第二层：加入这个领域真正用的术语，并说明每个术语对应第一层里的哪个东西
第三层：说明这个比方在哪里会失效——比方的边界在哪

每一层讲完停下来问我"这层清楚了吗"，我说清楚了再讲下一层。
```

> ⚠️ **第三层是关键**。所有比方都会在某处失效，不知道失效点的比方会变成误解的源头。
