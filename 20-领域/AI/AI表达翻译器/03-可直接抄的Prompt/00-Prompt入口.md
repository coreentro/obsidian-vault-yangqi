## 🧱 万能骨架（所有模板的底层结构）

```text
【目标】我要拿到什么（一句话，说交付物不说过程）
【背景】我是谁、什么水平、这东西给谁用
【材料】原文 / 报错 / 代码 / 数据（直接贴，不要转述）
【约束】不能违反什么（时间、能力、不能动的部分、篇幅）
【不要】明确的反例（比正例更能收敛结果）
【输出】什么形态（几段？表格？代码？可直接发出去的话？）
【验收】我会用什么标准检查（2–3 条可检查的）
```

> 💡 **只填四格就够用**：目标 + 材料 + 不要 + 验收。
> 大多数失败的 Prompt 缺的是后两格。

---

## ⚡ 三条通用加料句（可挂在任何 Prompt 后面）

**① 防幻觉**
```text
不确定就说不确定，不要补齐。把有把握的和推测的分开标出来。
```

**② 防穷举**
```text
不要列多个方案让我选。你来判断，说清理由和你放弃了什么。
```

**③ 防糊弄**
```text
做完请贴出真实证据（改动的具体内容 / 命令的实际输出 / 来源链接），不要只说"已完成"。
```
