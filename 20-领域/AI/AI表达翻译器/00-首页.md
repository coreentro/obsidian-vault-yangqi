## 🔩 核心机制：说不清 → 说得出

多数时候我们不是没想法，只有一种**感受**：

> "想高级一点但别装" · "这页看着挤" · "AI 老是答偏" · "我知道不对，但说不出改哪"

AI 不需要你会术语，但需要你把感受拆成**五格**：

```text
① 对象   我要改的到底是哪个东西？（这一段文字 / 这个按钮 / 整页节奏 / 我的工作流程）
② 效果   我想要的感觉是什么？（可信、轻快、克制、有条理）
③ 反效果 我不想要的是什么？（别花哨、别像模板、别啰嗦）
④ 约束   不能违反什么？（时间、能力、已有素材、不许改的部分）
⑤ 验收   什么结果才算做到了？（能一眼看到重点 / 手机上不折行 / 三句话能讲完）
```

> 💡 **五格里最被忽略的是 ③ 和 ⑤。**
> 只说"我想要高级感"，AI 只能猜；补一句"但别用渐变和大阴影，要能在白纸上打印出来还好看"，输出立刻收敛。

## 🧪 一条万能起手 Prompt

> 说不清的时候，不要硬憋。把这段直接贴给 AI：

```text
我现在只有一个模糊感觉：［把原话照抄，不要美化］
我最终想拿到的东西是：［结果／交付物］

请不要立刻给方案。先一次只问我一个问题，
帮我区分：我要改的对象、想要的效果、不想要的副作用、不能违反的约束、验收标准。
你每轮告诉我：你还缺哪块信息，为什么这块重要。

信息足够后，输出五样：
1. 用一句清楚的话重述我真正想要什么
2. 对应的专业说法／术语 + 一句白话解释
3. 一段我可以直接复制给 AI 的 Prompt
4. 3 条可检查的验收标准
5. 你仍然不确定的地方——不要替我补齐
```

## 🚧 不让它变成资料坟场的四条规矩

| 规矩 | 具体做法 |
|---|---|
| **一条一格** | 新词只写一张卡，卡里必须有"可直接对 AI 说的那句话"，否则不收 |
| **先用后存** | 没在真实任务里用过的 Prompt，只放 [[20-领域/AI/AI表达翻译器/05-收集与模板/待翻译收件箱\|收件箱]]，不进正式抽屉 |
| **失败也留** | Prompt 失败要记"失败在哪"，那是调试材料，不是废纸 |
| **不抄百科** | 概念卡只答四问：是什么 / 何时有用 / 改变什么 / 最易误解什么 |
