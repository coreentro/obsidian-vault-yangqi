# Prompt 卡片模板

> 🎯 **用法**：某段 Prompt 在真实任务里成功过，才值得做成卡。
> ⚠️ **没用过的先放** [[20-领域/AI/AI表达翻译器/05-收集与模板/待翻译收件箱|收件箱]]。

---

## 骨架（复制这段）

```markdown
## ［这个 Prompt 干什么］

**⏰ 适用时机**：［什么情况下掏出它］

**❌ 我最初怎么说的（失败版）**
> 「［原话，照抄，不要美化］」

**为什么不行**：［缺了对象／效果／反例／约束／验收 中的哪几项］

**✅ 可直接抄的版本**
```
［带 ［方括号槽位］ 的 Prompt］
```

**✅ 有效标志**
- ［怎么看出这次它对了］

**🔧 失败时的补救追问**
- ［一句话把它拽回来］

**🚫 不适用于**
［边界：什么情况别用这个］
```

---

## 五个必填项

| 栏位 | 为什么必填 |
|---|---|
| **适用时机** | 没有它，三个月后你不知道该什么时候用 |
| **失败版原话** | 这是最值钱的一栏——它记录你的**默认表达习惯**，也就是你会反复犯的错 |
| **槽位** | 没槽位就抄不走 |
| **有效标志** | 没有它，你不知道这次是真成了还是碰巧 |
| **补救追问** | 一半的情况下第一轮不会成，这一栏救场 |

> 💡 **"失败版原话"照抄不要美化**。你会发现自己反复漏掉同样的东西（通常是反例和验收标准）。

## 一个填好的例子

```markdown
## 让 AI 先问我，别急着给方案

**⏰ 适用时机**：我想做某件事但自己没想清楚，一开口 AI 就给一大套方案

**❌ 我最初怎么说的（失败版）**
> 「我想做一个知识库，你觉得该怎么弄？」

**为什么不行**：没说用途、没说给谁用、没说约束。
AI 只能给一套通用方案，我看着"好像对"但用不上，还被它的框架带着往下走。

**✅ 可直接抄的版本**
```
我想解决 ［问题］，但我自己也没完全想清楚。
不要现在给我方案。
请先向我提问，一次只问一个，问到你认为已经足够理解我的真实处境和约束为止。
每轮告诉我：你还缺哪块信息，为什么这块重要。
```

**✅ 有效标志**
- 它真的一次只问一个，并且停下来等我
- 它问的问题让我想到自己没考虑过的点

**🔧 失败时的补救追问**
- 它一次列五个问题 → 「一次只问一个。重来，先问最关键的那个。」
- 它问完自己往下讲 → 「你还没等我回答。停在这里等我。」

**🚫 不适用于**
- 我已经明确知道要什么、只是要它执行的时候（那样纯浪费轮次）
- 简单事实性问题
```
