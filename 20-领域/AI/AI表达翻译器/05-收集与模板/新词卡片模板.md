# 新词卡片模板

> 🎯 **用法**：复制下面的骨架，新建一张卡。**四问填完就算合格**，不用求全。

---

## 骨架（复制这段）

```markdown
---
title: ［词］
aliases: ［英文原名］, ［常见别称］
tags:
  - AI
  - 概念扫盲
created: YYYY-MM-DD
---

# ［词］（［英文原名］）

| | |
|---|---|
| 💬 **一句人话** | ［不含术语，可以打比方］ |
| ⏰ **什么时候有用** | ［我在什么场景下会用到这个判断］ |
| ⚠️ **最容易误解** | ［①… ②… ③…］ |

**追问句：**
```
［可以直接复制去问 AI 的一段话］
```

## 对我的场景意味着什么
［具体到我自己的用途；如果没影响就写"对我目前没影响"］

## 在哪遇到的
［来源／日期］

---
相关：［链到概念地图或相关卡］
```

---

## 填写要求

| 栏位 | 要求 | ❌ 不合格的样子 |
|---|---|---|
| 一句人话 | 不含术语，最好有生活类比 | "指模型对输入序列的表征能力" |
| 什么时候有用 | 具体场景，不是"很多场景" | "在使用 AI 时很有用" |
| 最容易误解 | 必须写你**自己曾经的**误解 | 空着，或抄别人的 |
| 追问句 | 能直接复制粘贴 | "可以问问 AI" |
| 对我的场景 | **允许写"没影响"** | 硬凑一段关联 |

> 💡 **"最容易误解"这栏最有价值**。它记录的是你从错到对的那一步，比定义有用得多。

## 一个填好的例子

```markdown
# 上下文窗口（Context Window）

| | |
|---|---|
| 💬 **一句人话** | AI 的工作台面积。台面就那么大，新材料放上去，旧的就被挤下去 |
| ⏰ **什么时候有用** | 长对话开始"失忆"、长文档只看了开头、改代码把前面改好的又改坏时 |
| ⚠️ **最容易误解** | ①以为窗口大就等于记得住——塞得越满中间越容易被忽略；②以为它会主动告诉我满了，它通常不会 |

**追问句：**
```
我们这轮对话里，哪些早期信息你已经不太确定了？
请把当前有效的关键结论和约束重新总结成一段，我们以这段为准继续。
```

## 对我的场景意味着什么
整理长论文和长对话时，别指望它记得住全部。每隔一段让它"重新总结当前共识"，
用总结替代原始长对话——比祈祷它记得住有效。

## 在哪遇到的
2026-08-17 建库时整理
```

## 🚫 什么不该做成卡片

| 不做 | 原因 |
|---|---|
| 我永远不会用到的概念 | 记了也不会想起来 |
| 只能抄百科定义、说不出人话的 | 说不出人话说明还没懂，先留收件箱 |
| 一次性的、会过期的 | 版本号、价格、某产品当前功能 |
