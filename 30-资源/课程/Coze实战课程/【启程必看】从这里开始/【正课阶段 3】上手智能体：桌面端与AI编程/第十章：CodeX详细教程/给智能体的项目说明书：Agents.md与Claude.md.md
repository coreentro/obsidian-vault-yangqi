那这时候就一定会产生一个问题：你的 Codex 是怎么知道你每个文件夹的作用的？

# 一、新员工入职的第一天

我们先不聊 AI，聊一个你一定经历过的场景

**想象你入职了一家新公司，老板把前任留下来的一个项目文件夹甩给你，说：五分钟，搞清楚这个项目是干什么的**

你打开文件夹，里面几十个子文件夹、上百个文件。你不可能五分钟把所有东西看一遍

这时候**你最希望的一定是前任给你留了一份说明文档**

这份文档不需要面面俱到，但它至少能告诉你：

- 这个项目是做什么的
- 文件夹结构长什么样
- 每个子文件夹是干嘛用的
- 有没有什么潜规则或者坑
- 我们在使用这个项目的时候要注意哪些约束

有了这份文档，五分钟你就能上手。没有这份文档，你可能半天都摸不着头脑

<callout emoji="✨">
**Agents.md，就是你给 AI 写的那份入职说明书**  
当 Codex 进入你的项目文件夹，它第一件事就是找这个文件  
找到了，它立马知道该怎么干活，找不到，它就只能猜
</callout>

# 二、Agents.md 是什么

**Agents.md 是一个 Markdown 文件，放在你项目文件夹的根目录下**

它的作用只有一个：**告诉 AI，这个文件夹是什么、里面有什么、你希望它怎么工作**

# 三、AI什么时候读取的Agents.md

你肯定会有个疑惑：我并没有告诉 Codex 去读取这个文档，它是什么时候读取的呢？

这个不需要我们人主动去指定，它是一种约定

他们的开发者在开发他们的时候，就把这个规则植入到了他们的大脑中

每当他们进入到一个新的项目中，他们就会在这个项目的根目录下扫描有没有叫 Agents.md 的文档，**如果有，就把它加载到上下文中**

Agents.md 不是必须的，如果没有，也并不妨碍 Codex 正常工作

# 四、为什么叫 Agents.md

这里简单说一下背景，帮你理清一个容易混淆的点

最早做桌面端智能体的是 Anthropic 这家公司，他们做了 Claude Code。他们定了一个约定：

**AI 进入文件夹时，默认找一个叫 `CLAUDE.md` 的文件**

后来 Codex、WorkBuddy 这些工具出来了，他们说：凭什么入口文件要叫 Claude？我又不是 Claude 家的

于是他们定了一个更通用的名字：**`Agents.md`**

<callout emoji="✨">
**CLAUDE.md 和 Agents.md 是同一个东西，只是不同约定的叫法不同**
- 你用 Codex → 放 `Agents.md`
- 你用 Claude Code → 放 `CLAUDE.md`
- 内容写法完全一样，只是文件名不同
</callout>

如果你以后同时用多个工具，两个文件都放一份就行。内容保持一致

所以你看我们的案例里面两个都有，目的就是你这套系统可能不仅给 Codex 用，还可能给 Claude Code 用

# 五、渐进式加载：AI 不需要一次读完所有东西

随着我们的文件夹越来越多，系统越来越庞大，难道我所有的规则都要塞进 Agents.md 里吗？

答案是：**不需要，也不能这样设计，因为太浪费上下文了**

这时候我们就要用到一个理念：渐进式加载，AI 不需要一次读完所有东西

---

我们用公司业务进行类比：你去一家陌生公司对接业务

你一定会首先找这家公司的对接人，了解一下公司的全貌，假设这家公司的对接人就是他们的老板

然后老板告诉你说，他会给你讲公司的组织架构、愿景、文化，还有一些重要的规范。

并且告诉你说，他们公司有三大部门：

1. 拍摄部（如果你要拍摄，去找小 A）
2. 剪辑部（如果你要剪辑，去找小 B）
3. 文案部（如果你要写文案，去找小 C）

这时候你的需求是写文案，所以你去找了小 C，**而小 C 会详细地告诉你写文案的流程和规范**

所以你看，企业老板不需要了解公司所有的信息，它是一个类似信息分发的模型

> 原图未迁移 · [飞书原图](https://feishu.cn/file/VU96b6yvWo3OZhxAvhxcfb9Dnqd) · `VU96b6yvWo3OZhxAvhxcfb9Dnqd`

**AI 也是这样，它先读根目录的 Agents.md，了解整体架构**

然后在 Agents.md 里面会告诉它每个文件夹是做什么的，并且可以约定好：如果想详细了解某个文件夹，请去读该文件夹下的 README.md

**等到它需要深入某个子文件夹时，再去读那个文件夹里的 README**

```
AI内容工作台学习版/
├── Agents.md          ← 老板：告诉你公司是干什么的
├── 01 素材管理/
│   └── README.md      ← 部门经理：告诉你素材管理的规矩
├── 02 内容创作/
│   └── README.md      ← 部门经理：告诉你内容创作的规范
```

这个机制叫**渐进式加载：**AI 不是一股脑把所有文档都读一遍，而是一层一层、需要时才深入

<callout emoji="✨">
**只有 Agents.md（或 CLAUDE.md）是约定好的，AI 会自动去找**
  
子文件夹里的说明文档叫什么名字都行，README 也好、规范也好，你自己定
  
你在 Agents.md 里指一下路就行：素材管理的详细规则见 `01 素材管理/README.md`
</callout>

我们这个迷你系统还不需要用到渐进式加载，因为它足够小，一份 Agents.md 就够了

但你要知道这个机制。当你的系统长大了，你不需要把所有规则挤在一个文件里
