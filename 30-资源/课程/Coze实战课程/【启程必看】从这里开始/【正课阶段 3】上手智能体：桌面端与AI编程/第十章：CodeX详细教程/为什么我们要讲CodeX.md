# 为什么我们要讲CodeX

# 写在前面

你好，我是大圣

前面一直跟大家分享，CodeX、Claude Code、WorkBuddy 都是同一类工具

那为什么在我们的教程里，要以 CodeX 为例来进行讲解？

# 一、为什么CodeX会火

如果你一直关注 AI 的信息，从 2026 年初开始：

1. 先火的是 OpenClaw（也就是"小龙虾"）
2. 然后再火的是 Claude Code、爱马仕
3. 现在最火的是 Codex

首先，OpenClaw 的火跟 DeepSeek 非常像，你可以认为 DeepSeek 的火让人们认识了 AI，而 OpenClaw 的火让人们认识了智能体

但我一直不建议大家去折腾 OpenClaw，因为我认为 OpenClaw 是给高阶玩家玩的，99% 的人还不到那个阶段

**那为什么先火的是 Claude Code，然后再火的是 Codex 呢？两个原因：**

第一：Claude Code 比 Codex 先出来，Claude Code 是桌面端智能体的鼻祖，所以 Claude Code 先火

第二：Codex 出来之后，因为 OpenAI 要抢 Anthropic 的用户，所以它的**风控策略比较低**，它的 20 美金额度是 Claude 同等价位的五倍不止

并且 Codex 这个 App 越做越好用，在上面加了很多的功能。它不仅成本比 Claude Code 低，使用体验也越来越好。

所以 Codex 火了

---

这里我想给大家分享的是，你如果是一个圈外人，经常关注 AI，但是没有体系化地学过，你一定会被这些反复火的名词折腾得一团乱麻

但如果你是圈内人，你会发现其实大家玩 AI 很现实：谁家的模型不封我号，谁家的模型便宜又好用，我就跑往谁家。

然后自媒体博主就会去写对应的教程，发对应的短视频，所以你的感觉就是它火了。

**所以我才一直跟大家讲，你要学 AI 的底层逻辑，否则你一定会被不断地牵着鼻子跑**

# 二、学了CodeX还用学其他的么？

这是一个非常重要的问题

我一直跟大家强调，我们学习咱们的课程一定要学底层逻辑，一定要举一反三

因为 AI 工具太多了，如果你一直浮于表面，那你的学习就永无止境

Claude Code、Work Buddy、Kimi Work、CodeX，它们本质上是一类工具，底层逻辑是一模一样的

我在做课程的时候，我会从底层逻辑出发，而不只是给你讲工具的操作

我的出发点一定是希望你学了 Codex 之后，其他的能够无痛上手
