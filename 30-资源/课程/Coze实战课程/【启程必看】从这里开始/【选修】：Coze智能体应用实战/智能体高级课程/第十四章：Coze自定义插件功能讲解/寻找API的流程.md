# 写在前面

大家好，我是大圣，这节课给大家讲解一个我们该如何找到API文档

在学习本节课之前，请确保你已经对API的概念有了一个充分且深刻的认识

# API的作用

这里我再次重申下API的作用，API可以让我们集成外部的能力。

在写少量调用代码的情况下就可以让你的智能体拥有无限的扩展能力

我们在学习Coze的时候，其中的插件其实就是一个个封装好的API。

这些插件仅仅把输入和输出暴露给用户，用户根本不用关心内容的实现逻辑。

调用外部的API也是同样的道理。

例如你想要实现文本转语音的能力，你自己肯定没有这样的功能，那该怎么实现呢？

就是我们找到外部的API服务商，通过付出一定的金钱成本，然后直接调用对方的能力。

调用API最大的好处就是，你只用关心输入和输出，其中的处理逻辑你根本不需要关心。

所以我才将API称为非程序员的外挂，他可以让我们做一个集成方，而不是技术开发方，我们只管关注应用层

# API调用两个场景

对于非技术人员来讲，如何找到满足自己需求的API才是最关键的。

这里会有两种情况

1. 你需要的能力是海外公司提供的
2. 你需要的能力是国内公司提供的

对于第一种情况，大家要注意，这时候你还要解决网络问题。

举个例子：

你想要使用ChatGPT的API接口，但是ChatGPT是海外的产品，你直接调用是不通的，这时候非技术同学不要自己去折腾网络问题，而是要找国内的API服务商帮你解决。

换句话说就是：你连接的还是国内的服务商，他们帮你做了中转服务，你只要给钱就行了

# API接入流程

当你意识到你自己需要使用外部API的时候，你接下来要做这么几件事情

1. 去网上搜索或者朋友询问，你想要接入的能力有没有API接口
2. 如果有，你可能会找到多家API服务商，你可以进行比价
3. 如果确定好了某家API服务商，你就需要阅读他的API文档（如何接入API）
4. 在自己的系统中（例如智能体）通过某种方式接入这个API

这里面有几个小技巧跟大家说下：

<callout emoji="💡">
- 一些关于文本转语音，数字人，图像识别等功能，大厂一般都有这个能力
- 可以保存一些比较靠谱的API服务提供商，一般你需要的通用能力他们都有支持
- 不仅要考虑API的价格，还要考虑稳定性，再便宜经常崩也不行
- 大厂的API虽然稳定，可能也便宜，但是接入有时候很复杂，这时候可以考虑第三方平台
</callout>

各家的API调用流程都不会完全相同，所以你需要掌握的是底层逻辑，我这里列出几个通用的概念

## API文档

API文档就是一篇文章用来告诉你这个API的输入和输出是什么，每个字段的含义。

## 异常处理

注意，在程序的概念中，一定会存在异常，你调用任何API都有可能发生错误

API的服务商大概率也会告诉你什么样的返回代表什么样的错误

这里我们不展开，这种就属于开发层面的一些东西了

## 在线体验

在线体验的意思就是你直接可以在他们的网站上就可以直接调用这个API，查看输入和输出。

提前体验下，看下是否符合你的预期

## 充值付款

一般来讲，任何的API调用都是付费的，所以你需要预先充值，然后按照调用次数或者某种方式消耗

注意：除非绝对信任，否则任何平台都不建议一次充很多钱，防止平台跑路

## 鉴权方式（API KEY）

这个所谓的鉴权方式，通常情况下叫做API KEY，是你调用这个API的身份标识

通俗的来讲就是：当你调用这个API的时候，API服务商需要能够识别是你调用的，从而来判断你有没有付费，有没有权限，以及对应的扣除你的钱

就跟我们登陆任何网站需要账号密码是一样的。

注意：API KEY是最简单的鉴权方式，还会有其他的鉴权方式
