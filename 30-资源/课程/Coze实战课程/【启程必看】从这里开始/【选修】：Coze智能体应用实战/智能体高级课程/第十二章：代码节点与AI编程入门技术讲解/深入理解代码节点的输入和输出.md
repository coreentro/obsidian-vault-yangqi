学完这节课，我希望你可以了解如何正确配置一个代码节点的输入和输出，以及它的含义是什么

## 获取输入

在上面完成输入配置之后，代码中到底是如何获取输入的呢？这就是我们接下来要讲的重点

**在上述的输入配置中，其实给到代码节点的的真实JSON输入：**

```JSON
{
    "params":{
        "inputStr":"徐州#杭州#贵州"
    }
}
```

其中外层的那个**params**是固定，**是Coze自动带的，不需要我们关注**

所以你会发现代码中的第一行都是：**params = args.params**

这行代码的含义是我们获取到输入的参数，并且赋值给params这个变量

**在这个案例中当我们拿到params的时候，我们其实是获取到了如下一个JSON**

```JSON
{
    "inputStr":"徐州#杭州#贵州"
}
```

**如何引用输入参数？**

在代码中，你可以通过**`params['inputStr']`**的方式获取输入参数的值。

其中input_string的变量的值如下：

```Plain Text
徐州#杭州#贵州
```

**PS：这其实本身是Python的语法逻辑**

其中**inputStr**是你在输入部分定义的参数名。

让我们结合截图来更直观地理解这三者之间的关系。

![图片展示了“字符串转数组”代码节点的输入、代码和输出配置界面。输入部分定义了参数名“inputStr”；代码部分定义了参数获取方式，如`params\['inputStr'\]`；输出部分变量名为“result”，类型为Array<String>。图片与上下文紧密相关，直观呈现了代码节点中输入、代码、输出配置的设置方式，帮助理解代码节点的输入和输出配置规则，避免在复制代码时因输入配置不一致而出错。](https://feishu.cn/file/PQKUbSkarothWnxLUiScJ6ptnvc)

**输入参数的名称和代码中获取的名称一定要一致！**

<callout emoji="💡">
 如上图所示，在输入部分，我们定义了一个名为**inputStr**的参数。
那么在代码中，我们就必须使用 `params['inputStr']` 来获取它的值。
如果你在输入部分命名为 `myInput`，在代码中却写成了 `params['inputStr']`
那程序就会出错，因为它找不到名为 `inputStr` 的输入参数
**PS：这是大部分学员在复制别人代码时最容易犯的错误，只复制代码，不复制别人输入配置和输出配置**
</callout>

## 编写核心处理逻辑

当我们获取到输入之后，就可以编写核心的处理逻辑啦

在本文的案例中，核心处理逻辑就是将输入的字符串，转换成数组

```Python
input_string = params['inputStr']
# 使用split方法将字符串分割成列表
result_list = input_string.split('#')
```

这里你可能会产生疑问，我就是不会写处理逻辑呀，不要着急，这些逻辑我们后面都是让AI帮我生成的

## 输出格式化

当获取输入以及进行核心处理逻辑后，我们最后要进行输出格式化。

**所谓的输出格式化，就是你最终要输出的JSON格式，这块要和接下来的输出配置进行配合**

本案例中，我们的输出格式化代码如下：

其中我标黄的部分是固定的模版

```Python
# 构建输出JSON（必须是字典格式）
ret: Output = {
    "result": output_array
}
    
return ret
```

而我们真正想要的格式是

```JSON
{
    "result":[
        "徐州",
        "杭州",
        "贵州"
    ]
}
```

# 输出配置

最后就是进行输出的配置了，这里非常简单，但是有好多小伙伴也会踩坑

这里需要注意以下几点：

1. 输出的配置本质就是在配置那个JSON树状结构，所有的key的名字要和代码的名字对应上
2. 变量的数据类型也要对应上，比如这个案例的输出result是字符串数组，所以变量类型就要是Array<String>
3. 层级也要对应，这个案例没有体现，后面会有案例

> 原图未迁移 · [飞书原图](https://feishu.cn/file/OHSmbeZUHo9YU9xw8d1c3u4jn0d) · `OHSmbeZUHo9YU9xw8d1c3u4jn0d`

**重要提示：** 确保此处定义的参数名、类型与代码中 `return` 的字典对象完全一致。

**`ret` 和输出参数的关系（重点）**

`ret` 是你在代码中构建的输出字典，而输出参数则是在图形界面中定义的输出格式。这两者也必须保持一致。

- **`ret`**中的**键名必须和输出参数中定义的变量名相同**。

  <callout emoji="💡">
  例如，如果你在输出参数中定义了一个名为 `result` 的变量，那么在代码中，`ret` 字典中也必须有一个名为 `result` 的键。
  </callout>

- **`ret`中键对应的值的类型必须和输出参数中定义的类型相同**

  <callout emoji="💡">
  例如，如果你在输出参数中将 `result` 的类型定义为 `Array<String>`，那么在代码中，`ret['result']` 的值必须是一个字符串数组。
  </callout>

# 回看代码模版

**Coze 提供的代码模板（Python）：**

```Python
async def main(args: Args) -> Output:
    params = args.params
    ret: Output = {
        "key0": params['input'] + params['input'],
        "key1": ["hello", "world"],
        "key2": {
            "key21": "hi"
        },
    }
    return ret
```

依据我们上面讲解的理论，我想你已经完全可以自己看懂这个官方案例了。

这里让我们再把模版简化一下：

```Python
async def main(args: Args) -> Output:
    # 从args中获取输入参数
    params = args.params
    
    # 在此处理输入并生成输出所需要的数据
    
    # 构建输出JSON
    ret: Output = {
        # 在此构建输出JSON
    }
    
    # 返回结果
    return ret
```

**代码模板解读：**

- `async def main(args: Args) -> Output:`：

  <callout emoji="💡">
  这是 Coze 要求的代码规范，你无需深入理解，只需按照这个格式编写代码即可
  </callout>

- `params = args.params`：

  <callout emoji="💡">
  **这行代码非常重要！**
  它表示获取输入数据，并将输入数据赋值给 `params` 变量，供后续代码使用。
  这里的 `args.params` 就是获取输入的 JSON 结构。
  </callout>

- `ret: Output = { ... }`：

  <callout emoji="💡">
  这段代码定义了输出数据的格式和内容。`key0`、`key1`、`key2` 是输出的键（key），它们对应的值（value）可以是各种数据类型。
  </callout>
