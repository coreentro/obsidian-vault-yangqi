# 批处理该如何使用

我一直强调，对于工作流中的任何节点，**其实都是给定一个输入，产生一个输出。**

对于单次的处理，我们只需要给定一个输入，对应的也会得到一个输出。

而对于多次处理，我们需要给到的是则是一批输入，对应的也会得到一批的输出！

**在编程概念中，是如何表征一批的概念的呢，答案就是数组**！

为了方便大家理解，我再举个例子：

你的需求是想要读取文章的链接

- 如果你是单次处理，那么你的输入就是一个文章链接的字符串

```Plain Text
"https://mp.weixin.qq.com/s/zIdVewXo-1zRNWeZo_9Axg"
```

- 如果你想要使用批处理，比如你一次性想要处理3篇微信公众号文章，那么你的输入就是一个数组

```JSON
[
    "https://mp.weixin.qq.com/s/zIdVewXo-1zRNWeZo_9Axg",
    "https://mp.weixin.qq.com/s/cnxJLi6McH7m0eItFGYJDw",
    "https://mp.weixin.qq.com/s/dak9kb9RSPB-dUWoRrFOQg"
]
```

**这几个链接使用英文的逗号进行分割，用来做教学案例**

**请自行找3个公众号文章链接，并且用英文逗号进行分隔作为测试案例**

```Plain Text
https://mp.weixin.qq.com/s/zIdVewXo-1zRNWeZo_9Axg,https://mp.weixin.qq.com/s/cnxJLi6McH7m0eItFGYJDw,https://mp.weixin.qq.com/s/dak9kb9RSPB-dUWoRrFOQg
```

# 批处理的输出

上面讲了单次和批处理的输入的区别，那他们输出的区别呢？

其实也是类似的：

- **在单次处理中，输出是一个对象**
- **在批处理中，输出则是一个对象的数组**

举例说明，在下面这个例子中我们通过LinkReaderPlugin讲解了插件的使用姿势

1. 在**单次处理**时，他的输出数据格式如下，你会发现，这是一个JSON对象

```JSON
{
  "data": {
    "content": "2021-09-27 12:18:00亚马逊李沐：..为了提升阅读体验，这里做一些省略",
    "title": "亚马逊李沐:用随机梯度下降来优化人生"
  },
  "error_code": "",
  "error_msg": ""
}
```
