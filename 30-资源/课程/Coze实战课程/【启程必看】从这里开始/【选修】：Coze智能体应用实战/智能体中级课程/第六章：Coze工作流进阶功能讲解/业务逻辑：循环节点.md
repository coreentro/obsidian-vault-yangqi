# 为什么需要循环-Why

想象一下以下的日常场景：

1. 洗碗工：你是一个洗碗工，你每天的事项就是洗完一箩筐的碗：你的做法如下：

   1. 确定洗碗的过程：“拿起碗，涂上洗洁精，冲洗，擦干”
   2. 每次拿起一个碗，进行洗碗动作
   3. 重复洗碗的过程
   4. 直到箩筐里没有碗之后，停止今天的洗碗工作，下班

1. 发送群组消息：假设你需要给50个朋友发送国庆节日祝福，你的做法如下：

   1. 编辑好一段国庆节日祝福的文案
   2. 在自己的好友列表中找到这50个朋友
   3. 针对每个朋友进行国庆祝福文案的发送
   4. 直到把最后一个好友发送完成，事情结束

1. 健身：你决定做50个俯卧撑作为日常锻炼。过程如下： 

   1. 确定正确的俯卧撑姿势
   2. 做一个俯卧撑
   3. 数一下已完成的次数
   4. 重复步骤b-c，直到完成50次

在这些例子中,我们可以看到一些共同点：

- **有一个明确的重复动作**
- **这个动作会被执行多次**
- **有一个结束的条件（**所有碗洗完，所有朋友都收到消息，做完50个俯卧撑）

在编程中，我们经常遇到需要重复执行某些操作的情况，这与上面的日常例子非常相似：

- 处理一个列表中的所有元素（如给50个朋友发消息）
- 重复某个动作直到达成特定条件（如洗完所有的碗）
- 按照固定次数执行某个任务（如做50个俯卧撑）

如果没有循环，我们就需要一遍又一遍地写相同的代码。

例如，假设我们要在没有循环的情况下打印"你好"5次，我们会写如下的代码

```Python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```

这种方法不仅繁琐，而且如果我们想改变打印次数,就需要手动增加或删除代码行。

而有了循环,我们可以这样写：

```Python
for i in range(5):
    print("Hello")
```

# 循环的定义-What

<callout emoji="🎹">
**编程语言是现实世界的抽象，它的存在是为了让工程师更好更快的解决现实中的问题**
因为我们现实世界中有这种循环往复的行为，因此在编程语言中也针对这个行为进行了**语法抽象**。
</callout>

所以关于循环的定义，我们从两个方面来看

## 现实世界的定义

在现实世界中，循环是指重复执行某个动作或过程，直到满足特定条件为止。

这是一种自然而然的行为模式，我们在日常生活中经常使用。

## 编程语言的定义

在编程中，循环是一种控制流结构，允许基于某个条件重复执行一段代码。

它使得我们可以用简洁的方式表达重复的操作，而不需要多次书写相同的代码。

主要有两种类型的循环：

### for循环

for循环用于遍历一个序列（如数组）或执行固定次数的操作

基本语法：

```Python
for 变量 in 序列:
    # 要重复执行的代码
```

其主要应用场景

- 处理一个列表中的所有元素（如给50个朋友发消息）
- 按照固定次数执行某个任务（如做50个俯卧撑）

### while循环

while循环:在满足特定条件时持续执行。 

基本语法：

```Python
while 条件:
    # 只要条件为真，就重复执行的代码
```

其主要应用场景

- 重复某个动作直到达成特定条件（如洗完所有的碗）

# 如何实现循环-How

本文并不是语法教程，所以并不会对语言进行详细的拆解。

我们从两个简单的编程示例入手，让大家感受下Python语言中是如何实现循环的

## for循环

基本语法:

```Python
for 变量 in 序列:
    # 要重复执行的代码
```

例子: 打印列表中的每个水果

```Python
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(fruit)
```

输出:

```Plain Text
苹果
香蕉
橙子
```

## while循环

基本语法:

```Python
while 条件:
    # 只要条件为真,就重复执行的代码
```

例子: 模拟存钱罐存钱过程

```Python
target = 100  # 目标金额
savings = 0   # 初始存款

while savings < target:
    amount = int(input(f"当前存款: {savings}元。请输入要存入的金额: "))
    savings += amount
    print(f"已存入 {amount}元，当前总存款为 {savings}元")

print(f"恭喜！你已经存到了 {savings}元，达到了 {target}元的目标！")
```

这个例子模拟了一个存钱的过程：

1. 我们设定了一个存钱目标（100元）。
2. 程序会不断询问用户要存入的金额，并更新总存款。
3. 当总存款达到或超过目标金额时，while 循环结束。

让我们看一下这个程序的模拟运行结果：

```Plain Text
当前存款: 0元。请输入要存入的金额: 30

已存入 30元，当前总存款为 30元

当前存款: 30元。请输入要存入的金额: 50

已存入 50元，当前总存款为 80元

当前存款: 80元。请输入要存入的金额: 25

已存入 25元，当前总存款为 105元

恭喜！你已经存到了 105元，达到了 100元的目标！
```

# Coze中的循环节点

## 循环节点的三种类型

### 使用数组循环

就像翻阅一本书的每一页，数组循环会依次处理一组数据中的每个元素。

**关键概念：**

- **item**：**当前正在处理的元素**
- **index**：当前处理到第几个元素（**从0开始计数**）
- **数组长度**：总共要处理多少个元素

**实际应用示例：**

```JSON
数组：[10, 20, 30, 40, 50]
第一次循环：item = 10, index = 0
第二次循环：item = 20, index = 1

...以此类推
```

### 指定循环次数

就像设定闹钟响几次，你可以明确指定要重复执行多少次任务。

- 可设置1-1000次
- 支持引用其他节点的数值作为循环次数

### 无限循环

像永动机一样持续运行，直到遇到终止条件才停止。

**适用场景：**

- 批量处理数据
- 增强搜索功能
- 回合制游戏逻辑

**设置变量**

设置变量和普通的变量节点不一样，这个设置变量是为了设置中间变量的值的。

**终止循环**

终止循环则是为了在无限循环中在达到某种条件时终止循环

### 重要规则

- ⚠️ **循环之间是串行执行，不支持并发（和批处理是两码事）**
- ⚠️ 不支持嵌套循环
- ⚠️ 循环节点中不能添加批处理节点
- ⚠️在循环体内添加节点的时候，**一定要先点击循环体（否则你的节点会加到循环体外面）**

### 使用中间变量

**中间变量就像接力棒，可以将一次循环的结果传递给下一次循环使用。**
