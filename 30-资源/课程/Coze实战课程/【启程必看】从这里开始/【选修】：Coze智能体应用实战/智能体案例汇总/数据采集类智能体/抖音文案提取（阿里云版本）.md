# 二、获取抖音文案插件

学员推荐的一个插件：https://www.coze.cn/store/plugin/7486709193416753202?from=store_search_suggestion

这个挺好用的，自己可以申请下阿里云的api key

<callout emoji="🎹">
这个插件是一个两个功能合二为一的插件：
第一个功能：通过爬虫手段根据抖音链接获取抖音的音频地址
第二个功能：通过阿里云的语音转文本能力将音频地址转化为文本输出
</callout>

**这个插件只能用来提取单篇视频的文案，没有办法做到根据关键词查询视频等功能**

## 费用情况

首先这个 API 肯定是收费的，但是收费极其低。好像还有免费的 token赠送，我目前使用了一段时间，还没有看到账单

为了可以使用这个 API，你可以在你的阿里云账号上充值一些费用

建议充值 10 块左右，不要多，用一段时间看看消费情况

地址如下：https://home.console.aliyun.com/home/dashboard/ProductAndService
