# Coze插件如何调用异步API

<callout emoji="💡">
这个来自于社群小伙伴 @醒 的分享，不是那么细节，但是思路很清晰，足够使用了
这个思路抽象来看如下：
1. 提交任务，拿到任务标识
2. 使用这个任务标识轮寻任务结果，固定时间间隔
3. 服务端返回任务结果，失败或者成功，轮寻结束
</callout>
