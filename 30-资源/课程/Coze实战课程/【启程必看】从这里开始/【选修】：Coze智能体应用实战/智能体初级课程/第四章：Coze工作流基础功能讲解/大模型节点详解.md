# 什么是大模型节点

大模型节点可以让我们在工作流中使用大模型的能力

# 如何配置大模型节点

## 模型选择

在Coze中应该选择哪个大模型，这个可以延伸阅读的文章

## 模型的设置

这里面主要需要关注的内容是：

1. 最大回复长度：最大值8192（**这个字段决定了大模型单次输出的长度**）
2. 其余的字段我一般不关注，大家感兴趣请自行AI

## 输入配置

输入配置就是设置这个模型节点需要的输入参数。

主要是为下面的系统提示词和用户提示词作准备

## 提示词设置

提示词大家都不陌生，但是Coze中有两个概念

分别是系统提示词和用户提示词，这两个概念容易把一些小伙伴搞懵。

感兴趣的小伙伴，请关注延伸阅读部分：[系统提示词和用户提示词的区别](https://axsppz4oyvj.feishu.cn/wiki/EanAwcFyOiCu6ak09xMc6r5Jn8e)

总结来说就是：

1. **系统提示词（System Prompt）**

   - **定义AI助手的角色和行为，比如让大模型扮演一个内科医生**
   - 支持动态变量引用

1. **用户提示词（User Prompt）**

   - **设置具体任务指令，比如问大模型：我总是咳嗽，该怎么治疗**
   - 支持动态变量引用

## 输出设置

大模型的输出设置有三种类型，分别是String、Markdown以及JSON格式

### String

就是普通的纯文本输出

### Markdown

对于不知道Markdwon的小伙伴请先学习：[Markdown语法是什么](https://axsppz4oyvj.feishu.cn/wiki/Ot9IwBWduiQ3ONkGA3vc6lGnnUp)

### JSON

对JSON不了解的小伙伴亲请先通过下文中的延伸阅读了解JSON

JSON格式其实就是一种结构化输出，他可以让大模型的输出更加稳定。

但是这在写提示词的时候需要使用到一种经典的方式：**提供示例，例如：下面这个提示词**

关于大模型输出JSON，我们后面会有案例供大家学习

```Bash
# 角色
你是一个专业的翻译官，能够准确地将用户输入的内容翻译成目标语言，不进行随意扩写。

## 技能

### 技能 1：翻译文本
1. 当用户提供一段文本时，迅速将其翻译成目标语言。
2. 确保翻译的准确性和流畅性。

## 限制：
- 只进行翻译工作，不回答与翻译无关的问题。
- 严格按照用户要求的目标语言进行翻译，不得擅自更改。

## 输出格式

请严格使用如下JSON格式输出

当用户的翻译输入是电脑时，你的输出为：

{
"input":"电脑",
"translation":"computer"
}
```

## 设置技能

你会发现在大模型节点上有个设置技能的选项

**配置技能后，LLM节点将获得：**

- 自动意图识别能力
- 智能工具调用能力
- 更强的问题解决能力

上面是官方的解释，这确实是个很强大的技能，但是我个人不建议新手使用这个能力。

使用了工作流，我强烈建议：**尽量保持节点功能的单一性和确定性**

1. **可控性更强**

   - 独立的节点设计让工作流的执行过程更加清晰
   - **每个步骤的输入输出都是明确可控的**
2. **降低不确定性**

   - **LLM的意图识别可能并不总是准确**
   - 自动调用技能的时机和方式可能不符合预期
