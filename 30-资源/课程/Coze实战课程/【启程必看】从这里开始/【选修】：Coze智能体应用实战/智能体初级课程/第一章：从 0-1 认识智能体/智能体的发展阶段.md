# 写在前面

大家好，我是大圣，这节课我想跟大家聊一个非常重要的认知问题。

在开始学习具体的智能体工具之前，我希望你能先建立一个正确的预期。

很多人一听到智能体这个词，就会觉得它很厉害、很神奇，甚至觉得它是万能的。

但现实是：智能体叫智能，但当下并不智能。

这节课我会用一个大家都熟悉的类比：自动驾驶，来帮你理解智能体到底发展到哪个阶段了

理解了这个，你就不会对智能体有不切实际的期待，也不会因为它没那么智能而失望。

智能体的智能是终极目标

我们先来聊聊，大家理想中的智能体是什么样的？

可能是这样的场景：

<callout emoji="✨">
你说一句"帮我做一个从杭州到北京的3天旅游攻略"，
然后智能体就自己去查机票、查酒店、查天气、查景点，最后给你一份**完美**的攻略，甚至帮你订机票，订闹钟提醒你
</callout>

你什么都不用管，只需要动动嘴，这确实是智能体的终极目标。

但问题是：现在还做不到。

或者说，能做到一部分，**但做不到完美，做不到稳定，做不到你完全放心**

为什么？因为智能体的核心是大模型，而大模型本身还在发展中。

- 它有时候会理解错你的意思
- 它有时候会规划出不合理的步骤
- 它有时候会自信地胡说八道

所以，智能体这个名字，描述的是我们的目标，而不是当下的现实。

# 用自动驾驶来类比

说到这里，你可能会问：那智能体现在到底发展到什么程度了？

我用一个大家都熟悉的东西来类比：自动驾驶

你应该听说过自动驾驶的分级，从L0到L5：

| 级别 | 名称 | 谁在开车 |
|-|-|-|
| L0 | 无自动化 | 完全靠人 |
| L1 | 辅助驾驶 | 人为主，车辅助（比如定速巡航） |
| L2 | 部分自动化 | 人为主，车能做更多（比如车道保持） |
| L3 | 有条件自动驾驶 | 车为主，但人要随时准备接管 |
| L4 | 高度自动驾驶 | 车为主，大部分情况不需要人 |
| L5 | 完全自动驾驶 | 车全权负责，人可以睡觉 |

现在市面上的车，大部分在L2、L3。L5是终极目标，但还没实现

智能体也是一样的发展逻辑，智能体的发展阶段

我把智能体的发展也分成几个阶段，方便你理解：

<callout emoji="✨">
**这是我个人的定义，没有用所谓的学术定义**
原因如下：
1. 市面上没有严谨的学术定义
2. 普通人需要的是真正理解，而非严格的学术
</callout>

| 阶段 | 类比 | 智能体形态 | 谁在规划 | 你需要做什么 |
|-|-|-|-|-|
| L1 | 定速巡航 | 提示词封装 | 人定好规则 | 设计好提示词 |
| L2 | 车道保持 | 单工具调用 | 人指定工具 | 告诉它用什么工具 |
| L3 | 有条件自动 | 工作流编排 | 人搭建流程 | 提前搭好工作流 |
| L4 | 高度自动 | 自主规划 | AI自己规划 | 只需要提需求 |
| L5 | 完全自动 | 通用智能体 | AI全权负责 | 动动嘴就行 |

当前的现实是：大部分智能体产品在L1-L3阶段，L4处于开始探索的阶段

比如，我们后面会讲到的各种工具

- 豆包、Kimi上的智能体 → 大多是L1（**提示词封装）**
- 秘塔搜索、Perplexity → L2（**大模型 + 搜索工具）**
- Coze工作流、Dify → L3（**人搭建工作流，AI执行**）
- 扣子空间、Manus → L4（**AI自己规划，但还不稳定**）

L5呢？那是AGI（通用人工智能）的事情，还早，而且现在技术圈对于 AGI都没有严格的定义

# 一切皆可智能体

讲到这里，我还想纠正一个误区。

很多人会纠结：到底什么才算智能体？是不是必须有**大模型 + 规划 + 记忆 + 工具**才算？

我的观点是：不要纠结这些技术概念

回到最本质的定义：

能帮你自动完成某个特定需求的AI系统，就是智能体。

按照这个定义：

- 精心设计的提示词，能帮你自动写周报 → 这就是智能体

- AI搜索工具，能帮你总结最新资讯 → 这也是智能体

- 精心编排的工作流，能帮你自动处理文档 → 这还是智能体

智能体的价值不在于它有多少个组件，而在于它能不能帮你解决问题。

就像你拧螺丝，有时候一把普通螺丝刀就够了，不需要搬出整个工具箱。

所以，一切皆可智能体，只要它能帮你干活。

# 写在最后

这节课的核心，我希望你记住三点：

**第一，智能体当下并不智能**

它叫这个名字，是因为智能是终极目标。但现在它还在发展中，有很多局限性。不要期待它一键搞定所有事情。

**第二，智能体的发展就像自动驾驶，是一个阶段性的过程。**

从L1到L5，我们现在大概在L2-L3的位置。L4刚起步，L5还很远。

**第三，普通人不要纠结技术概念，能解决问题就是好的智能体。**

管它有没有记忆、有没有工具，能帮你干活就行。

理解了这些，你再去学习具体的智能体工具，心态会更好，也更容易学会。
