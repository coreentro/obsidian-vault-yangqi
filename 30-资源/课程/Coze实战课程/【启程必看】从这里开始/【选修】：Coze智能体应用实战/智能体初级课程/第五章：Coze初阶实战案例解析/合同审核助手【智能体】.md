# 写在前面

大家好，我是大圣，这个案例我们手搓一个合同审核的智能体。

这个案例的核心是提示词还有插件，我希望通过这个案例让大家了解提示词和插件的重要性

# 需求分析

用户上传一个合同，可以对合同进行审核

具体分如下几步：

1. 用户上传一张Word或者PDF的合同
2. 通过插件读取合同的内容
3. 通过大模型将合同中的基本信息提取出来
4. 通过另一个大模型对合同进行初次审核
5. 将审核结果保存下来，并且生成PDF和思维导图
6. 对审核的结果进行复审，生成PDF和思维导图
