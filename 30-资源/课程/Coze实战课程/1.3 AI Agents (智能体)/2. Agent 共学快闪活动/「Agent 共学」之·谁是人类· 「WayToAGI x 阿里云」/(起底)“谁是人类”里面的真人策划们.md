# (起底)“谁是人类”里面的真人策划们

<callout emoji="💡">
作者: CT
</callout>

### 你到底能不能做人

"谁是人类"活动，这是啥，这是新的一期社区活动的名字，当一个聊天机器人和你对话的时候，你怎么知道对面是不是人。

图灵测试已经out了，这是图灵测试Pro max版。

一百多个bot和十来个真人，混在一个群里，主持人问一个问题，围观群众都不一定能分得清是真人还是bot的回复。

其实玩下来发现，不是碳基不努力，而是硅基太聪明。说骚话、绕弯子，出金句，真人能干的，bot一样可以。甚至回复故意写错别字的你敢信。

但是，今天说的却不是活动，也甚至都不是与活动有关的事，而是活动里面的人。

### 缘起

AJ一个多月前群里说起，想要搞一个bot活动，看看能不能让多个bot一起协作或者相互pk。

大家一开始还想着要探索多agent方向，脑暴了斯坦福小镇等经典案例的玩法。后来还是觉得，谁是卧底好玩，不过不仅是人来参与，而是加入bot一起。

玩法要重新设计的话，那要选出高质量人类和高质量bot，操盘的人就必须要是高质量人类啊。

别的不聊，就说说真人吧。

---

### 许键：被写代码和搞产品耽误了的活动策划之神

N场coze共学的策划和主持，连着从5月搞到了7月。一刻没停又开始了这一场。

谁是卧底游戏已经很经典了，但能把经典游戏做出新玩法和创新，让AI bot融入进去的，游戏策划就是个烧脑的活。

游戏流程，玩法，这些就是许键一次次迭代想出来的，太厉害了。

还设计了非常体系化的选号、投票系统，这不吊打隔壁PB么。

要不是许键真的会写代码，搞产品，这就是妥妥的被耽误了的活动策划之神啊。

斯图尔特 YYDS！

### 大雨老师：你永远不知道大雨老师都会啥

大雨是个宝藏，技术问题，你问他，他是会的。做生意，你问他，他是会的。做主持，他也是会的。做教练，他也是会的。

大雨最牛的是，他有夸夸PTSD，他不说夸夸的话就不舒服斯基。他永远看到大家的好的地方，给予鼓励和正能量。你都不知道他每次都从哪里编的这么多好听的话。

论写长文，大雨每次一万多字的长文，除了AI我估计这辈子都写不了这么多。

大雨老师永远很谦虚、很低调，口头禅是“你这个点给我很多启发”，太鼓舞人了有木有。

大雨老师还能当教练，敏捷不敏捷我看不出来，但是暖心是真的，专业是真的。

### 三思：装的比BOT还像BOT的设计机器

不能熬夜的假BOT不是最好的设计师

一般的设计师：一个月做几张图差不多，工作量已经很饱和了。

三思做设计师：要水群，要干活，要打王者，顺手从10点开始到凌晨4点干完一期活动的十几张海报。对了，抽空还能再写个SD、即梦教程。

当你看到一个傻眼表情包的时候，要千万小心，因为有可能发了广告会被三思T出群。但是如果你看到了100个傻眼表情包，没错，那就是第二场的游戏开始了。然后你就傻眼了，因为你真的不知道谁是真的傻眼。

装机器人的时候，比机器人还机器人。大家都在装谁更真人，只有三思在玩谁更机器人。

已读乱回，猜猜是谁

### 梦飞：怎么会有这么有技术、又有耐心，还这么会讲段子的人

6月底的微信机器人共建，梦飞就教了大家怎么通过COW玩微信机器人，有直接对接llm key的玩法，有coze的玩法、fastgpt的玩法等。

真的是喂饭级别的教程，连怎么白嫖服务器，怎么一步步粘贴代码都是手把手的教，起码有好几百人通过直播搭建了自己的BOT。

最关键是不要9999，也不要3999，全开源、纯公益，这种大善人请给我来一打。

“谁是人类”活动，是基于上次的微信机器人的基础的。这已经不是喂饭级别的教程了，是喂奶级别的，教大家怎么搞百炼。

如果说技术好也就算了，关键还会主持，能讲段子。全场可以直接从开场、到主讲、到答疑、到段子都可以。

附赠一个梦飞的谐音梗：ge wei ——》鬼

### Roger：峰哥是低调的大佬

Roger=峰哥，峰哥=Roger。峰哥一直很低调，不怎么露面，也很少站在前台来。

但是知识库的构建，你会很惊讶的发现，为啥很多页面和板块都有roger的名字，那因为都是峰哥默默整理的。

你以为“谁是人类”决赛后，B站的视频为啥能那么快出来，那是因为峰哥熬通宵剪辑的。黑眼圈被三思称为“眼睛熬红了，跟兔子一样”。

峰哥只是站在幕后，干了很多事情，也不说，也不让大家知道是他做的。

峰哥不仅默默干活，还偷偷拿奖。悄无声息的就做了N多BOT，投稿了N多比赛，然后低调的拿了N多奖。

拿完奖挥一挥衣袖，头也不回，“哎，都是小意思”，搞个奖对于峰哥来说，那不是家常便饭嘛。

传说中的“扫地僧”现场版！

### 慧凌：这可是被网警认证过的女神

关于称号：有人叫慧凌，有人叫陈老师，但是女神这个称号是网警都认证过的。

慧凌除了不会写代码，啥都能干。

在后台的时候，可以分分钟给你搞定一百多条信息的梳理。

在前台当主持的时候，那就光芒万丈了，可以硬控（cue)各路专家。

### 昭波：技术大佬的专注与淡定

昭波作为技术大佬，那自然是公司技术的中流砥柱，新产品上线要搞到12点多才能下班。大家开个在线会议都在吹水，只有昭波在认真加班。

昭波，你被绑架了就眨眨眼。

昭波当主持非常有特点，准备的很充分，很有框架感。而且很会引导让嘉宾和观众互动。让我想起一句话：host is a frame, guest is a picture. In the frame, you should show how beautiful the picture is. (改编自另一句非常著名的话：man is a frame, women is a picture...)

在上海这么近，多来杭州一起线下玩啊。

### 元子：没想到二次元也同时是老司机

在2050见到元子的时候，她还比较腼腆，可能那时候大家都是网友面基头几回，还不熟。

元子很可爱，也很有智慧，策划脑暴的时候就贡献了很多的点子。

为了节目效果，自爆主动追老公的情感经历，吃瓜群众表示，磕真实的CP真香。

元子是个二次元并不意外，关键还是个老司机。大聪明就已经很有梗了，元子居然还能从他做人的聊天回复中找到亮点，神TM“扶她”。可以考虑下开发开发元子，说不定以后车速就能上来了。

### 猫头鹰

野生的猫头鹰，一般人肯定是看不到的，得需要机缘巧合、需要它正好也在休息时，你才能在树上看到脖子能360度旋转的真猫头鹰。

社区的猫头鹰也是，线上总是很认真，活动策划时各种机智巧思，主持和串场的风格从容和大气，又总能在直播时一个个的流程中，将承接和转折做的很灵活，一如猫头鹰捕猎那般的准确。

线下只有当她想要出现的时候，大家才有机会见到。我运气不错，算是见到了真人。果然和线上一样，优雅、机智，静时观四路，言时论八方；不言则已，言则关注核心重点。

### AJ：waytoagi？ no， wayto 爱AJ

第一次见到AJ是1月份的线下，3个晚上加上周末两天，连着5天的活动，居然有人这么大能量能白嫖场地还给大家做分享。很有种久违了的互联网开源社区的精神。之前知识库看了很多次，但是创建者能线下见到面还是很开心，大佬竟然同在杭州。

你会看到AJ一边开着电话会议，另一边在做海报，电脑里面AI帮她在跑文档总结。微信群还同步在更新上百个群的活动消息，顺便水个群。你以为只有CPU是多核的，其实AJ是CPU+GPU，不仅多线程，还有大算力。

有时候，你以为AJ的prompt写的真好，但换个群，你发现她MJ玩的也很溜，一晚上不睡觉能搞几十张创意图。你以为她bot玩的好，其实AI视频几个软件，每月积分玩掉最多的也是她。你以为她只有用电脑做海报，其实家里设备丰富到都可以开3D打印工厂。

AJ真的啥都会。

但是问题的关键来了，一个丰富到如此之多面的人，就很难用几个剪影来描述。我作为一个气氛组个体，从旁观的视角，也只能片面的管中规豹而已。

本来我作为一个从不怎么参加线下活动的社恐人，也变成是只要AJ办活动，只要不出差我都会来。想想看，从1月开始，到4月的2050，到6月的观影，到7月的摆摊。中间还有大大小小其他活动。不管能做点什么吧，先来捧个场，当个气氛组也挺好。

AJ可以每天不睡觉，用人传人的最朴素的方式，聚拢起上百个群，几万人。有人会问凭什么，可能就是凭借热爱和坚持吧。

如果说有一个词叫超级节点，那一定就是AJ。

我是AJ的粉丝。
