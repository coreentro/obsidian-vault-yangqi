# 芋头小宝: 热点文章生成器

> [!info] 位置
> 1.3  AI Agents (智能体) › 2. Agent 共学快闪活动 ›  Agent 搭建共学快闪 0523 › 6月5日 Roger & 周洁 bot大揭秘

# 一、Bot 简介

<callout emoji="📌">
**BOT名称**：热点文章生成器
**功能价值**：辅助自媒体创作者生成可以一键复制发布的初稿，提供创意和内容，极大节约文字内容创作时间。
**应用链接**： https://www.coze.cn/store/bot/7376204877069975561?panel=1&bid=6cnclbhdk501v
</callout>

# 二、 过程中间的心路历程

<callout emoji="😞">
**痛点**：我兼职一个自媒体创作，平常喜欢写点新闻头条，但是无奈文笔一般，想法苍白，每次创作都要吭哧1个小时以上，尤其是0-1编写的部分，如果有人能帮我写个初稿，我在它的基础上二创，那就美滋滋啦。
**需求**：有一点框架和内容的文章+文章排版和配图
**产品功能：**
1. 接收用户感兴趣的主题输入
2. 全网搜索相关新闻
3. 提炼新闻重点
4. 分析新闻影响及制定应对策略
5. 输出文章配图
6. 输出文章文档
**优化UI/UE**
1. 首页产品功能介绍
2. 用户快捷命令设计
3. 背景头像优化
</callout>

# 三、使用的插件
