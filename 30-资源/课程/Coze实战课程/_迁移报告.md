## 二、未能迁移（及原因）

### 1. 图片与音视频二进制

- **图片 3122 张**、**附件/音视频 286 个**（video/mp4 209、video/quicktime 15、application/pdf 13、application/zip 10、text/x-python 8、application/x-msdownload 5）
- **原因**：这些文档属于外部租户 `axsppz4oyvj`。飞书对**第三方应用访问外部租户二进制资源**有限制：
  - `drive/v1/medias/:token/download` → HTTP 403
  - `drive/v1/files/:token/download` → HTTP 403
  - `drive/v1/medias/batch_get_tmp_download_url` → 返回空数组
  - `drive/v1/export_tasks`（导出 docx/pdf）→ `1069902 no permission`
- **注意**：这不是你个人权限不足。文档权限查得 `security_entity: anyone_can_edit`（未开防复制），
  你在飞书客户端里可以正常查看与另存；受限的是 API 应用身份。
- **补偿**：每张图的飞书 AI alt 描述已完整保留在正文的可折叠 callout 中，语义信息未丢失；
  并附原图链接可点回飞书。完整清单见 `raw/media_manifest.json`（3408 条）。

## 四、日后补齐图片的办法

若之后拿到该租户的应用授权（或换用有权限的身份），只需：

```bash
cd ~/feishu-migration
python3 backfill_media.py     # 读 raw/media_manifest.json，逐个下载并把 callout 换回 ![]()
```

清单里每条都记了 `token` / `doc`（笔记相对路径）/ `alt`，可精确回填。
