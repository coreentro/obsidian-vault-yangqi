# 写在前面

大家好，我是大圣，这节课我们带大家学习使用现有API的方式创建插件

这个方式我们不用写代码，只要配置输入和输出即可。

这种方式非常适合我们已经拥有了现成的API

# 什么是API创建插件

如果你的插件功能就是调用API，那么Coze给你提供了一种不用写代码的方式就可以实现API调用。

你要做的就是配置输入和输出

优点：不用写代码，非常适合非程序员选手

缺点：你必须严格按照API的输入输出，如果API的设计不合理，你也没有办法
