# 什么是选择器？

我更喜欢把选择器叫做：条件分支节点

<callout emoji="💡">
条件分支节点（if-else节点）就像是工作流中的"交通指挥员"，它会根据设定的条件，决定对话应该往哪个方向继续进行。
</callout>

# 核心功能

## 条件判断

- 节点会检查输入的参数是否满足"如果"区域设置的条件
- 满足条件 ➡️ 执行"如果"分支
- 不满足条件 ➡️ 执行"否则"分支

## 多重条件支持

- 可以设置多个判断条件
- 支持"且"（AND）和"或"（OR）逻辑
- 例如：

  - 条件1：用户年龄 > 18
  - 且
  - 条件2：用户已注册会员

## 多分支管理

- 不限于简单的是/否两个分支
- 可以添加多个条件分支
- 通过拖拽方式调整分支优先级

# 使用技巧

在使用选择器的时候，对于各个条件一定要注意：

<callout emoji="💡">
- **重要或常用的条件建议放在前面**
- **通过拖拽分支条件面板来调整优先级**
- **条件要明确且互斥**
- **避免条件之间的逻辑冲突**
- **确保有默认分支处理意外情况**
</callout>

# 实践示例：天气问候

## 场景描述

假设我们设计一个根据温度自动调整问候语的智能体。

智能体会根据当前温度，给出不同的问候语和建议：

- 温度过高时提醒防晒
- 温度适中时推荐户外活动
- 温度较低时提醒添加衣物

## 条件设置

```Bash
if (温度 ≥ 30°C)
    → "天气炎热，记得防晒，建议待在室内吹空调哦！"
else if (温度 15-29°C)
    → "今天温度适宜，很适合外出活动呢！"
else (温度 < 15°C)
    → "天气有点凉，记得多穿点衣服哦！"
```
