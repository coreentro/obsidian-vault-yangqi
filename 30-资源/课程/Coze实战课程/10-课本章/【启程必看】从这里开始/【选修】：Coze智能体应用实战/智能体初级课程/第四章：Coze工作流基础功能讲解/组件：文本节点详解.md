# 什么是文本处理节点？

文本处理节点是Coze工作流中的一个节点，可以对各种文本内容进行加工和处理。

**文本节点的所有能力都可以使用Coze的代码节点实现，但是由于代码节点对于编程新手来说上手比较困难，因此将常用的文本处理功能抽成了一个节点，方便开发者使用**

PS：**这其实就是一个低代码的演变过程，就是将常用的一些代码能力抽象出来做成模块，让普通人不用写代码也可以实现一些功能**

# 文本节点主要功能

文本处理节点支持两种基本的处理方式：

<callout emoji="💡">
1. **字符串拼接**：将多个文本片段组合成一个完整的文本
2. **字符串分隔**：将一段文本按照特定规则分割成多个部分
</callout>

# 字符串拼接应用场景

假设你做了一个手机销售的智能体，你希望用户可以自主选择手机品牌、版本，然后你会根据用户的选择进行商品库的搜索。

用户的选择如下：

```Bash
品牌: "苹果"
型号: "14"

拼接后的查询："苹果 14 手机"
```

# 字符串分割应用场景

字符串分割的目的是为了转换为字符串数组，方便进行后续代码节点的处理。

关于数组是什么，请参考延伸阅读中的JSON

假设你收到一串用逗号分隔的用户兴趣标签：

```Bash
输入字符串：
"游戏,音乐,旅行,美食,摄影"

使用文本处理节点（选择逗号作为分隔符）后，输出结果为数组：
[
  "游戏",
  "音乐",
  "旅行",
  "美食",
  "摄影"
]
```
