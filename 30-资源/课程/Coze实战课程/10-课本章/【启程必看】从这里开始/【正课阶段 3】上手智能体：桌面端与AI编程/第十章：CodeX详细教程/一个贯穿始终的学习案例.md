# 写在前面

你好，我是大圣

接下来我会跟大家讲讲 AGENTS.md、CLAUDE.md 和 Skill 等对于桌面端智能体最重要的概念

但这些概念如果单点地去讲，会有点单薄

所以我想用一个完整的学习案例，从头贯穿到尾，让大家在案例中去学习这些概念

这个案例是一套迷你的内容创作系统，它并不复杂：

1. 几个核心文件夹
2. AGENTS.md / CLAUDE.md 两份入口说明
3. 一组可以直接运行的 Skill，还有新手引导和一键清空

它依然很小，但该有的都有了。后面讲到的每一个概念，你都能在这套系统里面找到

# 一、为什么用这个案例

在之前的课程里，我给大家展示过我自己的内容创作系统

十几个文件夹、几十个技能，跑了快三个月才打磨到现在的样子

所以我非常擅长用内容创作系统来给大家讲解，因为这是我深度打磨过的

所以我做了一件事：**把我的系统做了一个极简的缩小版**

- 一套文件夹结构（你的工作台）

- 一组技能（让 AI 按你的规矩干活）

</callout>

**你下载后看到是电脑上的一个项目文件夹**

AI 会围绕这个文件夹读文件、写文件、移动文件、调用 Skill，并把关键动作写进 LOG（日志）

```text
AI内容工作台学习版/
├── README.md                  ← 给学员看的说明
├── AGENTS.md                  ← 给 Codex 等智能体看的项目说明
├── CLAUDE.md                  ← 给 Claude Code 看的项目说明
├── LOG.md                     ← 系统动作日志
├── 新手引导.md                ← 学员第一次体验时复制给 AI 执行
├── 演示案例.md                ← 我录课时使用的演示脚本
├── 00_收件箱/                 ← 灵感、链接、摘录先放这里
├── 01_素材库/
│   ├── 01_闪念/               ← 自己的想法和判断
│   └── 02_文章/               ← 公众号或外部文章素材
├── 02_内容草稿/
│   ├── 01_短视频/             ← 短视频口播草稿
│   └── 02_公众号/             ← 公众号文章草稿
├── 99_技能库/skills/          ← 给人看的 Skill 展示区
├── .codex/skills/             ← Codex 识别 Skill 的位置
├── .claude/skills/            ← Claude Code 识别 Skill 的位置
└── .agents/skills/            ← 其他桌面端智能体的 Skill 位置
```

| 你要做的事 | 对应位置 | 说人话 |
|-|-|-|
| 记录你的灵感、文章链接、摘录等内容 | `00_收件箱/` | 灵感、链接、摘录不用先分类，先收进来。 |
| 把内容放进素材 | `01_素材库/` | 整理后再进入素材库，后面创作都从这里取材。 |
| 生产内容草稿 | `02_内容草稿/` | 短视频和公众号分开存，产出不和素材混在一起。 |
| 让 AI 按规矩干活 | `.codex/skills/` 等 Skill 目录 | 记录灵感、整理收件箱、解析公众号、写正文、写开头、写标题、编排短视频、一键清空，都交给 Skill。 |
| 让新手直接体验 | `新手引导.md` | 学员不用先懂原理，先让 AI 带着跑一遍。 |

**为什么还要有 LOG？**

因为这套课想讲的不是“AI 给你一个答案”，而是“AI 围绕文件夹持续工作”。

LOG 会记录系统创建了什么、移动了什么、清空了什么，让你看到这个小系统的演化痕迹

# 三、这节课怎么学：视频 + 文字混合

<callout emoji="✅">
**这节课不需要你先理解全部细节**  
你先看视频，建立直觉；再按文字引导，让 AI 在你的电脑上把同一条主线跑一遍
</callout>

| 学习材料 | 你看什么 | 你要得到什么体感 |
|-|-|-|
| 视频 | 我会演示这套文件夹如何从灵感开始，一步步生成短视频草稿。 | 先知道这个案例“长什么样、怎么用”。 |
| 文字 | 你会拿到两个 ZIP 包和一份新手引导。 | 跟着 AI 亲手跑一遍，而不是只看我操作。 |
| 课后练习 | 你可以用“一键清空”恢复初始状态，再反复测试。 | 理解工作流不是一次性聊天，而是可以重复运行的系统。 |

## 你拿到资料后怎么做

1. 根据你的电脑下载对应版本：Windows 版 ZIP 或 macOS 版 ZIP。
2. 解压后，用 Codex、Claude Code 或 WorkBuddy 打开这个文件夹。
3. 把下面这句话发给 AI。

```text
请先阅读 新手引导.md，然后一步步带我体验这个 AI 内容工作台。
```

接下来 AI 会带你完成一条完整主线：

- 记录一条灵感到收件箱
- 记录一个公众号链接到收件箱
- 整理收件箱，让内容进入素材库
- 把一条素材生成短视频草稿
- 单独打磨开头和标题
- 最后查看 LOG，理解“文件即系统”

<callout emoji="💡">
**后面的课程再拆原理**
  
这节课先完成一件事：让你相信这个文件夹不是资料包，而是一个可以被 AI 操作的小系统
</callout>
