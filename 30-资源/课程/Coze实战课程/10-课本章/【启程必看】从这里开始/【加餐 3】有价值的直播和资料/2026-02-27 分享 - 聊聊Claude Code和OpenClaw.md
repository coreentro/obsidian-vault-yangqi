# 一、开场定调：今天不追热点

今天所有的内容都不是为了追热点，而是基于我一线实战的视角。

我服务过1800多位AI学员，我想和大家聊的是，2026年，我们到底该按照什么样的路径学AI

**我们到底该怎么学好 Claude Code？以及怎么正确地看待 OpenClaw？**

先亮明我的观点：

> **用不好 Claude Code，不要急着学 OpenClaw**

注意，我没有说 OpenClaw 不好，我也没有说你不要学它。我说的是**时机很重要**

今天我也不会讲 Claude Code 的安装教程，也不会讲 OpenClaw 的安装教程

了解我的伙伴都知道，一个真正有价值的安装教程，绝对不是一场直播能搞定的。它需要你静下心来，考虑到所有的情况，才能把事情搞定

那今天到底讲什么？**讲框架、讲路径、讲本质、讲一些应用案例**

我要帮你搞清楚三件事：

OpenClaw 到底是什么？

Claude Code 的核心到底在哪？

以及你现在应该从哪里开始学？

我们要既要讲道、又要讲术。仅讲术没有用，我们并不是安装完要打卡朋友圈的

# 二、Claude Code 和 OpenClaw，到底是什么关系？

好，既然要讲本质，我们就先把这两个东西的关系搞清楚

我拆解一个AI软件，有一个自己的框架：哪些是智能化的事情，哪些是工程化的事情

我先用一句话：Calude Code是开发工具，不断打磨各种Skills，然后让成品的Skills放在OpenClaw上去无限运行

---

我们先来看OpenClaw，OpenClaw 又称小龙虾，它本身就是一个软件程序

我用上面的框架来拆解它。首先来说智能化，它的智能化没有什么特殊的，就是用最强的模型，让模型自主调用工具，执行流程，获取上下文

那OpenClaw的工程化？我理解OpenClaw破圈的原因，就是它的工程化能力。三件事：

1. **可以接入聊天渠道**——飞书、Telegram、企微等，方便你随时和它对话
2. **支持7×24小时运行，具备长期记忆**——可以记住你做过的事情
3. **可以设置定时任务**——定期推送日报、周报，提醒你完成相关工作

OpenClaw 一点都不复杂，这个需求很快就会固化，谁都可以复刻。

AI模型厂商已经在跟进了——KimiClaw、MinimaxClaw，这些都在路上

---

那 Claude Code 是什么？Claude Code 是 Anthropic 这家公司推出的通用智能体。

它的智能化来自于：

1. 模型的智能，Cloud 模型的智能
2. Claude Code 本身就是一个通用智能体，它内置了一些智能化的技术在里面。

这里我们不展开聊。

那 Claude Code 比小龙虾还先出现，那为什么 Claude Code 没有出圈，而 OpenClaw 这么出圈？

我自己的理解就是上面那三个工程化的能力：

1. 接入聊天渠道
2. 24小时运行
3. 具备长期记忆，还可以设置定时任务

  
  
--------

所以我要再次表达我的一个观点：我们花时间学一样东西，一定要学它底层的逻辑

而我们学Claude Code也是学智能体，那都是学智能体，为什么我们要学Claude Code？

因为OpenClaw封装的太好了，好到你没有办法通过使用OpenClaw来培养你使用智能体的手感。

# 三、学习路径：一步都跳不过去

搞清楚了两者的关系，接下来的问题就是：**那我该从哪里开始？**

我之前在社群里分享过一个学习路径，这个学习路径到现在为止，我依然坚信它是无比正确的。

大家对照一下自己，看看自己到底在哪个阶段

## 第一步：AI通识（约5小时）

我们的课程5个小时就能学完，建议看两到三遍。

AI通识没有"学会"这一说，它只有你看过一遍、脑子里有个概念。比如最经典的几个问题：

- AI模型跟搜索引擎的区别是什么？
- AI模型擅长什么？搜索引擎擅长什么？
- AI为什么会胡说八道？
- 提示词到底该怎么写？

这些概念你脑子里得有，后面的一切才能听得懂。

## 第二步：重度使用 Claude / Gemini / GPT，建立对AI能力边界的直觉

有了通识之后，下一步不是急着装工具，而是先把模型用起来。

这是什么意思？我举个例子：你想让AI帮你写公众号、做内容，你知道要给它什么吗？你是否知道语料的重要性？你是否知道语料之于这些模型的意义在什么地方？

这些直觉，不是看教程能学会的，是用出来的。

## 第三步：安装 Claude Code，学习 Agent 生态

当你对模型有了手感，就可以进入 Claude Code 了

怎么算学明白了？我举一个最典型的例子：**你今天借助 Claude（AI模型）、Claude Code、互联网这三大工具，能够自己把 OpenClaw 给玩明白，就算学明白了**

如果你借助这三样东西都搞不定 OpenClaw，那你的 Claude Code 就是掌握得不够好

## 第四步：最后才是 OpenClaw 这类工具

怎么算玩好了？

你有了稳定运行的工作流。这个工作流原来你用 Claude Code 的时候，每次都要打开它、运行命令。

而 OpenClaw 是通过定时任务的方式，帮你把工作流自动运行起来

**不要逆序学习。你会很痛苦，而且不知道痛苦在哪。**

# 四、Cherry Studio：不要非此即彼

讲到这里，可能有人会问：大圣，有了 Claude Code，我还要用 Cherry Studio 吗？

当然要用。你不要所有工作都用 Claude Code。

Claude Code 消耗 token 的速度一定比 Cherry Studio 高，因为 Cherry Studio 只是跟大模型对话，而 Claude Code 内部有一些额外的机制在运作。

我这里想跟大家讲的是：**千万不要非此即彼**

很多人问我：有了 OpenClaw，我还要 Claude Code 吗？有了 Claude Code，我还要 Cherry Studio 吗？不是这样的。在AI时代，关键是什么？**你不要只考虑效果，还要考虑成本**

做内容相关的事情时，用 Cherry Studio 来思考一个问题是非常方便的。所以你一定要把 Cherry Studio 装好，然后不断去用 Claude 这个模型

# 五、Claude Code 怎么用？

好，前面讲了路径、讲了工具之间的关系，接下来我们重点聊聊 Claude Code 到底该怎么用。

## 先说最关键的一件事：安装

Claude Code 最关键的是什么？我觉得就是**安装**。真的不是废话

为什么这里我又去强调安装？因为我今天敢开AI编程的课，不是因为我要给大家讲编程，是因为我们要用自然语言去满足我们的诉求。

那你怎么去培养自然语言的这种体感？肯定只能是用，多用。那阻碍小白去用的一件事，只有安装

所以大家才看到我们的 Claude Code 安装教程，我迭代了好几版。光第一次发布我就花了两天，后来又更新了三四版，根据学员的问题调整后，很多纯小白都能完成安装。

安装完之后，就要不断和它对话、使用它。遇到问题，可以通过搜索引擎了解，也可以直接在 Claude Code 里问

你安装的不仅是一个 Claude Code，在后续使用它的过程中，还可以让 Claude Code 帮你学习 Claude Code。

这有点像写作很多人问我 Claude Code 怎么用好，就像很多人问我写作怎么写好。我的第一反应都是：**你先写100篇。** Claude Code 怎么用好？**先用它处理100个任务**

## 再说理论框架

当然大家付费买了课，我肯定要告诉大家一些基本框架

Claude Code 本身就是一个Agent。你要对 Agent 有一个理解

在课程里我们从智能体那一块就开始强调，讲了 MCP、Commands、Hooks、Skills

它们的本质是什么？说白了就是刚才讲的那三样东西：

1. **解决规划的问题**——让AI知道该怎么一步步做
2. **解决上下文的问题**——让AI拿到它需要的所有信息
3. **解决技能调用的问题**——让AI能调用外部工具完成任务

就这三个。把这些了解完，剩下的真的就是去用

## 使用方式：一切都在一个文件夹下

那具体怎么用？

很多人用不惯命令行。我要说的是：你一定要习惯命令行。不是说你必须用命令行，但当需要用的时候，你不能老觉得自己不习惯。当然现在也有一些辅助工具可以降低使用门槛，比如小七姐的 Token / Code 软件

用 使用Claude Code 的本质是什么？

**在某个文件夹下，有一个通用的 Agent。你要思考怎么用这个 Agent 把文件夹里的内容处理掉。** 说白了就是做一个项目。

所以你看我在做什么？每次要做一件事，就先建一个文件夹，起个名，这就是一个项目。

然后在里面折腾——要么让它写代码，要么把需要的语料（PDF等文件）扔进来

想想看，你所有的工作本质都是这些：给你一个 Excel 文件，根据它出图表、做汇报；你要写公众号，就根据选题和素材写一篇文章。

Claude Code 在文件夹里怎么折腾？它可以调用外部工具、调用 MCP、写提示词，最终生成文档：PPT、Word，把产出放到文件夹下

**说白了不就是：输入 → 执行 → 输出吗？**

# 六、两个实战案例

光讲理论可能有点抽象，来给大家看两个真实的例子。

### 案例一：我用 Claude Code 优化"11封信"

我有个一人公司的课程，里面有一套"11封信"的筛选体系。每次通过这11封信和学员1V1沟通时，花的时间很长，我想优化这个事情

**我是怎么做的？**

1. 建了一个文件夹，叫"优化11封信"
2. 把11封信的内容拖进来
3. 把最近5次跟学员1V1的聊天记录拖进来

就这两样东西。

然后跟 Claude Code 聊——说了我的背景和诉求。Claude Code 做了什么？

- 先读文件，了解我这件事
- 帮我规划处理方案
- 从聊天记录中提取共性问题
- 帮我生成了**第12封信**（FAQ形式）
- 帮我写逐字稿，我自己改一版
- 每个问题生成 Excalidraw 配图

有了逐字稿、有了配图，我就可以录视频了。

这里我更想传达的是：**用 Claude Code 要大胆，要敢问它，不要老想着去问别人。**

## 案例二：纯小白用 Claude Code 开发软件

再给大家讲一个案例，主角不是我，是我们社群里的一位纯小白，连电脑都用不溜的文科生

他跟着安装教程装上了 Claude Code。他一直有个英语学习相关的诉求，之前用复杂提示词来实现

写了好几万字的提示词也没成功。

不过这几个月的折腾也有收获——他把自己的诉求梳理得非常清晰，整理成了纸质文档

装好 Claude Code 后，他把这份文档交给它，借助 Claude Code 开发并部署出了一款软件。

部署本身是比较麻烦的事，但 Claude Code 擅长这个，它会引导你完成注册流程，帮你部署好并提供链接，直接使用即可

# 七、核心技巧：提供语料，辅助AI

从两个案例里面，你非要让我抽象出一些技巧的话，就是提供语料，然后提出你的诉求，没了。

但这里提语料的关键的点在哪里？不是说你非一定要只给文档，你要知道语料有很多种。

你帮他找到一篇GitHub的文档，你帮他找到一个官网的文档，然后提供给他，让他去获取，基于这个帮你安装。

语料有太多种——你的自我介绍、你自己的素材。

当你想让 Claude Code 理解一件事时，可以去官网把英文文档扒下来，直接让它学习

你可能会问：Claude Code 为什么不自己找？

这又回到那个问题了：Claude Code 的大脑是 Claude，它的训练数据有截止时间。

2025年10月出来的新东西，它可能不知道这个概念，也不知道对应的官网，只能不断去试，这就浪费 token

**发现了没？在这个过程中，最关键的是人辅助AI，而不再是AI辅助人。**

你要知道它的缺点在哪、优点在哪。你要弥补它的缺点，帮它找到它没有的东西：

- 帮它找 GitHub 文档
- 帮它找辅助教程和官网文档
- 帮它找专属语料
- 帮它下载别人的短视频，生成文案给到它

所以最终又回到了本质的能力：**你自己能不能在互联网上找到优质的信息？** 

如果你自己都找不到，这就很头疼了

学来学去，最终都是那些底层能力：**搜索能力、对优质信息的辨别能力、判断能力、提问能力**

这就是为什么我说不要着急学"小龙虾"：越用封装得好的工具，你这些底层能力越养成不了。

除非AI真到了AGI时代，但到那个时候，你可能就没有价值了

大家一定要明白，**我们到底在跟AI沟通什么。**

# 八、OpenClaw：框架拆解

好，聊完了 Claude Code，我们回过头来讲讲 OpenClaw。

前面说了，OpenClaw 一定是值得拥抱的新形态，但它本质还是智能体那套东西。

我现在虽然还没出 OpenClaw 的教程，但有责任帮大家拆解一下这个东西的框架

## 部署：给它找个"房子"

为了7×24小时响应你的工作，你需要给它一个能一直开机的服务器。市面上两种方案：

- **云端服务器**：阿里云、腾讯云，天然24小时开机
- **硬件电脑**：Mac mini 等，本质也是电脑，核心逻辑就是保持24小时开机

## 安装：两种方式

- **一键安装**：把配置都隐藏了，界面里傻瓜式操作，按提示配API、通道即可
- **底层安装**：装完只是个壳——没有"脑子"，你得配大模型；没有MCP和技能，你得配；没法接入飞书企微，你也得配

不管哪种方式，装完之后都有坑要踩。所以我又回到那个问题了：我在这台电脑上安装 Claude Code，让 Claude Code 帮我去搞定这些事。

说白了就这几个概念：

- **渠道**：最上层，和用户聊天的入口（飞书、Telegram等）
- **网关**：中间层，配置路由规则（哪个渠道绑哪个Agent）、模型（哪个Agent用哪个模型）、工具（同理）
- **Agent**：底层，每个Agent有自己的工作空间，彼此隔离

还记得前面说的那句话吗？**Claude Code 生产 Skill，OpenClaw 运行 Skill。** 你真正积累下来的资产，是那些经过打磨的 Skills——它们是你的业务经验被AI化的结果，是这套体系里真正属于你的东西。
