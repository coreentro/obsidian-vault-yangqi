# 为什么需要循环-Why

想象一下以下的日常场景：

1. 洗碗工：你是一个洗碗工，你每天的事项就是洗完一箩筐的碗：你的做法如下：

   1. 确定洗碗的过程：“拿起碗，涂上洗洁精，冲洗，擦干”
   2. 每次拿起一个碗，进行洗碗动作
   3. 重复洗碗的过程
   4. 直到箩筐里没有碗之后，停止今天的洗碗工作，下班

1. 发送群组消息：假设你需要给50个朋友发送国庆节日祝福，你的做法如下：

   1. 编辑好一段国庆节日祝福的文案
   2. 在自己的好友列表中找到这50个朋友
   3. 针对每个朋友进行国庆祝福文案的发送
   4. 直到把最后一个好友发送完成，事情结束

1. 健身：你决定做50个俯卧撑作为日常锻炼。过程如下： 

   1. 确定正确的俯卧撑姿势
   2. 做一个俯卧撑
   3. 数一下已完成的次数
   4. 重复步骤b-c，直到完成50次

在这些例子中,我们可以看到一些共同点：

- **有一个明确的重复动作**
- **这个动作会被执行多次**
- **有一个结束的条件（**所有碗洗完，所有朋友都收到消息，做完50个俯卧撑）

在编程中，我们经常遇到需要重复执行某些操作的情况，这与上面的日常例子非常相似：

- 处理一个列表中的所有元素（如给50个朋友发消息）
- 重复某个动作直到达成特定条件（如洗完所有的碗）
- 按照固定次数执行某个任务（如做50个俯卧撑）

如果没有循环，我们就需要一遍又一遍地写相同的代码。

例如，假设我们要在没有循环的情况下打印"你好"5次，我们会写如下的代码

```Python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```

这种方法不仅繁琐，而且如果我们想改变打印次数,就需要手动增加或删除代码行。

而有了循环,我们可以这样写：

```Python
for i in range(5):
    print("Hello")
```

# 循环的定义-What

<callout emoji="🎹">
**编程语言是现实世界的抽象，它的存在是为了让工程师更好更快的解决现实中的问题**
因为我们现实世界中有这种循环往复的行为，因此在编程语言中也针对这个行为进行了**语法抽象**。
</callout>

所以关于循环的定义，我们从两个方面来看

## 现实世界的定义

在现实世界中，循环是指重复执行某个动作或过程，直到满足特定条件为止。

这是一种自然而然的行为模式，我们在日常生活中经常使用。

## 编程语言的定义

在编程中，循环是一种控制流结构，允许基于某个条件重复执行一段代码。

它使得我们可以用简洁的方式表达重复的操作，而不需要多次书写相同的代码。

主要有两种类型的循环：

### for循环

for循环用于遍历一个序列（如数组）或执行固定次数的操作

基本语法：

```Python
for 变量 in 序列:
    # 要重复执行的代码
```

其主要应用场景

- 处理一个列表中的所有元素（如给50个朋友发消息）
- 按照固定次数执行某个任务（如做50个俯卧撑）

### while循环

while循环:在满足特定条件时持续执行。 

基本语法：

```Python
while 条件:
    # 只要条件为真，就重复执行的代码
```

其主要应用场景

- 重复某个动作直到达成特定条件（如洗完所有的碗）

# 如何实现循环-How

本文并不是语法教程，所以并不会对语言进行详细的拆解。

我们从两个简单的编程示例入手，让大家感受下Python语言中是如何实现循环的

## for循环

基本语法:

```Python
for 变量 in 序列:
    # 要重复执行的代码
```

例子: 打印列表中的每个水果

```Python
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(fruit)
```

输出:

```Plain Text
苹果
香蕉
橙子
```

## while循环

基本语法:

```Python
while 条件:
    # 只要条件为真,就重复执行的代码
```

例子: 模拟存钱罐存钱过程

```Python
target = 100  # 目标金额
savings = 0   # 初始存款

while savings < target:
    amount = int(input(f"当前存款: {savings}元。请输入要存入的金额: "))
    savings += amount
    print(f"已存入 {amount}元，当前总存款为 {savings}元")

print(f"恭喜！你已经存到了 {savings}元，达到了 {target}元的目标！")
```

这个例子模拟了一个存钱的过程：

1. 我们设定了一个存钱目标（100元）。
2. 程序会不断询问用户要存入的金额，并更新总存款。
3. 当总存款达到或超过目标金额时，while 循环结束。

让我们看一下这个程序的模拟运行结果：

```Plain Text
当前存款: 0元。请输入要存入的金额: 30

已存入 30元，当前总存款为 30元

当前存款: 30元。请输入要存入的金额: 50

已存入 50元，当前总存款为 80元

当前存款: 80元。请输入要存入的金额: 25

已存入 25元，当前总存款为 105元

恭喜！你已经存到了 105元，达到了 100元的目标！
```

# Coze中的循环节点

在AI编程中，我们一般会有两种跟编程打交道的方式

- 使用大模型帮我们编写代码，我们需要能够读懂代码，并且进行简单的修改
- 使用低代码平台，通过配置一些参数完成某个软件能力

前面我们已经理解了循环的概念，接下来我们来利用刚刚学到的循环概念来学习Coze中的循环节点

在视频中，我们会讲解两个工作流案例。

**PS：这两个案例皆为教学案例**

第一个案例：长文写作案例

我们在用大模型写作长文的时候，有一个头疼的问题是输出的长度问题，你会发现，如果你让大模型一次性输出2000字的文章，他中途可能会停止输出，我们可以利用循环节点来解决这个问题

- 首先使用大模型根据文章主题生成大纲
- 使用循环节点，让大模型针对每个大纲生成内容，其生成内容依赖以下四个内容

  - 文章主题：{{topic}}
  - 文章的整体大纲：{{articleOutline}}
  - 当前正在写的大纲：{{currentOutline}}
  - 之前已经完成的内容：{{article}}
- 使用一个中间变量，每次都将生成的内容拼接到之前已经生成的内容
- 当所有大纲都写完之后，该长文也会编写完成

第二个案例：输出固定长度的文字

我们都知道大模型的数学不好，因此当我们让大模型输出固定长度的文字时，你会发现大模型的输出文字长度并不能每次都按照你的预期来，在这个案例中我们就使用循环的节点能力来达到让大模型输出精确长度文字的能力
