## **总结**
会议讨论了微信机器人使用问题及 FaaS PPT、知识库讲解。主要内容包括：
- **微信机器人使用问题及 FastGPT、知识库讲解**

  - **微信机器人被限制登录**：微信小号被限制登录，可能需要等待一周才能恢复。
  - **FastGPT讲解**：本地搭建的词库在日常使用场景里面可能更落地、更实用。
  - **AI agent 供学活动**：本次活动围绕微信机器人，用 fast GBT 搭建本地版的以扣子平台。
  - **FastGPT 商用问题**：FaaS 的 GPT 在商用的时候是要有商业许可和付费的，需要查看开源协议。
- **如何使用 FastGPT 以及它的优势**

  - **FastGPT 的使用方法**：在宝塔面板中安装 Docker，然后通过终端输入命令，进入 FastGPT 文件夹。在这个过程中，可能会遇到下载速度慢或者无法下载的问题，可以尝试按 control+c 然后再右键粘贴，点击回车。
  - **FastGPT 的优势**：FastGPT 在知识库召回方面的表现比 define 更好，适合用于知识库对话或者关键字对话的场景。
- **通过终端输入命令下载文件**

  - **文件下载慢的解决方法**：可以通过更改镜像地址的方式提高下载速度，将原本的镜像地址更换为阿里云的镜像地址。在下载过程中如果遇到报错或其他问题，可以尝试重新连接或重新下载。
  - **one API 下载慢的原因**：one API 是一个非常好的工具，但下载速度较慢。此次下载会用到阿里云的 key，因为可以白嫖到它的向量模型来帮助创建知识库。
- **如何更换 Docker 镜像源**

  - **镜像被封问题**：之前的镜像源可能被封了，导致下载速度变慢。
  - **注册阿里云账号获取 token**：可以注册阿里云账号，进入灵机控制台创建 API key 获取 token。
  - **更换 Docker 镜像源**：可以通过修改 Docker 的 compose 文件来更换镜像源，也可以直接复制粘贴替换源。
- **如何配置 one API 访问 Yapi**

  - **下载和安装**：正确地完成下载和安装之后，界面会显示 running。
  - **配置 one API**：访问地址中需要将中间的地址替换为自己的包他左上角地址。
  - **配置端口**：在宝塔里面配置端口，若在宝塔中配置后无法访问，则需要在腾讯云里按照之前配置端口的方式再配置一下。
  - **访问 Yapi**：访问 one API 地址，将中间的地址替换为跑塔左上角地址，然后输入用户名和密码登录。
- **如何配置和使用基于向量模型的对话系统**

  - **配置对话系统**：需要获取 API 密钥，在 config 点节省文件中填写 API 访问地址和向量模型的 key，并将其粘贴到对应位置。保存后需要重启才能生效。
  - **使用知识库**：在登录 PPT 地址后，可以进入知识库页面，选择索引模型并创建知识库。在应用中选择关联知识库并发布后，就可以使用知识库进行语义检索和 AI 对话。知识库可以用于企业私有化部署，也可以上传到 code 上供第三方使用。
  - **测试对话系统**：使用蔡徐坤的爱好进行测试，系统会先进行知识库检索，然后进行 AI 对话，并给出答案。使用爱情公寓的数据集进行测试，更能体现知识库检索的作用。
- **如何使用 FaaS 和 OpenAI 创建 AI 应用**

  - **安装 FaaS 和 OpenAI**：在安装 FaaS 和 OpenAI 时，可以选择默认安装或自定义安装目录。安装完成后，需要验证是否安装成功。
  - **配置端口**：在配置端口时，需要在宝塔面板和腾讯云服务器上分别进行配置，确保端口统一。
  - **创建知识库**：创建知识库可以帮助提高模型的准确性和可用性，可以根据自己的需求进行创建。
  - **使用 YAPI 统一模型配置**：YAPI 可以帮助将不同模型的 key 和 base 统一为 OpenAI 的协议格式，方便模型的使用。
- **配置 FaaS PPT 及相关问题解答**

  - **配置 FaaS PPT**：选择类型后输入 MIS，创建令牌，配置打卡文件和 json 文件，然后保存。在当前文件夹下执行终端命令，最后在 Faas GBP 中配置 bot。
  - **腾讯云控制台配置防火墙**：进入控制台，点击防火墙，添加规则，输入端口号 3001 和 30000。
  - **常见问题及解决方案**：针对容器创建不成功的问题，提出可能是端口被占用或文件无法启动，需要查看报错信息并解决。对于 AI 模型显示为空的问题，可能是没有千问模型。
- **千问和 GPT4**：张梦飞介绍了千问和 GPT4 的使用方法，并回答了关于模型选择和使用的问题。
- **其他模型的使用**：张梦飞介绍了如何使用其他模型，并以讯飞和百度为例进行了演示。
- **平台知识库和服务器性能**：张梦飞解释了平台知识库是否需要付费以及服务器性能的相关问题。
- **微信机器人和 cost 活动**：AJ 介绍了微信机器人的搭建和 cost 活动的相关信息，并鼓励大家积极参与。
- **直播安排和线下活动**：AJ 说明了明天的直播内容为 AI 视频大赛讲解，本周日有线下活动，同时感谢了孟飞和英海的付出。
