[22:03](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=1323000)  **从混沌到秩序——AI 工作流的重塑与个人工作流的变革**
> 本章节主要介绍了银海 inhai 在使用 AI 过程中如何重塑 AI 工作流和个人工作流。首先，银海 inhai 进行了自我介绍，包括网络马甲、中文名、职业、兴趣爱好以及在开源社区的贡献等。接着，他提出本次分享将围绕 agent workflow 展开，包括其定义、个人理解、偏见以及实践案例等。最后，他对右下角网页进行了预告，称其可能更偏向于个人知识库，后续将完全开源。
[24:59](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=1499000)  **反思、工具使用、规划和多智能体协作**
> 本章节主要介绍了人工智能的四种模式、agent 的基本框架和 agent workflow 的概念，以及 agent workflow 的优势、组成部分和具体的工作流程，最后介绍了智能体的相关内容。
[40:57](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=2457000)  **深入理解 Agent Workflow 的套娃设计**
> 本章节主要介绍了 agent workflow 的套娃设计，并通过具体例子帮助大家理解。银海 inhai 指出，工作流的功能没有想象中的那么理想化，在规划过程中也比较麻烦。因此，需要关注大模型本身的 workflow 是怎么走的。在之前比较火的 prompt 中，社区使用了 lang GPT 的提示框架工作流设计，其中也使用了 COT 的思想，即 chain of thought。这种思想关注输入、中间链路和最终输出，通过设计 workflow 的概念，让大模型能够更好地按步骤完成工作。  
> 此外，还介绍了工作流的概念和应用。首先通过“lets think step that step”引出了工作流的逐步拆解的思想。然后回归到传统工作流，以 OA 系统的审批流为例进行了讲解。接着介绍了 RPA 工作流，它可以完成获取页面元素信息、采集数据等任务。同时，目前各种传统的 RPA 软件也开始结合大模型，辅助其设计更拟人化的思考过程。之后又提到了 config UI 和 stable diffusion 等 AI 绘画工作流，config UI 可以实现人脸融合等功能，而 stable diffusion 则需要调整模型和参数等。最后，还介绍了 JSON 结构在 VUI 中的应用。
[48:52](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=2932000)  **工作流设计与 AI 智能体的结合**
> 本章节主要介绍了工作流的相关内容，包括工作流的定义、DSO 配置文件、define AI 平台、config UI 等。其中，重点讲解了拷贝工作流和模仿式工作流两种学习方法，并通过 Rabbit 产品进行了演示。最后，银海 inhai 提出了别神化 AI agent，议程工作流可能是一个伪需求。
[52:00](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=3120000)  **自然语言能否用于创建工作流**
> 本章节主要讲述了复杂工作流的搭建问题。银海 inhai 认为目前复杂工作流的搭建比较麻烦，需要产品设计、流程图制作、开发等步骤，而且最终的 AI 效果与想象中有差距，需要更多的参与感。因此，他提出了一个想法，即通过自然语言创建工作流，类似于使用 Momi 语法生成购物流程图。他希望能够定义好规则，将自然语言转化为工作流节点，并实现至少 60%的还原度。这样可以提高工作流的协同创建效率。
[54:43](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=3283000)  **AI 工程平台的使用场景及价值**
> 本章节主要讨论了 agent workflow 的使用问题。会议首先提出了目前 agent workflow 在使用过程中存在的问题，即产品经理和研发工程师对其理解和使用存在困难。接着，会议以 AI 拍立得为例，说明了 agent workflow 可以作为 MVP 的验证方案，帮助快速实现想法。最后，会议总结了 agent workflow 作为验证 MVP 方案的优势。
[58:05](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=3485000)  **利用 AI 重塑工作流程**
> 本章节主要讨论了 AI 与人的协同关系，并介绍了信息处理的流程以及 AI 技术在信息表达和产品设计方面的应用。首先提出了嵌入、Copilot 和 agent 三种协同框架，并以产品经理设计产品功能为例，详细介绍了 agent 模式下的工作流变革。接着，解释了信息处理的流程，包括输入、处理、输出和反馈，并以自己的分享为例，说明了从信息提炼、处理推理、多任务解决到信息输出的过程。然后，通过对比传统的图像生成方式和 AI 生图，说明了 AI 技术在降低创作门槛和提高工作效率方面的优势，并分享了自己在工作流中使用的一些产品。  
> 最后，探讨了 agent 的发展和应用，认为 agent 的 knowhow 无法在短时间内被替代，同时也分享了自己对于 v to AGI 的理解。
[01:14:54](https://waytoagi.feishu.cn/minutes/obcnj25319j4eu964z51933v?t=4494000)  **关于公众号排版流程及 agent 落地场景的讨论**
> 本章节主要讨论了公众号排版流程以及 agent 的落地场景，并探讨了 AI 技术在实际应用中的一些问题和解决方案，以及 AI 工具在工作流程管理中的应用。会议首先分享了公众号排版经验和写作助手的案例，接着提出可以从小场景入手，积累经验，再推广到更多场景。然后，会议探讨了 AI 技术在实际应用中的一些问题和解决方案，包括开发拍照生成点评文案的功能、knowhow 在企业数字化转型中的重要性、钉钉 AI 助理在企业办公场景下的落地应用等。
