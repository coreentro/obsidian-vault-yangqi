# Agent 第三轮活动策划

### 目的

1. 本次活动分阶段带领AI爱好者玩转微信机器人。第一阶段能够让0基础的AI普通玩家独立创建微信机器人，并延展学会有个性有功能的微信机器人。第二阶段带领爱好者们进一步高阶玩转机器人。
2. 希望更多人有创意去捏一个好的健康助手
3. 期望能够看到更多的提高工作效率和生活效率的创意和工具
4. 简化的机器人部署方式、网页、插件
5. web掉线，更想学习了解下hook相关的
6. 希望能有一个简单的、直接的前端管理界面
7. 知识管理助手、微信消息管理助手

### 时间计划

6月19日-- 6月27日每晚20:00开始

  - 涉及邀请时间档期，保证输出质量

- 注册智普AI、注册coze.cn
