# 初识JSON

PS：请不要觉得枯燥，我已经用最精简的内容来讲解了，并且后面会有两个教学视频，请耐心看完～

## 什么是JSON

给JSON下一个简单的定义：JSON是**应用程序**用来**记录**或者**传递信息**的文字。

就好比人类之间沟通使用的汉字，其实就是一种约定的规范。

那我们学JSON本质就是**学的这份规范**，就好比你入职时背的行为规范。

所以不要发怵，也不要较真。

## 为什么要使用JSON

这里你可能要问了，程序之间传递信息为什么要用JSON呢？

1. 易于阅读和编写：JSON的语法简单明了，容易理解，毕竟程序员也要经常阅读JSON
2. 轻量级：JSON格式紧凑，数据量小，传输效率高（应用程序之间传输需要网络，在相同的信息密度下，数据越少越好）

## JSON的结构

JSON主要有两种数据结构：

1. 对象（Object）：类似于表格的一行，由键值对组成
2. 数组（Array）：多个对象的集合

为了方便大家理解，我们从实际的场景出发，依靠大家熟悉的表格来对比学习JSON

**场景一：我需要记录一个同学的信息：姓名、年龄、城市**

1. 用表格记录

| **姓名（name）** | **年龄（age）** | **城市（city）** |
|-|-|-|
| 大圣 | 18 | 杭州 |

1. 用JSON记录

```JSON
{
  "姓名": "大圣",
  "年龄": 18,
  "城市": "杭州"
}
```

PS：在规范中，JSON的键一般都使用英文，如下：

```JSON
{
  "name": "大圣",
  "age": 18,
  "city": "杭州"
}
```

- `name` 是键，对应的值是 `"大圣"`
- `age` 是键，对应的值是 18
- `city` 是键，对应的值是 `"杭州"`

**场景二：我需要记录多个同学的信息：姓名、年龄、城市**

1. 用表格记录

| **姓名（name）** | **年龄（age）** | **城市（city）** |
|-|-|-|
| 大圣 | 18 | 杭州 |
| 艾木 | 16 | 深圳 |

1. 用JSON记录

```JSON
[
    {
        "name": "大圣",
        "age": 18,
        "city": "杭州"
    },
    {
        "name": "艾木",
        "age": 16,
        "city": "深圳"
    }
]
```

我们再来看JSON支持的两个结构

1. 对象（Object）：类似于表格的一行，由**键值对**组成
2. 数组（Array）：**多个对象的集合**

从上面的两个场景中，我们可以发现

- 一个学生信息就是一个对象（Object）
- 两个或者多个学生信息就构成了一个数组（Array）

### 对象的语法结构

对于对象而言，其语法就是一个大括号{} 包裹的键值对。

所以对于一个学生信息而言，当我们要手写他的JSON语法时，

- 第一步，确定这个学生信息的键值对

  - name = 大圣
  - age = 18
  - city = 杭州
- 第二步，写一个大括号
- 第三步，将键值对放进去

```JSON
{
    "name":"大圣",
    "age":18,
    "city":"杭州"
}
```

注意事项

- **所有的键必须使用双引号包裹**
- **键和值之间使用冒号分隔**
- **除了最后一个键值对，其余的键值对使用逗号分隔**

### 数组的语法结构

数组就是多个对象的集合

所以对于两个学生而言，如果要手写他们的JSON语法时，

- 第一步：**写一个中括号**，
- 第二步：放入第一个学生对象
- 第三步：放入第二个学生对象

```JSON
[
    {
        "name":"大圣",
        "age":18,
        "city":"杭州"
    },
    {
        "name":"艾木",
        "age":16,
        "city":"深圳"
    }
]
```

### 嵌套

学习了对象的结构和数组的结构，你可能产生疑惑：就这？

JSON真正的强大之处在于他的嵌套结构，对象和数组是JSON结构的两个基石，然后通过不断的嵌套可以构造出非常复杂的数据结构

嵌套又分为两种

- 对象与对象的嵌套
- 对象与数组的嵌套

**场景三：我们要记录一个学生信息，包含姓名，年龄，城市、学习的课程，以及各科的成绩**

我们来分析，这里面可以有两个对象

- 学生信息

  - 姓名
  - 年龄
  - 城市
  - 各科成绩
- 各科成绩

  - 语文成绩
  - 数学成绩
  - 英语成绩

我们先创建各科成绩的对象

```JSON
{
    "语文成绩":100,
    "数学成绩":80,
    "英语成绩":30
}
```

再创建学生信息的对象（里面嵌套了各科成绩的对象）

```JSON
{
    "姓名":"大圣",
    "年龄":18,
    "城市":"杭州"
    "各科成绩":{
        "语文成绩":100,
        "数学成绩":80,
        "英语成绩":30
    }
}
```

而学生学习的课程，则是一个数组，因为学生可以学习多门课程，假设学生学习了

- 语文
- 数学
- 英语

将课程嵌套在学生信息中

```JSON
{
    "姓名":"大圣",
    "年龄":18,
    "城市":"杭州"
    "各科成绩":{
        "语文成绩":100,
        "数学成绩":80,
        "英语成绩":30
    },
    "学习的课程":["语文","英语","数学"]
}
```

这样，一个由对象、数组之间的嵌套对象就完成了

**PS：你这里可能有疑问，为什么有的值用双引号包裹，比如"大圣"，有的又没有双引号包裹，比如年龄的30。**
