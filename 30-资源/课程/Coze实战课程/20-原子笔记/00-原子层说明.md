# 原子层说明

这里放的是**你的笔记**，不是课程原文。

## 什么时候写原子笔记？

- 一个概念需要反复用（如：工作流、插件、Agent、Skill、RAG）
- 一套可复用步骤（安装、发布、排错）
- 一个案例里真正可迁移的结构

## 怎么写（保持短）

```markdown
# 概念名

## 一句话
## 关键步骤 / 结构
## 常见坑
## 课本章出处
- [[指向 10-课本章 中的原文]]
```

## 子文件夹

| 文件夹 | 放什么 |
|---|---|
| `概念/` | 定义型卡片 |
| `工作流与模式/` | 可复用流程 |
| `案例提炼/` | 从案例抽出的模式 |
| `待消化/` | 先丢链接与批注，稍后整理 |

## 禁止

- 把整篇课本章复制过来
- 修改 `10-课本章/` 里的原文
