# Coze 课程地图（课本章 + 原子笔记）

本课程库分成两层：

| 层 | 路径 | 作用 |
|---|---|---|
| **课本章** | `10-课本章/` | 原始课程正文，**只读参考**，不拆不改 |
| **原子笔记** | `20-原子笔记/` | 你自己的提炼：概念 / 模式 / 案例 |
| **元数据** | `90-元数据/` | 迁移报告等 |

## 学习原则

1. **先在课本章里读**，不要把 700+ 篇原文拆碎。
2. 读懂一个点后，在 `20-原子笔记/` **新建一张短卡片**，用双链指回课本章原文。
3. 原子笔记只写：**定义 / 步骤 / 坑 / 可复用模板**，不复制长文。
4. 课程总索引（飞书迁移）：[[30-资源/课程/Coze实战课程/10-课本章/00-索引]]
