好像确实没什么办法，官号太贵死得快，做公益钱包根本扛不住。用kiro和notion这种反代出来就是弱智，它们自带的系统提示词太长了。而很多非公益中转站也可能用其他模型装作Claude，并非纯血。我能想到的就是反代kiro、notion的站点后先试透明 HTTP 代理、再加协议转换、再开完整上下文和摘要白名单、再加入thinking、再加工具调用。反正就是排查减少可能降智的部分。另外站内有些公益提供的Claude来自any…虽然很离谱，但是进行了标注，不知道符不符合站里的规范。
