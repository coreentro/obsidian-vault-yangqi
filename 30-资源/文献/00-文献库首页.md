# 文献库首页

统一的科研文献层：**文献卡片 / 概念卡片 / 实验条件 / 课题关联 / 汇报 / 附件**。  
原有笔记**正文未改写**，仅归入统一结构。

## 怎么用

1. 新文献：复制 [[30-资源/文献/00-系统/模板/文献卡片模板|文献卡片模板]] → 放到 `10-文献卡片/`
2. 新概念：复制 [[30-资源/文献/00-系统/模板/概念卡片模板|概念卡片模板]] → 放到 `20-概念卡片/`
3. 读文献时：卡片写结论与启发；PDF 放 `90-附件PDF/`
4. 专题入口：[[30-资源/文献/专题/MOC-Knoevenagel|Knoevenagel 专题]]

## 结构

```text
30-资源/文献/
  00-系统/模板/     标准模板
  10-文献卡片/     一篇文献 = 一张卡片
  20-概念卡片/     可复用概念
  30-实验条件/     可复用条件包
  40-课题关联/     对“我的课题”的启发
  50-汇报PPT/      组会/汇报
  90-附件PDF/      原始 PDF
  专题/            专题 MOC
```
